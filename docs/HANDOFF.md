## 1. Владелец и режим работы

## 2. Тулчейн (восстановить в новом контейнере)
- `bash tools/build/setup.sh` (ставит Godot 4.5.1 в /opt/tw-tools, Android-шаблоны, SDK 35, debug keystore).
  Затем добавить строки из `tools/build/editor_settings_android.txt` в `~/.config/godot/editor_settings-4.5.tres` (нужна Java 21: `apt-get install -y openjdk-21-jdk-headless`).
- Godot: `/opt/tw-tools/godot`. **Всегда** через `flock /tmp/tw-godot.lock` (параллельные агенты).
- **Release keystore** (`CN=Tile Waifu`, SHA-256 3c65ad9e…5854, alias `tilewaifu`) — **только у владельца** (передан файлом вместе с паролем). В репозитории его нет и быть не должно.
  Без него обновление поверх 0.8.x не встанет. Попросить владельца загрузить файл и пароль; положить в /opt/tw-tools/release.keystore.
- Сборка: `cd game && GODOT_ANDROID_KEYSTORE_RELEASE_PATH=/opt/tw-tools/release.keystore GODOT_ANDROID_KEYSTORE_RELEASE_USER=tilewaifu GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=<от владельца> /opt/tw-tools/godot --headless --export-release Android ../build/TileWaifu-X.apk`
- **Обязательная проверка перед каждой сборкой** (иначе белый экран, как в 0.8.0): экспорт пакета и playtest на нём:
  `godot --headless --path game --export-pack Android /tmp/x.pck` → `xvfb-run -a godot --main-pack /tmp/x.pck --rendering-driver opengl3 --audio-driver Dummy --resolution 720x1280 -- --pt=fresh --shots=<dir>` → `PT OK`.
- Самотесты (`--headless --path game -- --<flag>=1`): selftest 240/240, event_selftest 84/84, league_selftest 1131/1131, profile_selftest 13/13,
  recovery_selftest 42/42, ults_selftest 669/669, letters_selftest ~2586, summon_selftest 56/56; `--fuzz=3` (144 партии, 0 ошибок).
- APK в git не кладём (>100 МБ). Доставка: SendUserFile + постоянная ссылка через Higgsfield media_upload (zip, source_type file_input,
  workspace d56c6962-fcec-4bcb-a0d6-fd78e2c43e29) → PUT → media_confirm → ссылка cloudfront.
- В `export_presets.cfg` `exclude_filter=""` — не исключать selftest-скрипты (на них ссылаются g.gd/main.gd/event.gd).

## 3. Higgsfield (контент)
- Картинки: `gpt_image_2_6`, quality high, resolution 2k, референсы через `image_references` (job id прошлой генерации или media id).
  Таблица имя→job id всех генераций: `tools/art/jobs.tsv` (job id живут в аккаунте Higgsfield и годятся как референсы).
- Видео-петли: `kling_o3_flf` (start=end кадр) — владелец счёл «слишком ИИ», плюс был артефакт «третья нога». Для живой анимации героинь
  используем **риг** (раздел 6). Видео — только короткие вставки (ульты/призыв), с покадровой проверкой.
- Фильтр nsfw Higgsfield иногда режет позы на коленях/латекс — переформулировать позу (стоя), сменить референс.
- **Каждый арт перед использованием — строгий аудит анатомии** (ноги/руки/пальцы считать по кропам, без текста, взрослое лицо).
  Скрипт-воркфлоу аудита: два независимых проверяющих на арт (см. историю: 5 из 30 артов датасета были бракованные — 3 ноги, 4 рукава и т.п.).
- Рецепт стиля v4 (одобрен «ИДЕАЛЬНО, БИНГО»): `docs/ART_DIRECTION_v2.md` сверху и `docs/ROSTER_20.md` §2.1 (V4_FACE / V4_TAIL).
- GPU-аренда: L40S 71 кр/ч (`gpu_rent`), команды `gpu_rental_exec` (≤90 с, длинное — через nohup и опрос логов). `/workspace` постоянный:
  `/workspace/tw/ai-toolkit`, `/workspace/tw/output/tw_heroines_v1/`, `.../tw_heroines_v2b/tw_heroines_v2b.safetensors` (**актуальная LoRA**, триггер `twaifu4 style`),
  данные `/workspace/tw/data/v2b`. Перед обучением на новом боксе: `apt-get install -y -q gcc python3.12-dev`, `pip install -r requirements.txt`, запуск с `CC=gcc`.
  Конфиги/скрипты в репо: `tools/gpu/train_v2b.yaml`, `tools/gpu/gen.py`. Не делать `pkill -f run.py` (убивает свою оболочку).
  Выгрузка с бокса: media_upload zip → PUT с бокса → media_confirm → скачать по cloudfront. Бокс **останавливать** (`gpu_rental_stop`) после работы.

## 6. Технические решения, которые нельзя забыть
- Анимация героинь = **риг на арте** (Skeleton2D + Polygon2D скиннинг, данные в `rig_def.json`, сборка `tools/build_rig.py`) — детерминированно,
  без ИИ-морфинга. Видео — только вставки. Владелец хочет «живее и кокетливее, как в BD2».
- Позы у богинь не должны повторяться (правило владельца) — `POSES.md`, ключи силуэтов уникальны.
- Ульты: шкала, ядро героини + модификатор наряда (П/О/Л/В/Ц/С), в рейтинге наряды силы не дают. Вставки без белых вспышек, ≤3 вспышки/с.
- Эффекты подчиняются `S.fx_level` (полные/умеренные/минимум) через `V9Feel.can_fx/can_shake/can_edge_flash`. Все нажатия — через `V9Feel`.
- Сохранения: `SAVE_VER` = 7 (миграция v6→v7 в g.gd). Новые поля — только с миграцией и проверкой в recovery_selftest.
- Git: работаем в ветке `gh-pages`, коммитить и пушить после каждого шага (хук требует). Атрибуция коммитов — по системной подсказке сессии.

## 12. Конституция интерфейса (владелец, 2026-11-24)
