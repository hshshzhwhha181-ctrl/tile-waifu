# Tile Waifu 0.8 — техническая спецификация

Основа: `docs/0.8-critique-plan.md` (что и зачем), `docs/0.8-codemap.json` (карта кода 0.7 с file:line).
Код: `game/` (Godot 4.5.1, GDScript, UI собирается в коде, вьюпорт 720×1280).
Новых механик нет. 0.8 — это «я» игрока, один ранг, люди вокруг и единые правила экранов.

## Решения владельца (не менять)
- ИИ-игроки **без метки «ИИ»** нигде в интерфейсе. Но: никаких счётчиков «сейчас онлайн»,
  никаких фальшивых отзывов, никаких сообщений «от игроков». ИИ не продаются как люди в магазине.
- Аккаунты и оплата — после теста. Прогресс офлайн, перенос через код восстановления.
- Стол риичи: в 0.7 есть только движок (`scripts/v08/table`), UI потерян. В 0.8 — только починить
  компиляцию движка (5 мест) и selftest; экран стола — после 0.8. Вход «Стол риичи» в режимах
  показывается закрытым с подписью «Скоро» и не считается одним из двух главных входов.

## Общие правила кода
- Новый код — в `scripts/v08/<модуль>/`. Классы через `class_name V8...`.
- Новые строки — в своём модуле (const словарь), не в `txt.gd`, кроме правки существующих ключей.
- Каждое изменение сохранения — через `G.save()`. JSON возвращает числа как float — всегда `int()`.
- Шрифт Playfair (UI.font «title», Common.ribbon, UI.title) — только для надписей ≥ 24 px.
  Мельче — Nunito («body»).
- Ни одной траты валюты без подтверждения (`Common.confirm`), кроме покупок, где кнопка уже
  показывает цену и это явное действие «Купить» в лавке/призыве.
- Сохранять совместимость с сохранением 0.7: миграция `S.ver` 5 → 6.

## 1. Ядро (Stream A) — `scripts/g.gd`, `project.godot`, `scripts/v08/core/*`, `scripts/v08/table/*`
- `project.godot`: `application/config/version="0.8.0"`. `G.version()` возвращает её.
- Сохранение: атомарная запись (temp + rename), резервная копия `user://save.bak.json`,
  при битом основном файле — загрузка из бэкапа. Нулевой `FileAccess` не роняет игру.
- `S.profile = {nick:"", avatar:"mc", frame:"", created:<unix>, id:<8 hex>}`; `S.profile_done=false`.
  Миграция v6: игрокам 0.7 тоже показать карточку профиля (profile_done=false), прогресс не трогать.
- `G.add_rp(n:int, source:String) -> Array` — единственная точка выдачи очков ранга.
  Источники: `path`, `daily`, `duel`, `blitz`, `zen`, `etude`, `event`, `tourney`, `table`, `other`.
  Пишет `S.stats[source] = {games, wins, rp}`. Отрицательное n допустимо, но никогда не опускает
  rp ниже начала текущей ступени (tier×3+sub). Старая сигнатура `add_rp(n)` = `add_rp(n,"other")`.
- `G.record_game(source, won:bool)` — счётчики статистики для профиля.
- Удалить фейковый `player_lv` из интерфейса (поле в сохранении можно оставить).
- `V8Recovery.export_code() -> String`: JSON сохранения → deflate → base64url, префикс `TW8-`,
  разбивка дефисами по 6 символов для читаемости; плюс контрольная сумма. `import_code(s) -> bool`
  проверяет префикс/сумму/версию, делает бэкап текущего, заменяет S, сохраняет.
  В UI: показать код, «Скопировать» (DisplayServer.clipboard_set), «Поделиться» не нужно.
- Починить 5 мест компиляции движка стола: `selftest.gd:61`, `mj.gd:284`, `round.gd:235/370/445`,
  переименовать `V8AI.call` (ai.gd:272). selftest стола должен проходить (исправить неверные
  ожидания теста, не движок, если ошибка в тесте).
- Общие хелперы UI в `scripts/screens/common.gd`:
  - `Common.confirm(main, title, text, price_icon, price, on_yes:Callable)` — окно с ценой, «Да»/«Отмена».
  - `V8Header.make(screen, main, title:String, on_back:Callable, on_help:Callable=Callable())` в
    `scripts/v08/hud/header.gd` — одна шапка экрана: «назад» слева (стрелка), заголовок по центру
    (Playfair ≥ 28), «?» справа, если передан on_help. Высота 96, ниже глобального топбара.
  - `V8Header.HEIGHT`, `V8Header.TOP` — откуда начинать контент.

## 2. Население и лиги (Stream B) — `scripts/v08/league/*`, `scripts/v07/event/ladder.gd`, `scripts/v07/event/tourney_screen.gd`
- `V8Population` (static, без сохранения в save — всё детерминировано по сиду):
  1000 ИИ-игроков: `id`, ник (русские и латинские ники в стиле мобильных игр, генератор из слогов
  и словарей, без повторов, без имён реальных людей и без брендов), аватар (герои + наряды из
  `assets/outfits`, кроп `Common.card_art`), рамка по цвету героини, «любимая героиня», базовая
  сила (распределение: много Бамбука/Нефрита, мало Дракона/Небожителя), темп (сколько партий в день,
  дни активности), город не нужен.
  `rp_at(player_id, unix_time)` — монотонно растущие очки ранга в квартале, плавные (без ступенек
  по 0), с дневным ритмом (меньше ночью по местному времени).
- Квартал: календарный квартал. Таблица квартала = топ-100 + строка игрока с местом.
  Очки игрока в квартале = rp, заработанные с начала квартала (`S.v8_league.q_start_rp`).
- Недельная лига: ступени = те же 6 тиров `G.RANKS` (заменить Медная…Лунная). Группа 20 человек:
  игрок + 19 из населения с близким рангом, детерминированно по неделе и id игрока.
  Очки соперников растут плавно по ходу недели (`week_points(player_id, t)`), к понедельнику утром
  у большинства уже не ноль — никаких прочерков. Повышение/понижение: топ-5 вверх, низ-3 вниз,
  но понижение не ниже ранга игрока по `G.RANKS`-тиру минус 1 и никогда в первую неделю.
  Миграция старой лиги: Медная→Бамбук, Серебряная→Нефрит, Золотая→Жемчуг, … по индексу.
- Карточка игрока (popup по тапу на строку): аватар, ник, герб ранга, лига, место в квартале,
  любимая героиня, «партий за неделю». Без метки ИИ. Для игрока — та же карточка (открывает профиль).
- `V7Ladder.backend` сохранить как разъём: позже на места ИИ придут люди.
- Экран турнира (`tourney_screen.gd`) переделать на `V8Header`, вкладки «Неделя» / «Квартал».
- Публичный API для главной и профиля: `V8League.my_week() -> {league_tier, place, points, group_size}`,
  `V8League.my_quarter() -> {place, total:1001, points}`.

## 3. Профиль и вход (Stream C) — `scripts/main.gd` (только `_splash`, `_meet_scene`, `SCREENS`, `settings`), `scripts/v06/story/story_scenes.gd`, `scripts/v06/story/txt.gd` (ключи title.*), `scripts/v08/profile/*`
- Титул: версия из `G.version()` («версия 0.8.0»), золотая плашка «Играть» вместо «Коснись»,
  ник игрока под логотипом, если профиль есть.
- Первый запуск: титул → карточка игрока → знакомство → первая партия.
  Карточка: ник (поле ввода + кнопка 🎲 «случайный», генератор из V8Population), выбор аватара
  (5 героинь), кнопка «Играть офлайн — прогресс на телефоне», ссылка «У меня есть код» (ввод кода
  восстановления → `V8Recovery.import_code`). Ник 3–16 символов, фильтр пустых/пробелов.
- Знакомство (`intro` в story_scenes.gd:17-27): ровно 3 реплики, без выбора; остальное героиня говорит
  в первой партии через существующие пузыри.
- Экран профиля (новый id `profile` в `main.SCREENS`): шапка V8Header «Профиль»; аватар, ник
  (изменить), герб и полоса ранга, лестница рангов (перенести сюда `main.rank_ladder`), статистика по
  режимам из `S.stats`, место в недельной лиге и в квартале (`V8League`), код восстановления
  (показать/скопировать/ввести), кнопка «Настройки» (открывает `main.settings`).

## 4. HUD и экраны (Stream D) — `scripts/main.gd` (только `_build_topbar`…`refresh_currency`, `_build_navbar`, `refresh_nav`), `scripts/screens/home.gd`, `scripts/screens/modes.gd`, `scripts/v06/modes/modes_data.gd`, `scripts/ui.gd`, `scripts/screens/{levels,shop,summon,collection,daily}.gd`, `scripts/v07/event/event_screen.gd`, `scripts/v07/room/*`, `scripts/v07/album/*`
- Топбар: слева аватар игрока (`S.profile.avatar`) + ник + ранг (герб маленький, название) — тап
  открывает профиль; справа две валюты. Убрать пилюлю player_lv. Топбар обновляется при смене профиля.
- Главная (Чайная): левая колонка из 4 значков — Поручения, Визиты, Письма, Рейтинг (рейтинг →
  экран турнира, вкладка Квартал). Настройки — в профиль. Убрать баннер закрытых «Желаний».
  Карточка лиги справа: герб лиги, «#место из 20», очки недели → экран турнира.
  Плашка симпатии без обрезки (подогнать ширину/размер шрифта, не clip_text).
  «Письма»: пока нет экрана писем — значок открывает список последних сообщений героинь из комнаты
  (если есть данные) или toast «Писем пока нет»; не врать бейджем.
- Режимы: два главных входа крупно — «Путь» (карта уровней) и «Турнир недели»; «Стол риичи» —
  закрытая карточка «Скоро». Остальные режимы ниже компактным списком, открываются по рангу:
  Блиц — Бамбук III, Сад/Дзен — Нефрит I, Дуэль — Нефрит II, Этюды — Нефрит III, Смена в чайной —
  Жемчуг I, Лунная лестница — Жемчуг II, Раскладка дня — сразу. Закрытые показывают «Откроется на
  ранге …». Убрать захардкоженные «НОВОЕ». На главной — прямой вход в режимы.
- У всех экранов из списка — `V8Header` с «назад» слева и заголовком; убрать разнобой «К карте»,
  «Назад», крестиков в шапках. Попапы — `Common.popup` как есть.
- Android «назад» (`NOTIFICATION_WM_GO_BACK_REQUEST`): закрыть верхний попап, иначе назад по экрану,
  на главной — ничего.
- Шрифты: найти все Playfair-надписи < 24 px и перевести на Nunito.

## 5. Партия и победа (Stream E) — `scripts/screens/play.gd`, `scripts/v06/modes/mode_play.gd`, `scripts/v07/event/event_play.gd`, `scripts/v07/integrator/combo.gd`, `scripts/v06/heroines/duel.gd`
- Подсказка/отмена/перемешать (30) и спасение лотка (60): после бесплатных — `Common.confirm`
  с ценой и галочкой «не спрашивать в этой партии».
- Очки ранга из всех режимов через `G.add_rp(n, source)`: дуэль (победа +20, поражение 0), блиц/дзен
  (по результату, 5–15), этюды, ивент и турнир (+по месту/очкам), Путь и ежедневка — как было.
  `G.record_game` везде.
- Экран победы одной колонкой без наложений: заголовок → звёзды → полоса единого ранга (было/стало,
  +N) → очки лиги недели (+N, место) → компактные яку → кнопки внизу. Героиня — сбоку/фоном, контент
  поверх неё на подложке. Комбо-плашка скрывается при открытии окна победы. «Новый ранг» —
  внутри окна, не toast поверх заголовка. Под звёздами строка-объяснение правила звёзд.
- Карточка удачи на уровне 1-6: стол виден и интерактивен не позже чем через 1 с.
- Стартовый набор «Набор первого гостя»: флаг показа сохраняется в S; показывать после 3-й победы
  в Пути, один раз, предложение действует 72 часа; не обещать билеты, которые не выдаются
  (выдавать их или убрать из текста).
- Строки «4 места в лотке» (story_scenes.gd:25, g.gd:60) — исправить на фактическое число слотов.

## Проверка
- `godot --headless --path game -- --selftest=1` → 240/240.
- `--event_selftest=1` → все проходят; spec selftest 288/288; `--fuzz=5` без SCRIPT ERROR;
  selftest стола проходит.
- Скриншоты: `xvfb-run -a -s "-screen 0 800x1400x24" /opt/tw-tools/godot --path game --rendering-driver opengl3 --audio-driver Dummy --resolution 720x1280 -- --shots=<dir> --screen=<id> ...`
- Новый флаг `--pt=<сценарий>` (playtest): прогон чистой установки до Чайной и по экранам с
  касаниями и скриншотами каждого шага; должен выполняться без ошибок.
