# Tile Waifu — состояние проекта

Обновлено: 2026-11-23.

## Что есть
- `apk/TileWaifu-0.2…0.7.apk` — сборки Android (Godot 4.5.1).
- Корень ветки `gh-pages` — старый веб-прототип (HTML/JS), по коду не связан с APK.
- `docs/0.8-critique-plan.md` — критика v0.7 и план 0.8 (из старого треда).
- Концепт-план: документ «Аниме-маджонг: концепт-план» в Claude Docs.

## Чего нет
- Исходников Godot-проекта. Они жили в контейнерах старых сессий и не были закоммичены.
  Работа над 0.8 (ранги, лиги) потеряна вместе с ними.
- В APK 0.7 уже есть скрипты `scripts/v08/table` (ai, mj, round, selftest) — заготовка стола риичи.

## План восстановления
1. Декомпилировать APK 0.7 (GDRE Tools 2.7.4) в проект Godot 4.5.1.
2. Закоммитить проект в `game/` и дальше коммитить исходники после каждого шага.
3. Пересобрать 0.7 из исходников, сверить с APK.
4. Делать 0.8 по `docs/0.8-critique-plan.md`.

## Решения
- ИИ-игроки в лигах: **без метки** (решение владельца, подтверждено 2026-11-23;
  риск разоблачения из раздела «Что говорят игроки» принят осознанно).
  Счётчиков «сейчас онлайн» и фальшивых отзывов нет. Когда появится сервер,
  на места ИИ приходят живые игроки через тот же разъём.
- История тредов старого аккаунта: `docs/THREADS.md`.
- Площадки: сначала RuStore (APK, размер не ограничиваем), Яндекс Игры после (облегчённый веб-пресет). Решение 2026-11-23.
- Качество: «всё приятно нажимается, гармонично и дорого» — главный критерий приёмки любой фичи.
- Владелец разрешил действовать без подтверждений (автоматический режим), включая траты кредитов Higgsfield в пределах баланса.
