Обновлено: 2026-11-23.

## Что есть
- `apk/TileWaifu-0.2…0.7.apk` — сборки Android (Godot 4.5.1).
- Корень ветки `gh-pages` — старый веб-прототип (HTML/JS), по коду не связан с APK.

## План восстановления
1. Декомпилировать APK 0.7 (GDRE Tools 2.7.4) в проект Godot 4.5.1.
2. Закоммитить проект в `game/` и дальше коммитить исходники после каждого шага.
3. Пересобрать 0.7 из исходников, сверить с APK.
4. Делать 0.8 по `docs/0.8-critique-plan.md`.

## Решения
- ИИ-игроки в лигах: **без метки** (решение владельца, подтверждено 2026-11-23;
  риск разоблачения из раздела «Что говорят игроки» принят осознанно).
  Счётчиков «сейчас онлайн» и фальшивых отзывов нет. Когда появится сервер,
  на места ИИ приходят живые игроки через тот же разъём.
- История тредов старого аккаунта: `docs/THREADS.md`.
- Площадки: сначала RuStore (APK, размер не ограничиваем), Яндекс Игры после (облегчённый веб-пресет). Решение 2026-11-23.
- Качество: «всё приятно нажимается, гармонично и дорого» — главный критерий приёмки любой фичи.
- Владелец разрешил действовать без подтверждений (автоматический режим), включая траты кредитов Higgsfield в пределах баланса.

## 0.8.1 (2026-11-24) — исправление белого экрана
- Причина: в export_presets.cfg из APK были исключены файлы самотестов (`scripts/*/*selftest*`), а g.gd, main.gd и event.gd
  ссылаются на их классы → на телефоне autoload G не компилировался → белый экран загрузки. В редакторе/xvfb это не видно,
  потому что там запускается полный проект.
- Исправлено: exclude_filter пуст; «Лектор салона» (mc_tutor, перерисован) тоже снова в сборке. versionCode 9, ставится поверх 0.8.
- **Обязательная проверка перед каждой сборкой:** экспортировать пакет и прогнать на нём playtest:
  `godot --headless --path game --export-pack Android /tmp/x.pck` затем
  `xvfb-run ... godot --main-pack /tmp/x.pck --rendering-driver opengl3 --audio-driver Dummy --resolution 720x1280 -- --pt=fresh --shots=<dir>` → `PT OK 51`.
- Рейтинг: целимся в Mature 17+ (Google Play) / 18+ (RuStore), уровень привлекательности — как у Brown Dust 2, но свои дизайны. Решение 2026-11-24. Детали — docs/HEROINES.md.

## Решения владельца 2026-11-24 (вечер)
- Ростер 20 богинь A / S / SSR (5 текущих + 15 новых) → `docs/ROSTER_20.md`. Наряды тоже по рангам; темы фишек и стола видят другие игроки; SSR меняет весь HUD/меню.
- Все идеи из штурма утверждены заранее (и будущие) → `docs/IDEAS.md`. Внедрять красиво, через критиков.
- Подача: необычные шрифты (свой акцидентный шрифт у каждой SSR-богини, OFL, с кириллицей), стилизованные профили игроков, чаты.
  Чаты между игроками — только с сервером и модерацией (жалоба/блок обязательны в сторах); до сервера — чат с героинями и реакции-стикеры.
- Монетизация: пей-воллы и мотивация к покупкам — да, по правилам сторов (шансы гачи раскрыты, без обманных таймеров).
- Анимации: у каждой богини свой индивидуальный набор движений, «сочно» как в BD2 — ножки (скрещивание, трутся коленки), губы (улыбка, прикус губы, воздушный поцелуй, лип-синк), покачивание, физика волос/ткани.
  Границы прежние (HEROINES.md): взрослые, без наготы, без сексуальных действий, без камеры на пах.
- Обе Новы (латекс-присед и крыша) — в датасете LoRA v2 по выбору владельца.
