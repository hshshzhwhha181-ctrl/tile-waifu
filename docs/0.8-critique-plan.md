# Tile Waifu 0.8 — критика и план цельного продукта

Nov 23, 2026 · @Aeyv.exe

## Итог

v0.7 — это набор хороших систем, которые не знают друг о друге. В игре три разных ранга (Бамбук, Ученица, Медная лига), четыре разных шапки экранов, восемь режимов на одном экране и ни одного «я» игрока: нет имени, профиля, лиги, людей вокруг.

0.8 делает из этого продукт: вход с профилем (офлайн, с кодом восстановления), один ранг игрока на все режимы, лиги и рейтинг квартала с \~1000 ИИ-игроками, одна шапка и одни правила HUD на всех экранах. Новых механик в 0.8 нет, только сборка того, что есть, в целое.

## Как я играл

Бот-игрок жмёт настоящими касаниями (touch, как палец), экран с пропорциями твоего RedMagic 1216×2688. Прошёл чистую установку: титул → сцена знакомства → первая партия → победа → Чайная, затем все экраны: уровни, режимы, желания, гардероб, лавка, комната, ивент, турнир, лобби и стол риичи. Скрипт прогона остаётся в игре (`--pt=`), его можно гонять на каждую сборку.

## Критика v0.7 по экранам

Самое дешёвое ощущение даёт не графика, а швы между системами: налезающие плашки, три ранга, разные шапки, трата кристаллов без вопроса.

## План 0.8

0.8 не добавляет режимов: она даёт игроку «я», один ранг и людей вокруг, и приводит экраны к одним правилам.

1. **Вход.** Титул → карточка игрока (ник с кнопкой «случайный», аватар, «Играть офлайн — прогресс на телефоне», «У меня есть код») → знакомство → первая партия. Код восстановления переносит весь прогресс на другой телефон без сервера. Аккаунты и оплата — после теста, как договаривались.
2. **Профиль.** Аватар в шапке открывает профиль: ник, ранг с гербом, статистика всех режимов, место в лиге и в квартале, код восстановления, настройки.
3. **Единый ранг.** Одна лестница Бамбук → Нефрит → Жемчуг → Золото → Дракон → Небожитель. Очки дают все режимы: Путь, стол риичи (по месту), турнир. Комнаты стола открываются тем же рангом. Потеря очков за плохое место только в старших залах и никогда ниже начала текущей ступени.
4. **Квартал и лиги.** 1000 ИИ-игроков с никами, аватарами, рангами и своим темпом. Они играют в твоей группе турнира недели и стоят в рейтинге квартала (топ-100 + твоё место). Очки растут по ходу недели, таблица живая и без сети. По тапу открывается карточка игрока с небольшой пометкой «ИИ». Счётчиков «сейчас онлайн» и фальшивых отзывов нет. Когда появится сервер, на места ИИ придут люди через тот же разъём.
5. **HUD.** Шапка: профиль (ник + ранг) слева, две валюты справа, больше ничего. Главное действие справа внизу под большим пальцем. Левая колонка главной — четыре значка (Поручения, Визиты, Письма, Рейтинг). У новых экранов одна шапка: «назад» слева, заголовок, справка справа. На экране победы ничего не налезает.
6. **Мелкие доработки.** Платная подсказка с подтверждением, версия на титуле из сборки, симпатия без обрезки.

После 0.8, по отдаче: мягкая подстройка расклада после 2 провалов; комбо-лестница высоты тона; стикеры героинь за столом вместо чата; сервер для живых лиг; озвучка выкриков стола, когда на Higgsfield появятся кредиты; меньше режимов на старте с открытием по рангу.
