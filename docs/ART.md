# Tile Waifu — арт-библия 0.8

## Стиль
Графит + полированное золото + пыльная роза, акценты сакуры, нефрит/лаванда по смыслу.
Глянцевые лаковые поверхности, мягкий свет сверху-слева, без текста в арте.
Мастер-эталон: стайл-тайл «графит-золото» (Higgsfield job 47d64c06), гербы лиг — «фишка маджонга в фонаре» (job d5f51543).

Правила:
- Иконки в кругах (`v08/ui/icon/*` первые 8) — для колонок и шапок; «голые» золотые глифы — для кнопок в партии и навбара.
- Ранг = герб-медальон (`rank/`), лига недели = герб-фишка (`league/`). Не путать.
- Розовые «кавайные» плитки из `assets/icons/*` и плоские кремовые глифы — устаревшие, заменяются.
- Никакого текста внутри картинок, кроме логотипа и кнопки «Играть» на титуле.
