# Tile Waifu 0.9 «Живая чайная» — спецификация

Цель: каждая минута в игре ощущается живой и дорогой. Новых режимов нет.
Главный критерий приёмки (владелец): **всё приятно нажимается, гармонично и дорого.**
Основа: `docs/ROADMAP.md` §0.9, `docs/HEROINES.md` (§2 ульты, §3 лестница редкости, поправка владельца про уровни фансервиса), `docs/ART.md`.
Площадка: сначала RuStore (APK), размер не экономим. Веб-пресет — позже.

## A. Фундамент
- Настройка «Эффекты: полные / умеренные / минимум» (S.fx_level), читается всеми эффектами ниже. Умеренные — без тряски и вспышек по краям; минимум — только отклик нажатий.
- Настройка «Вставки ульт: полностью / коротко / выкл» (S.ult_cutin).
- Единый сервис отклика `V9Feel`: press(node) — масштаб 0.94→1.0 с пружиной, звук клика, лёгкая вибрация; success/fail/big. Все JButton и фишки идут через него (часть уже есть в 0.8 — свести в одно место).
- Аудио: питч-лестница для комбо (каждая пара в комбо на полутон выше, до октавы), лёгкий дакинг музыки на вставках.

## B. Система ульт (HEROINES.md §2)
- Шкала умения → «Ульта». +1 за пару, порог 8 пар (5 при высокой симпатии вне рейтинга), стартовый заряд SR +2 / SSR +3 вне рейтинга.
- Ядро героини (одно на все её наряды): МТ — снимает 1 пару; Рин — возвращает лоток (пуст → снимает пару); Хана, Юэ, Нова — по §5 библии.
- Модификатор наряда П/О/Л/В/Ц/С (§2), у базовых нарядов нет.
- Таблица `ULTS[outfit_id] = {name, lines, palette, ref_img, face_rect, mod, sfx}` для всех текущих нарядов (названия ульт из §5).
- Запуск тапом по портрету, 2 с на выбор цели или автоцель. В рейтинге: стартовый заряд 0, порог 6, модификаторы и скины выкл, клип короткий.
- Пары от ульты помечаются from_ult (не заряжают ульту, не продлевают комбо).
- Вставка (кат-ин): стоп-кадр наряда в косой полосе цвета героини поверх затемнённого поля, название ульты каллиграфией, реплика, эффект на сильную долю. R/SR ≈1,33 с, SSR ≈2 с. Тап пропускает вставку, эффект срабатывает. Не больше 3 вспышек/с, без белых вспышек.
- В профиле/магазине: «В рейтинге наряды не дают силы».

## C. Живая героиня в Чайной + Письма
- Касания по зонам (голова / рука / наряд / фон): разные реакции — эмоция из 25 портретов (`assets/v08/emotions`), реплика, голос (если есть файл), +симпатия с дневным потолком 3. Зоны — только уместные, без «интимных» зон.
- Простой лип-синк/моргание уже есть (риг) — подключить к репликам.
- Видео-пилот: если есть `assets/v09/video/mc_lobby.ogv` — проигрывать петлю на главной вместо статичной Маджонг-тян (только когда партнёр mc и эффекты «полные»), со статичной заменой и замером FPS в dev-оверлее (--fps=1).
- «Письма»: 1–2 письма в день по событиям игры (первая победа дня, рекорд комбо, ранг, давно не заходил) от героинь, экран писем с бейджем на главной, ответ одной из 2 реплик → +симпатия.

## D. Сочность партии и экрана победы
- Комбо-лестница: плашка растёт и меняет цвет по ступеням, на высоких ступенях — вспышка по краям экрана, лёгкая тряска (по fx_level), вибрация в такт, аура героини в её фирменном цвете.
- «Лихорадка» читается без звука (рамка поля, цвет, частицы).
- Победа: звёзды с «штампом», яку-штампы по одному с ритмом, полоса ранга с переливом и искрами, прокатка цифр наград.
- Чиби/портрет героини в партии только у края HUD; ничего не перекрывает поле и не ловит тапы.

## E. Призыв в 3 ступени
- Фонарь появляется → его цвет заранее выдаёт лучшую редкость (R нефритовый, SR лавандовый, SSR золотой) → смена музыки → раскрытие карт. Гарант и счётчик видны. Пропуск со второго призыва.
- Арт фонарей: `assets/v09/summon/lantern_{r,sr,ssr}.png` (если нет — рисовать кодом).

## Проверка
Все самотесты, --fuzz, --pt=fresh **на экспортированном пакете** (`--export-pack Android` + `--main-pack`), скриншоты всех экранов, вставки ульт и призыв.
