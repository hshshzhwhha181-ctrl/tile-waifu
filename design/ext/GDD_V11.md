## 1. Столпы, аудитория, позиционирование

### 1.1 Видение в двух фразах
Tile Waifu — спокойный маджонг-пасьянс с глубоким риичи-столом внутри и коллекцией десяти взрослых героинь, которые помнят игрока. Гача только косметическая, доска всегда решаема, «играть» никогда не значит «смотреть рекламу».

### 1.5 Красные линии (неизменны, действуют во всех сборках)
Все героини явно взрослые (23+ в каноне, пропорции 7–7,5 голов, возраст и профессия в профиле); никакой школьной темы и «учитель–ученик»; никакой наготы, нижнего белья как самостоятельного наряда, просвечивающих тканей на интимных зонах, сексуальных действий, камеры на пах/«подглядывания», разрушения одежды ультой/поражением; флирт направлен только на игрока; интимные зоны касания мертвы; чужие ассеты (в том числе BD2) в промптах и датасетах запрещены (`HER §1, §4`, `HANDOFF §1.3`). Любое расхождение «возможностей арта» с этими линиями решается в пользу линий.

## 2. Игровые контуры

### 2.1 Контур сессии (≈3 минуты: «один уровень Пути»)
```
[Чайная] тап «Играть · N» (≤1 с до доски; карточка уровня: «решаемо · сид #… · проверено ботом»)
   │
   ▼
[Партия 2–3 мин] тап по паре ── SFX ≤40 мс ── haptic ── Bond-тик партнёрше (невидим, в итог)
   │   ├ комбо ×5/×10/×20 → героиня «кромка/выход/витрина» (T1/T2/T3, §9.3)
   │   ├ заряд ульты +1 за пару → ульта готова (8 пар у всех, заряд на старте 0) → тап по кольцу-кнопке ульты (не по героине, §4.3)
   │   ├ осталась 1 свободная ячейка лотка → музыка +tension-слой, сердцебиение (и визуальная пульсация ячейки для игры без звука)
   │   └ Отмена/Перемешать бесплатны и безлимитны, без счётчиков на кнопках; Подсказка: 3 бесплатных на уровень, далее 30 монет
   ▼
[Победа — быстрый путь ≤3 с, обычный уровень]
   одна панель: «Поле чисто» (120 мс тишины → короткий стинг), звёзды, награды иконками, полоса Bond «+N», Season XP
   CTA: «Ещё уровень» (розовая «Игра»); вторичные ≤2: «На карту», «Поделиться». Тап в любой момент = сразу дальше
[Победа — полная цепочка ≤20 с, 3 панели, 1 Confirm] только в вехах: первая победа в жизни, босс главы, первая ★★★ главы, каждая 10-я победа
   панель 1: звёзды + «Поле чисто» (400 мс тишины → `sting_victory`); панель 2: награды; панель 3: героиня (арт T3) + Bond + XP
   ▼
[следующий уровень] или [возврат в Чайную]
Каждая победа одновременно: Bond партнёрше, прогресс Заданий дня, Season XP, ★ Салона, Мастерство наряда.
```
Ни продаж, ни попапов внутри живой доски и в цепочке победы (`UX §5.2 п.4`). **На экране победы нет ни одного счётчика «осталось сегодня»**; допустима только полоса «ещё N уровней до сундука» (прогресс к награде, не лимит). Причина быстрого пути: 25–30% времени уровня уходило бы на ритуал (критик art) [КР].

### 2.2 Контур дня («минимум» ≈5 минут, «полный» ≈25 минут)
```
Вход → [Утренний поднос] 1 Confirm «Забрать всё»: 1 билет желания + 100 монет (копится до 14 суток отсутствия, §5.3)
   → Фонари на Чайной: «Салон» (с L7), «Сегодня» и «Серия» (с L16)
Сегодня: Партия дня (общий сид) + 3 Задания дня по 25 кр (+15 кр за все три); задания подбираются из режимов, в которые игрок играл за 7 дней; 1 бесплатная замена задания в сутки
Салон: до 3 подарков партнёрше (Bond), касания, 2 визита кафе в любое время суток
Серия: «чайные листья» — не сгорают: пропуск = пауза, возврат без потерь
Игровое ядро: 3–6 уровней Пути + любой другой режим (Mode Tour, §2.3)
Минимум 5 мин: «Забрать всё» + 1 Задание/Партия дня + 1 касание → серия идёт
Критерий экономики: ≈10 минут обычной игры ≥100 кр (три Задания дня + Партия дня), ≈25 минут ≈170 кр (ворота `econ_budget`)
```
Потолка кристаллов «в сутки» **нет** (удалён: источники в сумме ≈172 кр, потолок 300 был мёртв, а счётчик «240/300» читался как энергия) [КР]. Единственная защита — серверный антифрод-предел 600 кр/сутки, недостижимый честной игрой; он указан в «Правилах» одной строкой (§5.3).

### 2.3 Контур недели
```
Пн 04:00 МСК: сброс недели → новые Задания недели, Дух недели (кооп-босс, 3 ИИ-союзницы из вашего ростера), сид Подземелья, подношение Пагоды
Mode Tour: любые 3 из 8 типов режимов за неделю → сундук (100 кр + 150 монет + 20 лепестков)
Дуэль недели (формы I–V соперницы), недельная строка лидерборда друзей/кода
Вс: «открытка недели» (итог: уровни, режимы, Bond, лучший комбо) — без продаж
```
Типы режимов для Mode Tour (8): Путь, Классика, Тройки, Связи, Сад, Стол/Рука, Коикои, Дуэли/Приключения. «3 из 8» вместо «5 из 8»: пасьянсист закрывает неделю Путём, Классикой и Тройками и не обязан заходить в риичи/Коикои/Дуэли ради 100 кр [КР].

### 2.4 Контур сезона (56 дней = 8 недель)
```
Фаза A «Новая луна» (дни 1–28): новый SSR-наряд баннера (50/50 с catch-up) + 3 S-наряда + «Новая гостья» (героиня, у которой пройдены ворота, §4), прямая продажа этих нарядов ЗАКРЫТА
Фаза B «Полнолуние» (дни 29–56): 2 SSR из каталога (в этот момент закрыта их прямая продажа) + переключатель «Цель желания» (бесплатный, гарант не сбрасывает); наряды фазы A открываются для прямой покупки с 29-го дня
Дорожка сезона: 40 ступеней, ПОЛНОСТЬЮ бесплатная + повторяемая «ступень 41+»; платная линия — только косметика (899 ₽)
События: мини A (нед. 2–3, 10 дн.), мега (нед. 5–7, 21 дн.), мини B (нед. 8, 7 дн.) — §10
Дуэльные сезоны: 28 дней, 2 за сезон (мягкий сброс рейтинга)
Арки Пути 1–10 открыты в 1.0 (гейт по ★, §3.2 M1); арки 11+ — по одной за сезон с 1.1
Конец сезона: «Зал славы» (итог сезона); календарь баннеров на ≥14 дней вперёд виден в игре (S44)
```
**Правило «одна витрина»:** наряд в каждый момент либо на баннере (только гача), либо в прямой продаже (только покупка). Прямая продажа открывается через 28 дней после старта баннера и приостанавливается на время любого повторного показа этого наряда на баннере; на карточке баннера и в листе подтверждения до оплаты написано «Прямая продажа: после баннера, с (дата), 1 490 ₽» (§5.6) [КР].

### 2.5 Диаграмма мета-контура (как всё связано)
```
                       ┌──────────────────────────────────────────────┐
   Путь / режимы ─────►│ ★ звёзды ──► Салон (ремонт зон, фоны стола)  │
   (партии)            │ Bond-очки ─► лестница привязанности ─► Клятва│
        │              │ Кристаллы ─► Желания ─► наряды (S/SSR)     │
        │              │ Монеты ────► подарки ──► Bond                │
        │              │ Лепестки ──► прямая покупка/звёзды нарядов   │
        │              │ Season XP ─► дорожка (бесплатная)            │
        │              └───────────┬───────────────────────┬──────────┘
        ▼                          ▼                       ▼
   Задания дня/недели ─► Mode Tour ─► Альбом (штампы)   Фон Салона = фон стола во ВСЕХ режимах
        ▲                                                  Наряд = HUD-скин, ульта, реплики

```
Правило связности: ни один режим не вводит собственной «глубокой» экономики; каждый режим подключён минимум к трём общим потокам (кристаллы, Bond, Season XP) и ровно к одному «своему» счётчику, видимому только внутри режима (Цветы месяца, Спокойствие, очки события) — §3.3 матрица.

## 3. Карта режимов

### 3.1 Итоговый состав: что оставляем, сливаем, режем
Источники состава: `R1/B:mode_map` (13 режимов), `R2/DD:MODE MAP` (изменённые роли), `MOD §6` (хаб и порядок открытия), `ADV` (Приключения поглощают Странствие, Пагоду, Дракона, Чайные домены), `ARCH` (headless Session API на режим).

| 2 | **Сегодня** = Партия дня + Задание дня (`daily`, `bridge`-часть) | ОСТАВИТЬ, слить «Партию дня» и «Задачу дня» в одну строку | Главный дневной ритуал; серия без потерь (`R2/L#6`) |

**Приоритеты выпуска (ворота производства, [КР]).** Владелец хочет много взаимосвязанных режимов, поэтому все 11 карточек остаются в 1.0; но у каждой своя цена (обложка, хозяйка, петля музыки, HUD-скин, сертификаты, selftest). Режим в билд входит, только если у него пройдены ворота §3.5 п.5; при срыве сроков сначала переносятся режимы П3, затем П2 — **без правки остальных разделов GDD** (каждая связь режима с общими потоками необязательна для остальных).

|---|---|---|

### 3.2 Паспорта режимов
Формат: назначение · для кого · крючок · питает · сессия · награды · разблокировка · ядро. «Bond» — очки привязанности партнёрше (§4.1); «кр» — кристаллы; суточные числа входят в бюджет §5.3. «Первая победа дня» удалена из всех режимов (не нужна: кристаллы идут Заданиями дня).

**M1. Путь (`path`)**
- Назначение: хребет и туториал; пары + лоток-парковка (4 ячейки; на отдельных уровнях 3 или 5; Тройки — 7, §7.2), цели и препятствия, босс-узел главы (хозяйка главы = героиня), «Пики» без бустеров, «Легендарные».
- Для кого: все; S2/S5 — основной режим.
- Крючок: «решаемо · сид #… · проверено ботом» на карточке; трёхзвёздочная цель; «проходят ≈N%» с L10 (по данным беты, до данных — по прогону бота); героиня-партнёрша живёт в полосе под полем (§7.2).
- **Объём 1.0: 1000 уровней (10 арок × 100) доступны к релизу.** Арка k+1 открывается при ≥60% ★ арки k (≈180 из 300 ★) — гейт по мастерству, не по календарю; календарных замков нет. «Мастерство арки»: 3★ на всех 100 уровнях = титул + 40 кр + 100 лепестков (один раз на арку). Пики и Легендарные имеют недельную цель «5 Пиков» = 30 кр. [КР: RPG, пасьянсист]. Если арки 7–10 не готовы к заморозке контента, они приходят обновлением — раздел GDD не меняется.
- Питает: ★ (Салон), Bond +3 за победу, Season XP +2 за победу (**без суточного лимита**), Мастерство наряда +1 пара-зачёт, ключ к разблокировкам режимов (§3.4), открытие героинь (хозяйки глав).
- Сессия: 2–4 мин (уровни 1–8 — 60–90 с).

### 3.4 Порядок открытия
Правила [КР]: **одна новая система за сессию и не более двух за календарный день** (журнал `new_system_shown`); «система» = экран с собственной экономикой или прогрессом (Желания, Салон, Сегодня+Лавка, Подземелье, Стол+Рука, Дуэли, Коикои, Пагода+Дух); «режим без мета» (Классика, Тройки, Связи, Сад) системой не считается, но даёт не более одной новой карточки за сессию; не более 1 неблокирующего уведомления на 2 мин в первые 10 мин. Любое кольцо NEW FEATURE UNLOCKED имеет кнопку «Позже».

### 3.5 Общие правила режимов (контракт)
1. **Героиня рядом, но не мешает:** один макет партии «board-first» (§7.2): героиня — полоса под полем высотой ≤28% экрана (по пояс), ≤1 риг + ≤1 видео на экране, ни пикселя героини на поле; **касания героини в партии отключены** (они живут в Чайной и Салоне); ульта запускается отдельной кольцо-кнопкой, а не тапом по героине (§4.3). Переключатель «Минимум» сворачивает героиню в медальон 160 px (по умолчанию в Классике, Связях и Саду).
2. **Единый словарь событий** (`TWEvents`): MATCH, DENY, CLEARED, ROUND_ENDED, RANK_UP, PULL_DONE, WALLET_CHANGED, TASK_PROGRESS, SETTINGS_CHANGED — режимы публикуют, оболочка и мета подписываются (`ARCH`).
3. **Session API** каждого режима (headless): `new(seed, cfg)`, `step(action) → [Event]`, `snapshot()`; в ядре нет Node/Tween/Audio (CORE_PURITY lint).
4. **Нормализация и «наряды не дают силы»:** единая таблица §3.5.1 (заменяет три описания черновика). Автоворота: бот с одним и тем же сидом и разными нарядами даёт идентичный результат (разница 0).
5. **Ворота режима к релизу:** решаемость 100% ботом (включая подстроенные доски Пути); доли побед с первой попытки по §3.2 M1; selftest режима зелёный; автотест «0 ложных нажатий» на 20:9 и 9:16; фон выбранной зоны/фон стола подставляется; у режима есть обложка, хозяйка, петля музыки, HUD-скин (иначе карточка скрыта, §3.1 приоритеты).
6. **Кристаллы вне партии:** внутри партии ничего не тикает; итог один раз на победе.
7. **Тупик-детектор** во всех режимах с полем (§3.2 M1); **автосохранение** любой партии.

#### 3.5.1 Нормализация: режим × что включено
Единые константы: порог ульты **8 пар**, стартовый заряд **0**, зависимости заряда от редкости наряда и симпатии **нет**. #### 3.6.2 Честность раздачи — механизм
1. Стена: CSPRNG ОС + Fisher–Yates без modulo-bias; seed 128 бит.
2. **Commit-reveal:** перед каждой раздачей в шапке показывается `SHA-256(seed ‖ salt)` («Раздача В1-0 · a3f9…»); после раздачи раскрываются seed, salt, мёртвая стена и руки ИИ; пересчёт хэша одной кнопкой и на сайте. Честная граница: это доказывает, что стена не менялась после ваших ходов; доказательством отсутствия смещения генератора служат публичный отчёт (≥1 000 000 симулированных раздач: распределение синьшантена стартовой руки) и профиль «Честность».
3. **ИИ получает только публичное:** `AI.decide(PublicView)`, где `PublicView` = своя рука + публичные сбросы/мелды/дора/очки/ход; у типа нет полей «стена» и «чужие руки». Тест `ai_no_wall`: (а) тип не содержит запрещённых полей; (б) подмена стены и чужих рук при тех же публичных данных не меняет решение (fuzz 10 000 раздач). Формулировка для игрока: «ИИ не видит ни стену, ни ваши фишки».
4. **Запрещены:** rubber-banding, «мягкая» следующая раздача после серии, адаптация силы ИИ к вашим результатам. Сила ИИ фиксирована выбранной ступенью. «Подстройка» и «Обходная тропа» существуют **только в Пути** и всегда показывают, что изменено.
5. **Профиль «Честность»** (S42): распределение синьшантена ваших последних ≥500 раздач против теоретического, простыми словами («норма» / «заметное отклонение: проверьте нас») + χ²-значение.
6. **Paifu:** экспорт Tenhou6 JSON и mjai кнопкой на итоге; импорт чужой раздачи по сиду.
7. Метка «ИИ · имя» на каждой сопернице (R-03).

Силы: Новичок (заметные ошибки в защите и эффективности), Адепт, Мастер (максимум, без доступа к скрытой информации). **Публичные цифры (ворота релиза):** для каждой из 15 комбинаций прогон ≥100 000 партий self-play; показываются рейтинг, % рон, % цумо, % дэал-ин, % риичи, % фуро — в профиле соперницы и в «Правилах». Цифры измеряются, а не пишутся от руки.

#### 3.6.5 Разбор, подсказки, тренажёры, статистика
- **Разбор** — только после раздачи (в ходе недоступен): каждый сброс сравнивается с лучшим ходом аналитического ИИ (тот же движок на максимальной силе, детерминированный); показываются «совпало N из M», точность %, красные отметки на ходах с потерей ≥ порога (порог в данных: ориентир 3 п.п. вероятности победы раздачи) и кнопка **«Переиграть с этого хода»** (детерминированный сид, вне рейтинга, 1 тап).
- **Подсказки:** в «Обучении» полные; в «Бамбуке» — только защитные значки «Нет яку» и «Фуритен»; остальное (синьшантен, укэирэ, «Нужен 1 хан») — тумблер «Подсказки», **выкл по умолчанию**; партия в «Бамбуке» с включёнными расширенными подсказками очков ранга выше ступени Новичок не даёт.
- **Тренажёры** — в «Руке» (M9).
- **Статистика «Мои партии»** (S42): распределение мест, средняя позиция, % рон/дэал-ин/риичи/фуро, средние хан и очки, ошибок на партию; локальная история последних 100 партий; экспорт paifu.

#### 3.6.6 Ввод руки на телефоне (S23) — исключение из `HIT_TARGET_MIN`
Правило «все цели ≥96 px» (§7.2) **не применяется к фишкам руки**: 13 фишек + вытянутая по ширине 720 не дают 96 px. Расчёт критика (52 px) не помещается: 13×52 + 12×2 + 8 + 52 = 760 > 720. [РЕШЕНИЕ] фишка руки **46 px** (база 720; на 1080 — 69 px), высота **≥100 px**, зазор 2 px, вытянутая отделена зазором 10 px: 13×46 + 12×2 + 10 + 46 = 678 px. Компенсация — двухшаговый ввод:
- одинарный тап **никогда** не сбрасывает: тап поднимает фишку на 24 px и подсвечивает; второй тап по ней или свайп вверх — сброс;
- риичи: подтверждение свайпом вверх по объявленному сбросу; **Рон/Цумо** ≥120×96 px, **Пон/Чи/Кан** ≥96×96 px;
- тумблеры: «авто-цумогири», «авто-пас», «авто-рон» (выкл по умолчанию);
- скорость ИИ: 3 шага (0,3 / 0,8 / 1,5 с на ход);
- прерывание (звонок, сворачивание, убийство приложения): раздача сохраняется ход в ход и восстанавливается без штрафа;
- грани: стандартные 34 + красные пятёрки; опция «высокий контраст»; темы тайлов (Bond Lv5, ₽) проходят гейт контраста ≥4,5:1;
- **«Классический стол»**: без героини, cut-in и голоса; включён по умолчанию у нажавших «Я играю в риичи»; ультимы и навыки героинь на столе отсутствуют;
- приоритет озвучки ron > tsumo > riichi > pon/chi/kan не допускает перекрытия реплик героини (§8.5).

## 4. Система героинь

Ростер 1.0 — **цель 10 героинь** (`HANDOFF §2.2`, `ROS §2`): `mc` (Маджонг-тян), `rin`, `hana`, `yue`, `nova`, `zlata`, `tsubame`, `miel`, `kohaku`, `shirin`. Остальные 10 из ростера 20 (волны 2–3) — после 1.0 по тому же конвейеру. **«Ранг героини» (A/S/SSR из `ROS §1.1`) в интерфейсе не показывается** — это внутренний тир производства (объём косметики); редкость есть только у **нарядов** (§4.2). Из этого следует, что «новая SSR-героиня» невозможна: в сезон приходит «Новая гостья» (героиня) и новый SSR-наряд (любой героини, §10) [КР: гачер].

**Ворота героини в билд [КР]:** героиня попадает в релизный билд, только пройдя все четыре пункта: (1) `Skeleton2D`-риг; (2) озвучка Beta-24 на JP (§8.4); (3) касания тиров симпатии 0–2, 3–5, 6–8 по ≥3 реплики на тир (4-й тир 9–10 — до Клятвы); (4) одобренный набор кадров «Нейтральный» и «Стандартный» (§4.6). Рабочая цель старта — все 10; **минимально допустимый состав на заморозке контента — 7** (mc, rin, hana, yue, nova, zlata и первая прошедшая ворота из tsubame/miel/kohaku/shirin) [РВ: подтвердить, см. OPEN_QUESTIONS]. Не прошедшие ворота приходят как «Новая гостья» — по одной за сезон вместе со своим SSR-нарядом на баннере.

Правило открытия героини: **бесплатно, игрой**. МТ — на старте; «гостья» — выбор 1 из 3 (Рин/Хана/Юэ) на стартовом баннере (L5); следующие открываются как «хозяйки глав» Пути (босс-узел главы) по расписанию **L20, L30, L45, L60, L80** [НЕ ПРОВЕРЕНО: темп] и далее L100, L130, L160, если ворота прошли все 10; остальные — «Новая гостья» по сезонам. Если из желания выпал наряд закрытой героини, она приходит вместе с ним (ни одна крутка не пропадает). Осколков героини нет. Это снимает «мандатных героев» Omniheroes (`R2/OMNI avoid`).

### 4.2 Наряды, редкость, коллекция
- **Редкость только у нарядов:** результат желания — «Подарок» (бывш. A, нефрит), **S** (лаванда-серебро), **SSR** (золото). Редкость = богатство косметики (HUD-скин, рамка, анимация, озвучка), **не** откровенность и не сила: «С редкостью никогда не растёт площадь открытой кожи» (`HER §3`). Золото в интерфейсе зарезервировано за SSR и одним акцентом; кнопки не золотые (§11.4).
- **Состав 1.0 («Launch-38») [РЕШЕНИЕ]:** 10 базовых (бесплатно; у каждой есть «нейтральный» закрытый комплект как слой одежды на том же риге, §4.6), 10 «клятвенных» (`*_vow`, бесплатно за Клятву), **18 желаемых: 6 SSR + 12 S**. SSR (рабочие id): `rin_ssr`, `hana_ssr`, `yue_ssr` (гостевые для баннера «Первый гость»), `zlata_ssr`, `nova_ssr`, `mc_ssr`. Каждый сезон: +1 SSR и +3 S (§10.3). Дорожная карта на 3 сезона с именами публикуется до запуска.
- **Каталожное правило [КР]:** SSR-наряд входит в пул, только если у него **риг + видео-ульта + ≥8 строк озвучки наряда**; S-наряд — ≥4 строк. S-наряд без рига (статичный кадр + короткое видео) допустим, но не выше S, цена прямой покупки ×0,6 (**S 359 ₽ вместо 599 ₽**, лепестками 540 вместо 900), метка «Статика». Ригами покрываются: 10 базовых + 6 SSR + ≥4 S + ≥5 клятвенных (итого 25; вилка «15–20 нарядов сверх базовых» сохранена: 6+4+5 = 15); остальные наряды — статичный опорный кадр + короткое видео (Theora q8, ≤0,5–1 МБ) только где риг не тянет (`R2/DD:АНИМАЦИЯ`).
- **Плашка на каждой карточке наряда** (баннер, Лавка, превью): «Риг / Видео / Статика · Голос N строк · Сцена да/нет».
- **Превью до траты (S43):** кнопка «Посмотреть 10 с» на баннере, в Лавке и в календаре: риг (дыхание, моргание), одно касание, 1 реплика JP с субтитром, короткая ульта; без владения и без цены на экране превью.
- **Звёзды наряда (Созвездие ★1–★5):** дубль даёт +1★ автоматически; докупить звезду можно лепестками: ★2 60, ★3 120, ★4 180, ★5 300 (накопл. 660) **или за ₽ по фиксированной цене: ★2 49, ★3 79, ★4 119, ★5 199 (все четыре 446 ₽)**; лепестки за рубли не продаются. ★ даёт только косметику: ★2 доп. реплика, ★3 рамка, ★4 фон сцены, ★5 золотой вариант ульты (палитра и тон звука, не сила).
- **Дубль после ★5 [КР]:** S → **60 лепестков**, SSR → **150 лепестков**. Дубль Bond **не** даёт. **Защита от дублей:** гарантированный S в десятке и «Свеча» не выдают наряд, который уже есть, пока в пуле остались неполученные.
- **Мастерство наряда:** считает пары из режимов с полем пар (Путь, Классика, Тройки, Связи) (бронза 200 / серебро 800 / золото 2 000 пар); награды — эффекты, реплики, титул; **в рейтинге и Приключениях = 0** (`ADV`).
- **Коллекция (Альбом):** страницы «Героини» (закрытые — силуэтом), «Наряды» (рамка редкости, ★), «Позы», «Голоса» (JP и RU), «Сцены» (CG, Свидания, Клятва), «Ульты». Героини, не прошедшие ворота, в 1.0 не показываются (нет «ям без дна»).
- **Прямая покупка:** §5.6, правило «одна витрина». Базовые и клятвенные не продаются; «Подарок»-ранг нарядов не имеет.
- **Метрика ворот экономики:** доля бесплатной коллекции активного игрока к дню 56 ≤70% (`econ_budget`), чтобы после первого сезона оставался смысл крутить [КР].

### 4.3 Навыки и ульты
Формула (`HER §2`, с изменением v11): **ядро героини** (одно на все её наряды) + **тактика ядра** + **модификаторы** (выбираются игроком) + **свой клип** наряда. **Наряд меняет только клип, голос и внешний вид** [КР: mahjong, art, RPG].
- **Заряд:** +1 за каждую пару, линейно, без связи с комбо. **Порог 8 пар, стартовый заряд 0 — у всех, во всех режимах** (удалены «5 пар при Bond ≥6» и «S+2/SSR+3»). Симпатия и редкость заряд не ускоряют.
- **Запуск:** на портрете-медальоне героини светится **отдельное кольцо-кнопка 96–120 px** (дуга заряда); тап по кольцу = ульта, **тап по самой героине в партии ничего не делает** (касания живут в Чайной/Салоне, устранён конфликт «ульта vs касание»); 2 с на выбор цели; без выбора — автоцель; «умный» автозапуск (по настройке) учитывает блокировки и выключен в режимах со сравнимым результатом (§3.5.1).
- **Ядра (подтверждено для основательниц):** МТ — снимает 1 пару (цель: тап по паре); Хана — рывок (свайп), снимает 1 пару и открывает 1 фишку; Юэ — луч по ряду; Нова — тап по ярусу; Рин — без цели, возвращает фишки лотка и подсвечивает пару (`HER §2`). Ядра волны 1 (Цубамэ, Миэль, Кохаку, Ширин, Злата) описаны в `ROS §3`, в этом GDD не пересказаны (не перечитывал).
- **Тактики ядра:** у каждой героини **2 тактики** равной ценности (разброс ≤10% по прогону бота); вторая открывается на Bond Lv4 и выбирается вне режимов со сравнимым результатом; в них — базовая (§3.5.1).
- **Модификаторы** (видны иконкой на доске): П подсветить 1 пару 3 с; О открыть 1 закрытую; Л растопить лёд/замок; В вернуть фишку из лотка; Ц автоцель; С подсветить пару для самой старой фишки лотка. **Игрок выбирает по одному на героиню**, список открывается симпатией (Lv2 — 2, Lv4 — 4, Lv6 — все); они **не привязаны к наряду**. Разброс эффективности между модификаторами ≤3% (бот). **Запрещены** модификаторы про время, перестановку поля, заглядывание вперёд, повтор перков героинь.
- **Нормализация:** сводная таблица §3.5.1; в профиле и магазине: «Наряды — только внешний вид и голос; силы они не дают».
- **Клип:** SSR — 6 долей ≈ 2,0 с (первые две доли — макро-глаз); S — 4 доли ≈ 1,33 с; короткая версия ≤0,6 с от тапа до возврата управления (тапы буферизуются); озвучка в первые 0,2 с; тап пропускает с нулевого кадра, эффект на доске не отменяется; полная версия — при первом надевании, при первой ульте дня в этом наряде и в Галерее; **в сравнимых режимах всегда короткая**; ≤3 вспышек в секунду, без белых (кроме 0,15 с в Клятве и смене наряда). Настройка «Вставки ульт: полностью / коротко / выкл».
- **Ворота кат-ина:** одобрение ≥70% в закрытой бете (1-тап рейтинг), иначе переделка (`R1/B:audio_anim_targets`, BD2 публикует approval 75%/61%, `R2/L#4`).

### 4.4 Салон
Мета-режим «твой дом героинь»: зоны (по одной на героиню в билде, до 10), которые восстанавливаются за ★ (20→70★ за зону: z1 20, … z10 70; пример из `SPEC`: «Фонарный двор» Ханы 60★, «Лунная веранда» Юэ 65★, «Мансарда Новы» 70★). Фон выбранной зоны — один из фонов стола во всех режимах и лобби (§7.3).
- **Визит:** тап по зоне → героиня стоит в полный кадр (кадр по Bond), одна реплика в пузыре-строке, ряд подарков (3 иконки; любимый подсвечен), касание = сердечки + голос. Реакция на подарок — в первую секунду.
- **Кафе:** 2 визита в сутки **в любое время суток** (не «утро/вечер»), +4 BP, маленький бесплатный подарок «Чай» ×1.
- **Без цен:** в Салоне, Чайной, Телефоне и сценах платных предложений нет вообще (`UX §5.2 п.4`).
- **Что делает Салон «без дна» невозможным:** вехи оканчиваются Клятвой (§4.5), после — «жизнь героини» (раз в сезон личное письмо и вариант сцены; день рождения), а не новая шкала.

### 4.5 Клятва (церемония) и Свидания
- **Клятва** — капстоун Lv10; зарабатывается игрой, кольцом за кристаллы не покупается (`R2/L#10`, `R2/OMNI avoid`). Игрок выбирает момент («Сказать сейчас» / «Позже»). Сцена **≈25–35 с**, озвученная, **Skip с первого кадра** (повторный просмотр в Галерее):

| Время | Кадр | Звук |
|---|---|---|
| 0,0–0,15 | белая вспышка (единственная разрешённая) | `vow_ring` |
| 0,15–4 | портрет T3, взгляд на игрока, лёгкий параллакс, дыхание | мотив героини, музыка −6 дБ |
| 4–14 | крупный план рук/кольца-значка, золотые сердца ≤18 частиц | реплика `level_max_vow` (JP, RU субтитры) |
| 14–22 | смена наряда на клятвенный (`*_vow`) по вспышке 0,15 с, новый фон | `heart_levelup_big` |
| 22–30 | финальный кадр, фраза-тег, рамка «Клятва · имя» | стинг ≤2 с |
| 30–35 | письмо падает в Телефон | `reward_pop` |

  Награды: клятвенный наряд, **3 билета желаний**, титул и рамка, лобби в тире T3, 10 поз фото-режима, «жизнь героини».
- **Свидание (Lv6 и Lv8):** ветвистая сцена 90–120 с, 2–3 выбора (без «правильных» ответов, любая ветка +BP), CG в Галерею. Доступно в тирах арта «Стандартный» (с ограничением кадра по Bond) и «Полный»; в «Нейтральном» — те же сцены в кадре нейтрального комплекта без `bold`-жестов. Взрослая подача **только в красных линиях §1.5**.

### 4.6 Тиры арта и «Режим приглушения»
Настройка верхнего уровня (Настройки → Картинка → «Оформление» и «Режим приглушения»), три положения; **переключатель всегда доступен**, явно подписан, ничего не «подменяется тихо» (урок BD2: 592 поста / 2 127 комментариев, `R2/L#2`, `R2/L#11`). **Выбор делается на первом экране (S02)**: чип «Оформление: Аниме / Спокойное» — «Аниме» = «Стандартный», «Спокойное» = «Нейтральный» (для игры на людях и для тех, кому героиня не нужна, [КР: пасьянсист]). В сборке, отправляемой на модерацию RuStore, по умолчанию стоит «Нейтральный» (§11.6).

| Тир арта | Для кого | Кадр | Чулки/ноги (по LEGWEAR) | Жесты | Сцены | Ульта T3-комбо | Сборка |
|---|---|---|---|---|---|---|---|
| **Нейтральный** (SFW) | «на людях», Яндекс, превью стора | **отдельный закрытый наряд-комплект** (воротник/плотная ткань), кадр от головы до бёдер **без акцента на грудь**; не кроп базового наряда | плотные колготки | без `bold` | Свидания в том же кадре | T3 = T2-кадр | в APK и **единственный** в Web (Яндекс) |
| **Стандартный** | выбор «Аниме» в 18+ | полный кадр по Bond-тирам | чулки/гольфы в рамках LEGWEAR | базовые | Свидания 1–2 | вариант `все↑` | только APK |
| **Полный** | отдельный тумблер «Мне 18+, показывать откровенные сцены» (выкл по умолчанию), Bond ≥6 | как «Стандартный» + `bold`-вариации | + «дизайнерские» рваные образы пяти героинь (строго не выше середины бедра) | + `bold` | + Bond-gated варианты | вариант `18+` при `V10Age.bold_ok()` и Bond ≥6 | только APK |

- Эффективный кадр = min(тир арта, тир Bond). Вставки тира «Полный» **не** имеют наготы, нижнего белья как наряда, камеры на пах и пр. (§1.5). Тумблер «Полный» блокируется при активной паузе покупок (§5.9).
- Дополнительно: «Общий голос» вместо героини (нейтральный диктор), «Скрыть наряды на столе» (на столе базовые), **«Тихий режим»** — одна иконка в паузе/Чайной: тир «Нейтральный» + голос выкл + без cut-in; переключение ≤1 с. Тиры арта 2 и 3 — данные, переключаемые флагом; тир 1 — новые изображения (производится первым, R-21).
- **Возраст [КР: юрист]:** экран S02 — ввод **полной даты рождения ДД ММ ГГГГ цифрами** (клавиатура-цифры, автопереход; барабаны не подходят для 1975 года). Возраст считается по дате устройства и по серверной дате, где она доступна; <18 — экран отказа, флаг блокировки хранится вне сохранения (Keystore, подписан), повторный ввод — только после «Очистить данные» или через 24 ч. Формулировка в интерфейсе — «заявлено 18+» (самодекларация — не верификация, **[ЮР]**). Яндекс-сборка — тир «Нейтральный» без `cg_16`, `bold`, тяжёлых `.ogv` (`HANDOFF §5 P2`).

### 4.7 Касания, Галерея, Фото-режим
- **Касания:** 5 зон — голова, рука L, рука R, волосы, наряд; **интимные зоны мертвы** (красная линия). Реплики зависят от тира Bond × время суток; спам 3+ касаний за 1,3 с → отдельная реакция (`touch_spam`); кулдаун реплики 4 с; редкая реплика 1/20 [наше решение, проверить плейтестом, `R2/DD:АНИМАЦИЯ`]; реакция начинается <100 мс. В партии касания героини отключены (§3.5 п.1); в Чайной и Салоне касание не блокирует остальной интерфейс.
- **Галерея** (вкладка в «Героини», открывается с L7): все Свидания, Клятвы, ульты, комбо T1–T3, голоса; повтор и цикл; превью-10 с до открытия не покупаемой сцены (сцены Bond-gated, не продаются); экспорт — нет. Реализует просьбу BD2 «реплеи и комбинации».
- **Фото-режим/«Любоваться»:** тап по пустому фону — HUD уходит за 0,3 с, героиня приближается на 6%; запись 6 с для сторов/трейлера; позы по Bond.

### 5.5 Гача: правила, шансы, гарант, баннеры
Единый движок `TWGacha.pull(state, banner, n)` платит сам и пишет ledger (дубль-движок и `V10Odds` удаляются, `ARCH`). Результат желания имеет три ранга: **«Подарок»** (бывш. A, 81,3%: подарок случайной открытой героине эквивалентом Чай/Сладость/Любимое 50/120/250 монет + **5 лепестков**; арта не требует), **S**, **SSR**.

**Шансы (одинаковы на всех баннерах, кроме «Первого гостя»):**

| Ранг | База (до гарантов) | Итог (с гарантами; MC 2 млн желаний, seed 11, `design/_sim3.py`) |
|---|---|---|
| SSR | **1,5%** | **≈2,43%** (в среднем одна SSR на ≈41 желание) |
| S | 13% от остатка | **≈16,3%** (≥1 S или выше в каждой десятке) |
| Подарок | остаток | **≈81,3%** |
Гарантированный S в десятке не сбрасывает счётчик SSR и входит в «≈16,3%».

**Гарант (счётчики видны; одна строка на экране: «SSR через N · Свеча через M · Следующая SSR — избранная / 50 на 50»):**
- **Мягкий гарант с 60-го желания:** без SSR шанс SSR = 1,5% + 5 п.п. × (N − 60) для N = 61…79 (61-е: 6,5%; 70-е: 51,5%; 79-е: 96,5%); **80-е желание — SSR 100%** (жёсткий гарант).
- **50/50 с catch-up:** каждая выпавшая SSR — избранная с вероятностью 50%; если нет, **следующая SSR на этом баннере гарантированно избранная**.
- **«Свеча» на 120-м желании** с момента последней избранной SSR: игрок **выбирает любую SSR баннера** (срабатывает в ≈10% циклов; не заменяет catch-up, а ограничивает худший случай).
- Счётчики **не сгорают** при смене баннера и сезона (отдельные: «Пять ветров» (без избранной: мягкий с 60, жёсткий 80), фазовые — общий счётчик на «Новую луну»/«Полнолуние» через сезоны, «Первый гость» — свой); дубли → ★ и лепестки (§4.2), Bond не дают.
- **S-ап:** при выпавшем S с вероятностью 50% это один из трёх S-нарядов баннера (равновероятно), иначе из общего пула; catch-up для S нет.
**Результаты (симуляция 2 млн желаний, seed 11):** среднее до **любой** SSR ≈**41,2**; до **избранной** ≈**61,9** (медиана 64; 90-й перцентиль 119; максимум 120). Числа шансов публикуются **только из Марков-расчёта `core/gacha`** (как в v10: ≈2,90% при гаранте 60); симуляция — ориентир для теста (допуск ±0,5%).
**Цена в рублях** (по пакетам §5.6, 37,4–39,8 ₽/желание, без бонусов): любая SSR ≈**1 540–1 640 ₽**; избранная в среднем ≈**2 300–2 500 ₽**; худший случай (120 желаний) ≈**4 500–4 800 ₽**. Старый «худший случай 200 желаний ≈ 7 800 ₽» удалён.

**Сравнение с v10 (не нерф) [КР: гачер]:**

|---|---|---|
| Шанс SSR итог | ≈2,9% | ≈2,43% |
| Желаний до любой SSR | ≈34,5 | ≈41,2 |

### 5.7 Анти-FOMO правила (чек-лист 10/10 — ворота релиза)
1. Любой баннер возвращается (Фаза B, прямая покупка с 29-го дня).
2. Серия «чайных листьев» не сгорает: пропуск = пауза.
3. **«Утренний поднос» копится до 14 суток отсутствия** (не 3); билеты в инвентаре не сгорают [КР: F2P].
4. Каждое событие имеет «догоняющий предмет» и лавку, открытую ещё 7 дней после финала; полный дневной набор события ≤5 минут.
5. Нет личных таймеров, «успей», «последний шанс»; календарные таймеры одинаковы для всех (`V10Lint.BANNED`).
6. Гарант не сгорает.
7. Ничего эксклюзивного за пейволлом; платная линия — косметика.
8. Не более 1 уведомления в сутки, тихие часы 22:00–09:00 местного времени [РЕШЕНИЕ], без вины («скучаю» допустимо один раз, не как давление); разрешение на пуши (Android 13+) просим один раз после победы на L10, не на старте.
9. Любое изменение шансов, цен, контента публикуется **за 14 дней** и касается только новых счётчиков; купленное не меняется задним числом (`R2/L#2`). **Оговорка [КР: юрист]:** изменение по требованию закона или стора может не ждать 14 дней; тогда публикуем причину и выдаём компенсацию п.10.
10. **Компенсации (стандарт) [КР: F2P]:** плановые/аварийные работы >1 ч = 150 кр; критичный баг экономики или вынужденное удаление контента = 300 кр + письмо в «Телефоне»; опрос с процентами.

### 7.2 Макет партии «board-first», плитка, HUD [КР: art, пасьянсист]
Один макет вместо двух (в v10 `01_match` и `02_combo` расходятся: поле сжималось, героиня заходила на плитки). Требования:
- **Поле** ≥92% ширины экрана и ≥60% высоты; лоток на всю ширину под полем (Путь 4 ячейки, на отдельных уровнях 3 или 5; Тройки 7 — **R-14 закрыт этим решением**); героиня — полоса под лотком высотой ≤28% (по пояс), **ни пикселя на поле**; одно сценическое размытие под полем вместо шва «сукно/сцена»; комбо-ступени T1–T3 играют в полосе героини и поверх фона, **поле не сжимают и не сдвигают**.
- **Плитка:** ≥64 px при базе 720 (≥8,9% ширины; ≥96 px на 1080); ползунок размера **S/M/L/XL** (M = 64, L = 72, XL ≥ 80 px) — в **Пути, Тройках и Классике** (не только в Классике); уровни Пути авторятся на ≤11 колонок при M; раскладки Классики с большим числом колонок при XL получают панорамирование (только Классика). Контраст свободной и заблокированной плитки ≥4,5:1, заблокированная не темнее 65% яркости свободной; **один набор граней** (классические 萬筒索, ветры/драконы, цветы/сезоны для Классики) во всех режимах; опция «высокий контраст» и метки для дальтоников (символ в углу).
- **HUD:** `HIT_TARGET_MIN` **96 px**; Отмена/Подсказка/Перемешать 112 px; **без счётчиков на кнопках** (Отмена/Перемешать безлимитны; текущая сборка v10 показывает 2/1 — ворота QA «нет цифр на Отмене и Перемешать»).
- **Минимум:** переключатель сворачивает героиню в медальон 160 px (по умолчанию в Классике, Связях, Саду).
- **Субтитры в партии:** шрифт без рукописного начертания, 36 px при базе 720 (§7.4), строка у плеча героини.
- **Игра без звука:** визуальные заменители аудио-сигналов (пульсация последней свободной ячейки вместо `tray_heartbeat`, цветной контур при комбо, подпись SFX опционально).

### 7.3 Фоны (владелец просил «меняющиеся фоны») [КР: art]
Фон в партии/Столе = выбранная зона Салона или фон стола. Объём: **10 зон Салона** (по числу героинь в билде), **12 фонов Коикои** (по месяцам, только режим Коикои), **24 фона стола «без героини»** = 4 сезона × день/ночь × 3 темы (Чайный дом, Сад-бамбук, Город-ночь), генерация окружений через LoRA `tw_master_v1` с AD-проходом (сильная сторона LoRA, `LORA`). Открытие: 6 с начала, 8 играми (Сад: Спокойствие, дорожка, события), 4 рангом «Бамбука», 6 — только «Пасьянс+». Наборы тайлов (4: Бамбук, Лак, Нефрит, Ночь) — рамка и материал, грани стандартные и проходят контраст §7.2. Время суток и сезон подставляются автоматически (настройка «Автофон» вкл по умолчанию). Фон не занимает центр поля: контраст граней — §7.2.
