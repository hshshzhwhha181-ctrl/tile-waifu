# Параллельная работа 6 агентов Gemini (Antigravity)
Каждый агент = отдельный разговор Antigravity + СВОЙ git worktree (не делите одну рабочую папку!):
`git worktree add ../tw-<роль> -b claude/ext-<ID> origin/claude/ext-base` (для стека — от ветки предыдущей задачи).
Godot импортирует проект в `.godot/` отдельно для каждого worktree — это нормально (диск и первый запуск медленнее).

## Правила для параллельных агентов (обязательно)
1. Один агент — одна ветка за раз; не пушить в чужие ветки.
2. НЕ редактируйте общие файлы (реестры модулей, `tools/tw_test.py`, `project.godot`, общий STATUS). Если нужна регистрация — напишите точную строку в раздел «Нужна регистрация» своего отчёта, Claude добавит при слиянии.
3. Статус каждого агента в `design/ext/reports/STATUS_<G#>.md` (не в общий файл).
4. Новые файлы создавайте в своих каталогах (battle — `game/core/modes/battle/`, `data/battle/`; legal — `data/legal/`, `game/shell/screens/legal/`; и т.д.). Пересечение файлов с другим агентом = остановись и запиши в BLOCKED.
5. Нагрузка: не запускайте полный `tw_test.py` чаще, чем после каждого завершённого пункта критериев; тяжёлые прогоны — по одному на машине (Godot headless жрёт CPU).
6. Уровни усилий: G1, G2 — Neon xHigh; G3, G4, G6 — Neon High; G5 (тексты) — Neon Medium/High.
