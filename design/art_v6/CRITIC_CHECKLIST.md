# CRITIC_CHECKLIST: критерии приёмки кадра (art factory v6)

Версия 2026-11-28 (ветка `claude/art-recipe`). Основание: решение владельца о пропорциях (`PROPORTIONS_OWNER_BINDING.md`), отзывы владельца 26-30, `defects_1..3.json`, `BAKEOFF_VERDICT.md`, `design/ART_TIER_FULL.md` §2, §3a, §3b, §7.

## 0. Как работает критик

* Кадр смотрится **целиком в полном размере** (не на превью), затем кропы: кисти и пальцы, колени и голени, стопы, талия и бёдра, лицо. Шкалы 0.5x (4-up) пропускают дефекты рук и стоп.
* Каждый пункт: **PASS / FAIL / N/A**. Любой FAIL пункта «КРИТИЧЕСКОЕ» (A. жёсткие линии, B. возраст/лицо) = кадр отклонён, без права «потом исправим». Остальные FAIL: кадр отклонён, если FAIL >= 1 пункта уровня **major** или >= 3 пунктов уровня **minor**.
* Приёмка = proportions >= 2 из 3, limbs 3, twist 3, thigh >= 2, naturalness 3, boldness >= 2 (шкала бейк-оффа) и нет FAIL в A и B.
* Результат критика в JSON на кадр: `{"image","heroine","slot","pose_id","pass":bool,"fails":[{"item","severity","where","note"}],"scores":{"proportions":0-3,"limbs":0-3,"twist":0-3,"thigh":0-3,"naturalness":0-3,"boldness":0-3},"est":{"crotch_pct":..,"heads":..,"leg_over_torso_plus_head":..}}`. Оценки пропорций помечаются `eyeball` (глазомер), пока нет разметки точек.
* Критик **не видит** ожидаемый результат до оценки, но знает `pose_id` и класс наряда из `assignments.json` (чтобы проверить скрутку и покрытие).

## C. Пропорции (КРИТИЧЕСКОЕ-major; мерить, где виден весь рост)

Измерение на кадре от макушки до пятки (или до носка на каблуке): `H` = полная высота, `crotch` = линия паха (низ таза / начало бёдер), `leg = crotch -> пол`, `torso = плечо -> пах`, `head` = высота головы.

| # | PASS | FAIL |
|---|---|---|
| C1 линия ноги | `leg / H <= 0.48` (допустимое окно паха: 0.45-0.48 от пола) | `leg / H > 0.48` (больше 0.50 = major, больше 0.54 = критично для пропорций) |
| C2 торс и ноги | `leg <= torso + head`; торс читается как полный блок, **торс не короче ног** | `leg > torso + head`, «ноги от ушей», нога вдвое длиннее торса |
| C3 головность | `H / head` в диапазоне **6.75-7.0** (допуск глазомера +-0.15; вне 6.5-7.3 = FAIL) | вне допуска |
| C4 каблук и перспектива | умеренный каблук (court heel), длина голени и стопы естественна, ноги не крупнее торса из-за ракурса | шпилька, удлиняющая линию ноги; голень или стопа переднего плана больше торса; ноги «к камере» |
| C5 рост через масштаб | высота героини выражена масштабом/кадром, не длиной ног (Yue 7.0 не «длиннее» Rin 6.9 в ногах) | высокая героиня нарисована длинными ногами |
| C6 кроп | если в кадре нет пола/пятки: оценка N/A, но кроп бёдер/колен проверяется по C7 и по D | |

Таблица допусков по героиням (таблица владельца): Yue 7.0, Zlata 7.0, Rin 6.9, MC 6.85, Hana 6.8, Tsubame 6.8, Shirin 6.75, Kohaku 6.75, Nova 6.75, Miel 6.75.
