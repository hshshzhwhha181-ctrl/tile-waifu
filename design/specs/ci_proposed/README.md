# ci_proposed — заготовки workflow (НЕ активны)

Файлы лежат вне `.github/`, поэтому ничего не запускают и не ломают текущий `qa.yml`. Чтобы включить: скопировать в `.github/workflows/`, убрать суффикс `.proposed`, один раз запустить `workflow_dispatch` и убедиться, что зелёное. Описание уровней — `design/specs/UNIFIED_QA_PLAN.md` §17.
- `qa-nightly.yml.proposed` — ночной полный прогон (full tests, длинный soak, аудит палитры всего арта с артефактом-трендом, issue при красном).
- `qa-prerelease.yml.proposed` — ручной пре-релизный гейт (всё ночное + список ручных/устройственных пунктов как проверочные выходы).
Не включено намеренно: `golden-rebaseline` (нужен `TWSkinShot`, §7) и перф на устройствах (нужна ферма/руки).
