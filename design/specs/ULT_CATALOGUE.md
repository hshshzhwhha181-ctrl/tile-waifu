# Каталог ульт (ULT_CATALOGUE)

Файл сгенерирован `design/specs/sim/gen_catalogue.py` из `ult_data_heroes.py` и `ult_data_rows.py`; единственный источник правды — эти два файла, вручную таблицы не править. Машинный вид: `design/specs/ult_catalogue.json` (копия идёт в `game/core/ult/data/ult_catalogue.json`, `BATTLE_ULT_SPEC` §7.3). Правила классов, таймингов, красных линий и палитры — `BATTLE_ULT_SPEC.md` §4–§7.

**Красные линии (во всех строках):** все героини явно взрослые; нет наготы (нет открытых сосков и гениталий, нет контура паха), нет сексуальных актов и жидкостей; нет школьного/детского кода; нет текста и логотипов в арте (печати «東風» и т. п. рисует движок шрифтом); камера не ниже границы подола (§6.2), нет вида под юбку, нет «сканирования тела»; флирт адресован только игроку; золото — только в рамках редкости (`PALETTE_LOCK` U4).

**Ключ.** `id` совпадает с `skin_id` из `SKIN_HUD_SYSTEM.md` §6.2 (58 скинов к месяцу 12; запуск S1 = 38): ульта = кинематограф боя этого скина. Класс: BASE (сигнатурная ульта героини) / VOW (Обет, `*_vow`) / S / SSR / SSR+ (`ssrp`, «Витрина сезона»). Сезон: S1 запуск (m0–2), S2–S3 до m6, S4–S6 до m12 (`SKIN_HUD_SYSTEM` §6.5). `legacy-id` — ближайший наряд в коде (`G.ITEM`, `V9Ults`, `V10W1Ults`), **не 1:1**, только для переноса ассетов. Подол — класс для линтера камеры (`long`, `knee`, `mini`, `pants`, `swim`; §6.2). С, всего = 0,8 триггер + кат-сцена + 0,5 выпуск. Твист T1…T8 — §2.6. Позы/плиты/голос — ключевые позы, видео-плиты, JP-реплики. МБ — вес ульты внутри пака скина (входит в бюджеты `SKIN_HUD_SYSTEM` §1.4/§2.7, отдельно не складывать). Кр — Higgsfield-кредиты **автономно** (до запаса ×1,3); **прирост** — после вычета того, что уже оплачено строками «Ключ-арт» и «Видео-ульта» `SKIN_HUD_SYSTEM` §5.2. Ч — человеко-часы автономно; ч прирост — после вычета строки «Ульта» `SKIN_HUD_SYSTEM` §5.3.

**Вне каталога:** новые героини (по GDD — одна «Новая гостья» за сезон) не входят в 58 скинов; каждая добавляет `<hero>_base` + `<hero>_vow` (≈ +143 кр и +61 ч на героиню) — решение OD-14.
