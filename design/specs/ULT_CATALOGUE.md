# Каталог ульт (ULT_CATALOGUE)

Файл сгенерирован `design/specs/sim/gen_catalogue.py` из `ult_data_heroes.py` и `ult_data_rows.py`; единственный источник правды — эти два файла, вручную таблицы не править. Машинный вид: `design/specs/ult_catalogue.json` (его же копирует игра в `game/core/ult/data/ult_catalogue.json`, `BATTLE_ULT_SPEC` §7.3). Правила классов, таймингов и красных линий — `BATTLE_ULT_SPEC.md` §4–§7.

**Красные линии (во всех строках):** все героини явно взрослые; нет наготы (нет открытых сосков и гениталий, нет контура паха), нет сексуальных актов и жидкостей; нет школьного/детского кода; нет текста и логотипов в арте (печать «東風» и т. п. рисуется шрифтом движка, не запечена в арт); камера не ниже границы подола (§6.2), нет вида под юбку, нет «сканирования тела»; флирт адресован только игроку.

**Статус id:** `launch` — релиз 1.0; `m6` — к 6-му месяцу; `m12` — к 12-му (план А: GDD §10.3, +1 SSR-«флагман», +3 S и +1 героиня за сезон). **ID наряда — предложение**, пока нет `SKIN_HUD_SYSTEM` (ветка `claude/spec-skin` на момент написания в origin отсутствует); колонка `legacy-id` — id в коде (`G.ITEM`, `V9Ults`, `V10W1Ults`), для миграции. Если спека скинов переименует наряд, меняется только колонка id и таблица соответствия, правила не меняются.

**Колонки:** класс — BASE (сигнатурная ульта героини) / VOW (Обет) / S / SSR / FLAG (SSR-флагман сезона); подол — класс подола для линтера камеры (`long`, `knee`, `mini`, `pants`, `swim`); с, всего — 0,8 с триггер + кат-сцена + 0,5 с выпуск; твист — риддер ульты T1…T8 (§2.6); позы/плиты/голос — ключевые позы кат-ина, видео-плиты, JP-голосовые реплики; МБ — вес пака одной ульты; кр — кредиты Higgsfield до запаса ×1,3; ч — человеко-часы.
