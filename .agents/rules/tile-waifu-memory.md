# Память проекта Tile Waifu (Antigravity Rules)

Этот файл переносит оперативную память агентов из сессий Claude и `docs/HANDOFF.md` в систему правил Antigravity. При работе с проектом всегда соблюдать иерархию источников правды.

## 1. Иерархия документов (при конфликте побеждает верхний)
1. **Красные линии и прямые решения владельца** (`docs/HANDOFF.md` §1, `docs/HEROINES.md`).
2. **`docs/UX_RULES.md`** — конституция всего, что видит и слышит игрок (5 вкладок, бюджеты экрана, запретный жаргон, правила цен, иерархия кнопок). Любое «нет» в чек-листе P0 (§10) блокирует вливание.
3. **`docs/HUD_V2.md`** — дизайн-система «Тишина и лак» (`V10DS`, `V10Plate`, `V10Button`, `V10HudHome`, `V10HudMatch`, `V10ComboShowcase`), заменяет старый HUD 0.9.
4. **`docs/INTEGRATION_0.10.md`** и **`docs/0.10-spec.md`** — карта слияния W1–W4, контракты данных, `V10Hooks`, `V10Registry`, `V10Money`, `SAVE_VER = 8`.
5. **`docs/STYLE_SYSTEM.md`**, **`docs/ART_DIRECTION_v2.md`**, **`docs/LEGWEAR.md`**, **`docs/POSES.md`**, **`docs/AUDIO_BIBLE.md`**, **`docs/VIDEO_BIBLE.md`**, **`docs/MODES.md`**, **`docs/ADVENTURE.md`** (спека 0.11), **`docs/CEO_PLAN.md`** (план 1.0 RuStore).

## 2. Режим работы и критерии владельца
- Отвечать по-русски, коротко, по делу, без воды.
- Автономный режим одобрен владельцем: использовать субагентов, параллельные дорожки и проверки без лишних переспросов.
- Главный критерий приёмки: **«всё приятно нажимается, гармонично и дорого»** (`V9Feel.press`, `V10Juice`, соблюдение `S.fx_level` и `a11y_calm`, без белых вспышек).
- Площадки: **1.0 = RuStore (APK)** без жёсткой экономии размера; **1.1 = Яндекс Игры** (отдельный облегчённый SFW веб-пресет ≤100 МБ без `bold`/`legwear_apk`).
- Юридический нюанс 1.0 (из личной памяти владельца): владелец и соавторы не открывают ИП/ООО лично (статус военнослужащих) — ООО/ИП под RuStore Pay и Яндекс Игры оформляется через супруг с договором и равными правами/переходом прав между тремя соавторами и регистрацией ПО в Роспатенте.
- ИИ-соперники в лигах 0.10 — без метки (в 1.0 перед коммерческим релизом сверить с `CEO_PLAN.md` §5). Свободных чатов между игроками без сервера и модерации нет.

## 3. Неприкосновенные красные линии контента (17+ / 18+)
- Все героини — взрослые (20+), со взрослыми пропорциями лица.
- Никакой наготы, сексуальных действий, камеры на пах или раздвинутых ног к камере, никакой школьной темы / «учитель–ученик».
- Никаких чужих ассетов/картинок (включая Brown Dust 2) в референсах и датасетах LoRA.
- Привлекательность уровня BD2 достигается взглядом, пластикой живого рига (`Skeleton2D` + `Polygon2D`), чулками по каталогу `LW01…LW87` (`docs/LEGWEAR.md`) и голосом.
- Каждый сгенерированный арт обязан проходить строгий аудит анатомии (счёт рук/ног/пальцев по кропам, отсутствие текста, взрослое лицо, совпадение узора чулок на обеих ногах).

## 4. Higgsfield и генерация контента
- Считать расход по журналу транзакций Higgsfield (на момент переноса оставалось **~507 кредитов**). До пополнения баланса не запускать тяжёлое GPU-обучение (`tw_master_v1`), держать фокус на коде, интеграции, ригах и точечных ассетах.
- Персонажи в `gpt_image_2_6`: передавать character element ID `<<<id>>>` из `docs/STYLE_SYSTEM.md` §1 (основательницы + 5 героинь волны 1).
- Боевые веса LoRA уже обучены и сохранены в бэкапе (`tw_heroines_v2b` — `twaifu4 style`, `tw_ui_v1` — `twui style`; ссылки в `docs/STYLE_SYSTEM.md` на `gh-pages` / `claude/project-thread-ugde4m`).
- Живая анимация героинь на экранах — только через **риг** (`V10LiveRig`, ≤1 риг и ≤1 видеоплеер на экран).

## 5. Тулчейн, тесты и сборка Godot 4.5.1
- Проект Godot лежит в `game/`. Горячие файлы (`g.gd`, `main.gd`, `play.gd`, `home.gd`, `tray_board.gd`, `collection.gd`, `project.godot`) правит только интегратор короткими хуками.
- Обязательные гейты перед любой сборкой:
  1. Базовые самотесты (`selftest`, `event_selftest`, `league_selftest`, `profile_selftest`, `recovery_selftest`, `ults_selftest`, `letters_selftest`) + `--fuzz=3`.
  2. Модульный раннер `--v10_selftest=all`.
  3. Экспорт `.pck` (`--export-pack Android` / `Android-test` / `Android-store`, `exclude_filter=""` — никогда не исключать `*selftest*`!) и прогон `--main-pack` с `--pt=fresh` → `PT OK`.
- Release keystore (`CN=Tile Waifu`, alias `tilewaifu`) никогда не коммитить в Git. APK (>100 МБ) в Git не класть.
