# Салон Пяти ветров (0.10, M2 — спека §Р1–Р2)

Дорожка `salon`, ветка `v10-salon`. Всё живёт в `game/scripts/v10/salon/` и `game/assets/v10/salon/`;
горячие файлы не тронуты — подключение одной-двумя строками (раздел «Хуки» ниже).

## Что это для игрока
* **Карта салона** (`v10salon`): зоны снизу вверх (z1 внизу), над ними **один** закрытый тизер (следующая зона
  или «Следующая зона откроется с аркой 2» без таймера). Шапка одна: «назад» · «Салон» · банк ★ (нажатие — что это
  и что звёзды не продаются). Внизу всегда «Играть · уровень N» и «ещё 4★ до „Фонари у входа“».
* **Бирки** на нитях над каждой невосстановленной вещью: «Вывеска · 3★». Качаются от прокрутки; если хватает звёзд —
  золото, мягкое свечение и прыжок раз в 3 с. Первый визит: реплика Маджонг-тян и единственный обязательный
  палец-подсказка на самой дешёвой бирке.
* **Лист задачи** (0,28 с, пружина): «Сейчас → После» (кропы той же картины), отделка Лак / Нефрит +N / Сезонная
  (замок «входит в пропуск сезона», без цены), «Восстановить · 3★» или «Ещё 2 звезды» + «Играть · 57».
* **Восстановление**: звёзды летят из банка по Безье (каждые 60 мс, высота тона растёт), счётчик тикает, облако
  пыли, вещь «падает» на 40 px с пружиной 1,08→1,0, готовая картина растекается из центра вещи (тушь с шумной
  кромкой), блик 0,6 с, искры, вибрация. Туман над зоной редеет с каждой задачей.
* **Финал зоны**: тёплая волна света снизу вверх 0,8 с восстанавливает всё остальное (небо, стены, пол), затем
  церемония: героиня зоны выходит (риг `appear()` или дышащий стоп-кадр), «тук-тук-туууук» + `salon_zone_sting`,
  реплика пером, лента «Новая сцена: Рин за стойкой», сундук — фишки наград каскадом 80 мс с нотами пентатоники,
  «Смотреть сцену» / «Играть · 57». После закрытия над картой открывается следующая зона.
* **Готовая зона**: героиня живёт прямо в зоне (Маджонг-тян — риг V10LiveRig только у видимой зоны; Рин — вырезка
  с шейдером дыхания), тап — реакция и реплика; кнопка «Сцена». Тап по восстановленной вещи — лист отделки.
  Все вещи в нефрите — состояние «Нефрит» (финальное).
* **Сцена зоны** (`v10scene`): шторка 0,35 с; z1/z3 — комната + живой риг Маджонг-тян (тапы, жесты, липсинк),
  z2 — полная картина «Рин за стойкой» с дыханием по маске её вырезки (комната неподвижна). Кнопки 120 px:
  «Реплика» (3 реплики × 4 порога симпатии, без повтора подряд), «Фон лобби» (тост «Теперь она встречает тебя
  здесь»), «Фото». Первый просмотр: +20 симпатии (жёсткий источник) и письмо.
* **Фото**: интерфейс тает 0,25 с, 3 кадра (В рост / По пояс / Портрет), кадр ждёт отрисовку, вспышка — виньетка
  в цвете зоны (не белая), водяной знак «Tile Waifu · ИИ-арт», PNG в `user://photos/` + индекс `S.v10_salon.photos`.
* **Карточка-хаб на главной** (`V10SalonHub`): живая миниатюра текущей зоны (тот же шейдер), «Зона II», кольцо
  4/6, золотая точка «можно восстановить», строка ближайшей цели.
* **Полоса окна победы** (`V10SalonWinBar`): «Салон: «Фонари у входа» 3/4★», полоса заполняется от старого банка.

## Хуки для интегратора (M2)
1. `main.gd` SCREENS: `"v10salon": preload("res://scripts/v10/salon/salon_screen.gd")`,
   `"v10scene": preload("res://scripts/v10/salon/zone_scene.gd")` (или через `V10Registry` по §2.8). Оба экрана
   вызывают `main.show_chrome(false, false)` и кладут `v8_back` в meta (Android «назад»).
2. Сейв: `V10Save.register("v10_salon", V10Salon.defaults())`; `V10Salon.ensure(S)` идемпотентна. Миграция не нужна:
   банк = сумма лучших ★ − spent, игрок 0.9 сразу получает весь запас (интро «У тебя уже 34★…»).
3. Звёзды: после записи лучшего результата уровня Пути — `V10Salon.notify_stars(new_best - old_best)`
   (или на `V10Hooks.game_ended`). Кэш суммы сбрасывается.
4. Главная: `V10SalonHub.make(rect, func(): main.go("v10salon"))` слотом `V10Registry.home_slot("salon", …)`;
   `card.refresh()` на `V10Hooks.app_resumed`. Фон лобби: `V10Salon.lobby_texture()` ("" = обычный фон).
5. Окно победы: `V10WinStack.add_bar("salon", 20, func(ctx): return V10SalonWinBar.build(ctx, w))`, ctx
   `{stars_before, stars_after}`; вторая кнопка «В салон», если `V10SalonWinBar.want_salon_button()`.
   Афиша: строка из `V10Salon.next_goal()` / `hub_info()`.
6. Хуки-колбэки `V10Salon` (статические Callable):
   `grant_cb(rewards, "salon_z1")` → V10Wallet/бустеры (по умолчанию gems → `S.gems`, остальное в `S.v10_salon.inv`);
   `bond_cb(hero, 20, "salon_scene")` (по умолчанию `V10Bond.gain`, если класс есть, иначе очередь `bond_pending`);
   `letter_cb(hero, "salon_scene")` → `V9Letters.queue`; `day_cb` (по умолчанию `V10Meta.day_key()`);
   `season_cb` → пропуск сезона (M4); `level_cb` → номер следующего уровня Пути для «Играть · N».
   «Играть» ведёт в `main.go("levels")` — интегратор может заменить на прямой запуск уровня.
7. Риги: `V10SalonHeroine.RIGS` — когда дорожка `rig_rin` положит `res://assets/v10/rig/rin_qipao/rig.tscn` (или
   `rin_base`/`rin`), Рин в зоне, финале и сцене автоматически станет живым ригом; сцена z2 тогда берёт комнату
   `z2_lobby.webp`. Для z4–z6 (M6) добавить зоны в `ZONES` (арт по рецепту ниже) и героинь в `RIGS`.
8. Звуки: свои `salon_thud`, `salon_sweep`, `salon_zone_sting` (кото + колокол, 4 с), `salon_shutter` лежат в
   `assets/v10/salon/sfx/` (mirelo, −18 LUFS); `salon_star`, `salon_open`, `salon_sheet` — из банка Sfx через
   `SFX_FALLBACK`. Если дорожка audio положит `res://assets/sfx/<имя>.wav`, играет её файл. Всё уважает `S.sound`.
   Статические кэши (шрифты, текстуры FX) сами очищаются на `root.tree_exiting` (`V10SalonUI.arm_cleanup`).
9. Шрифты: `V10SalonUI.font()` — когда влита `V10Fonts`, заменить тело функции на её реестр (Playfair/Nunito те же).
10. Фото: индекс в `S.v10_salon.photos`; влить в альбом (V7Album) и экспорт TWShare в 1.0.
11. `--v10_selftest=all`: зарегистрировать `salon_selftest.gd` (метод `run()` → bool, печатает `SALON_SELFTEST n/n`).

## Рецепт арта следующих зон (z4–z6, M6)
`gpt_image_2_6`, quality xhigh, 2k, 4:3. Сначала «готовая» картина (муted painted, тёплый вечер, раздельные
читаемые предметы с промежутками, без людей и текста), затем «разруха» правкой с image-ref на готовую:
«Keep EXACTLY the same composition… change only its condition: abandoned for years…». Потом 9:16 «лобби» с
image-ref. Прямоугольники задач подбирать `tools/rects.py` (слои: задние → передние). ≈ 3,5 кр за картину.
