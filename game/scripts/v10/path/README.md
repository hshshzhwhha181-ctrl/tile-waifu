# 0.10 · Путь (веха M2: П1 карта, П2 Пики и Легендарные, П3 Огонёк пути)

Ветка `v10-path` (в неё влита `v10-levels` — генератор 1000 уровней). Горячие файлы не тронуты: всё здесь,
подключение — короткими хуками ниже.

## Запуск

```
cd game
# самотест (≈ 1 мин)
XDG_DATA_HOME=/tmp/twx flock /tmp/tw-godot.lock godot --headless --path . res://scripts/v10/path/path_demo.tscn -- --path_selftest=1
# скриншоты (xvfb), пресеты fresh|mid|peaks|legend|arc2
XDG_DATA_HOME=/tmp/twx flock /tmp/tw-godot.lock xvfb-run -a godot --path . --rendering-driver opengl3 --audio-driver Dummy \
  --resolution 720x1280 res://scripts/v10/path/path_demo.tscn -- --shots --path_state=mid \
  --path_shots=/tmp/shots --path_seq=map,card,close,card_peak,close,arcs,close,assist,close,fail_peak,close,chest,won
```
`XDG_DATA_HOME` — чтобы раннер не трогал сохранение игрока (`user://`). `--shots` без значения — чтобы main не показывал заставку.

## Правила (сверено с 0.10-spec)

- Основная линия = все уровни, кроме Пиков. `S.unlocked` считает её (Пики не на пути). Пик (`V10LevelGen.is_peak`,
  позиция 8 главы с «Очень сложным») — боковая скала, открывается после босса главы. Генератор ставит первые Пики
  с главы 4 арки 1 (спека говорила «с главы 7») — оставлено как в генераторе.
- Выпущены арки 1–2 (уровни 1–200), `ARCS_RELEASED`. Арки 3–10 видны силуэтом в шторке без таймера.
- Кристаллы Пути — только первое прохождение: `reward.gems + per_star×★`, за новую звезду при переигровке
  `+per_star`, не больше 15 побед в сутки (метка «Полная награда сегодня» — с 10-й). Пик — 30 за первую победу,
  Легендарный — 150 + лавр, конец арки — 1 билет (один раз, и при обходе). Сундук главы — 20 кр + 100 монет,
  звёздный (25★/30) — 40 кр + 10 Лепестков. Осколков нет.
- Подстройка: после 2 провалов подряд (не на Пиках и Легендарных) хозяйка предлагает облегчённую раздачу
  `V10LevelGen.build(i, -1, null, true)`; звёзды сохраняются. Решение зависит только от провалов и уровня
  (самотест подменяет кристаллы/траты и сравнивает).
- Легендарный: после 5 провалов «Обходная тропа» открывает дальше, лавр — только за победу, корона пустая.
- Огонёк пути: победа +1 ступень (до 3), провал −1. Ступень N даёт N бустеров даром (Фонарик → Ветер → Свиток).
  На Пиках, Легендарных, Очень сложных и в режимах `peak/legend/pagoda/wander/ranked/palm/duel_ranked/challenge`
  кружки серые «Здесь только честная игра», огонёк там не меняется.

## Хуки для интегратора (горячие файлы правит только он)

1. **main.gd**: `SCREENS["v10path"] = preload("res://scripts/v10/path/path_map.gd")`; вкладка «Партия» → `go("v10path")`
   вместо `levels` (или через `V10Registry.screen`). `switch_arc` сам вызывает `main.go("v10path", {arc})`, если экран зарегистрирован.
2. **Старт партии**: карта зовёт `main.go("play", {"level": i, "v10_cfg": cfg})`. В `play.gd::build` —
   `if args.has("v10_cfg"): cfg = args.v10_cfg` (уже `V10LevelGen.build`, с `assist`, `mode` = ""/"peak"/"legend",
   `no_paid_help`, `v10_boost`, `extra_hints`, `v10_wind`). Доска — `V10LevelBoard` (README v10-levels, п.2).
3. **После раздачи** (`play.gd`, когда доска готова): `V10PathBoosters.apply_board(board, cfg)` — Фонарик раскрывает,
   Ветер тихо снимает 2 пары (без `matched`, комбо не растёт, цепи/ключи засчитываются). `cfg.extra_hints` прибавить к подсказкам.
4. **Победа** (`play.gd` / `V10WinStack`): `var r = V10PathState.on_win(i, stars, ms)`; затем
   `V10PathBoosters.on_win(cfg.mode, cfg.tier, cfg.peak)`. Кристаллы уже начислены (`r.gems`, `r.grants`) — старую
   формулу `reward.gems + stars*20` для уровней 0.10 не применять. Если `r.summit` — `V10PathDialogs.win_peak(main, r)`.
   Возврат на карту: `main.go("v10path", {"won": {"i": i, "stars": stars}})` — проиграет анимацию пути и маркера.
   `r.chests` — какие сундуки стали готовы (на карте они подпрыгивают).
5. **Провал**: `var r = V10PathState.on_fail(i)`; `V10PathBoosters.on_fail(...)`;
   `var jam = V10PathJam.find(cfg, log)` где `log` — индексы снятых игроком фишек по порядку (копить в play.gd из
   тапов доски / `V10Hooks.pair_taken`); окно: `V10PathDialogs.fail_window(main, i, r, jam, retry, to_map, show_jam)`,
   `show_jam = func(j): V10PathDialogs.show_jam_on_board(board, j)` (кольцо 2 с). На Пиках/Легендарных это окно
   заменяет стандартное (там нет платных кнопок); на обычных уровнях его можно показать вместо или добавить блок затора.
   `retry` при `r.offer_assist` сначала показывает диалог хозяйки.
6. **Сохранение**: ключи `S.v10_levels`, `S.v10_boosters` создаются лениво (`V10PathState.st()`, `V10PathBoosters.st()`).
   При влитом M1 — зарегистрировать дефолты в `V10Save.register("v10_levels", {...})` и `("v10_boosters", {...})`.
   `S.unlocked`/`S.stars` — старые ключи; миграцию 48 → 1000 решает интегратор (предложение в README v10-levels).
7. **Кошелёк/косметика/время**: `V10PathState.grant` идёт в `V10Wallet.add(key, n, src)`, покупка бустера —
   `V10Wallet.spend("gems", 60, src)`, лавры и рамки — `V10ProfileCos.unlock(id, "path")`, сутки — `V10Meta.day_key()`;
   пока этих классов нет, работает запасной счётчик в `S` (только для автономного запуска; при интеграции классы есть).
   ID косметики: `laurel_arc1…10`, `frame_rising_1…10`.
8. **Самотест** в `V10Registry`: `--v10_selftest=all` → вызвать `path_selftest.gd` (`run()` → `[ok, total]`).

## Открыто
- Расхождение имён арок: спека — «Арка 2 Фестиваль фонарей (101–200)», генератор — мир 2 «Чайная во льду», мир 3
  «Фестиваль фонарей». Карта следует генератору (`V10LevelGen.WORLD`), подписи арок — `V10PathRules.ARC_TITLES`.
- Механики «Туман» (145) и «Фонарь-срок» (185) в генераторе отсутствуют (там свой ритм вводов); в карточке имена есть.
- Фоны глав — карты 0.6 (`assets/v06/map/w1..w6`), для арок 7–10 по кругу. Обложки арок 7–10 не генерировались
  (арки не выпущены, в шторке силуэт плашкой).
