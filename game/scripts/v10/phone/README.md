# v10/phone — «Телефон»: Лента · Чаты · Почта (0.10, веха M3, §Р8–Р9)

Ветка `v10-phone` (от `gh-pages`, в неё влита `v10-chat`). Новые файлы только в `game/scripts/v10/phone/` и
`game/assets/v10/phone/`; существующие файлы не правились — точки встраивания ниже.

## Что это
Игровой лакированный телефон (не имитация Android), выезжает снизу пружиной 0,4 с поверх главной.
- **Вкладки** Лента / Чаты / Почта: тап или свайп, золотой индикатор едет пружиной, у каждой вкладки свой бейдж.
- **Чаты**: список (аватар-эмоция в кольце, имя её почерком, последняя строка, пульсирующая точка, партнёр закреплён;
  героини без переписки — «Скажи привет стикером»). Диалог: все её ветки подряд с разделителями-заголовками,
  «печатает…» (0,4 с + 35 мс/символ, ≤ 2,2 с, тап ускоряет) с точками-волной и тихими «тиками», пузырь растёт
  из хвостика пружиной + «тинь» + лёгкая вибрация + подпрыгивание аватара; фото (тап — на весь экран), голосовое
  2–4 с (волна-прогресс, «липсинк» аватара, расшифровка под волной); ответ — 2–3 пилюли или стикер; долгое нажатие
  на её пузырь — 6 реакций (она отвечает ≈30%); завершённая ветка — «Разговор окончен» + фишка «♥ +N».
- **Стикеры**: лоток выезжает снизу, вкладки «Общие» + каждая героиня (её — первой), закрытые — серые
  «Симпатия 5» (без цен). Стикер прыгает в чат, она отвечает (≤3 в день, без симпатии).
- **Лента**: карточки (лицо, имя почерком, дата «вт, 3 дек», фото, подпись ≤280), комментарии других героинь
  появляются через 0,8 с, двойной тап по фото — большое сердце + 16 сердечек + вибрация + pop, «Нравится» (+1, раз),
  две пилюли-реплики → её ответ через 1 с (+2, раз). Никаких чужих счётчиков, цен и «Призвать».
- **Почта**: письма 0.9 (`V9Letters`, правила не тронуты) в стиле телефона; письмо — страница с бумагой, подписью
  почерком, P.S., двумя пилюлями и её ответом-пузырём. «Записки и сцены» — ссылкой на старый экран `letters`.
- **«Как ей тебя звать?»**: 120 имён с готовой звательной формой (`names.gd`), переключатель «он/она» (род в её
  репликах `{g:…}`), «Не называть» → «мастер стола». Свободного ввода нет.

## Хуки для интегратора (M3)
1. **Сейв**: `V10Save.register("v10_phone", V10Phone.default_state())` и `V10Save.register("v10_feed", V10ChatFeed.default_state())`
   (у `v10_phone` добавлены ключи `name`, `named`, `tab`, `recent_st`, `intro` к `chat` из v10-chat). `V10Phone.ensure()`
   идемпотентно дополняет ключи и сам по себе, если M1 ещё не влит. После `G.load_game()`/восстановления транспорт
   пересоздаётся сам (`V10Phone.transport()` сверяет ссылку на `S.v10_phone.chat`).
2. **Главная (home.gd)**: кнопка «Письма» → «Телефон»: готовый виджет `V10PhoneButton.make(main, rect)` (бейдж
   `V10Phone.badge()`, `refresh()` на `home_built`/`day_rolled`); нажатие — `V10Phone.open(main, {})` (оверлей поверх главной). `open_mail()` → `V10Phone.open(main, {"tab": "mail"})`,
   конкретное письмо → `{"letter": id}`, чат героини → `{"hero": "rin"}`.
   Если нужен экран: `main.SCREENS["phone"] = preload("res://scripts/v10/phone/phone_screen.gd")` (или через `V10Registry`).
3. **События (V10Hooks)**: `game_ended` → `V10Phone.event({kind="first_win"})` / `{kind="combo_record", combo=N}` /
   `{kind="rank_up", rank=…}`; возвращение — `{kind="comeback", days=gap}`; гардероб — `{kind="outfit", outfit=id,
   outfit_name=…}`; `app_resumed` и `day_rolled` — `V10Phone.tick()`. Затем `G.save()`.
4. **Симпатия**: всё идёт через `V10Phone.gain()` → `V10Bond.gain(h, n, src)` (src `chat`→`chat_branch`, `feed_like`,
   `feed_reply`). Пока `v10/meta/bond.gd` не в сборке, симпатия не начисляется (никаких прямых `G.add_aff`).
   Ответ на письмо 0.9 по-прежнему внутри `V9Letters.reply` (`G.add_aff`) — перевести на `V10Bond` в M1 (`letter_reply`).
5. **День**: `V10Phone.day_info()` берёт `V10Meta.day_key()/day_index()`, когда `v10/meta/meta.gd` в сборке; до этого —
   локальные сутки с 04:00 (через `Time.get_datetime_dict_from_system`, grep-запреты §2.5 не нарушаются).
6. **Самотест**: `V10Registry`/`main.gd`: `--phone_selftest=1` → `await V10PhoneSelftest.run(main)` (нужен узел в дереве).
7. **Шрифт**: при вливании `v10-fonts` подхватывается `res://assets/v10/fonts/caveat/caveat-600.woff2` автоматически.
8. **Стикеры**: арт лежит в `assets/v10/phone/stickers/<id>.webp`; поле `img` в `data/v10/chat/stickers.json`
   (`assets/v10/stickers/`) не используется — `V10Phone.sticker_path(id)` ищет в папке телефона.
9. **Музыка вкладки** «Телефон» (дорожка v10-audio): включить в `phone_screen._build` через `Sfx.music("phone")`.
10. **Android «назад»**: у оверлея есть мета `v8_back` (main.android_back её вызывает): закрывает по слоям.

## Открытые вопросы
- Ответ на письмо 0.9 даёт +5 мимо Bond (см. п.4) — правит владелец `letters.gd` в M1.
- Голосовые без звука голоса (озвучки фраз нет): волна + липсинк + расшифровка. Озвучка — дорожка v10-audio.
- Премиум-паки стикеров (Лавка M4) — не входят; лоток готов принять пакеты как новые вкладки.
