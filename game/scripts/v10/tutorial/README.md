# V10Tutorial — обучение, подсказки и «Как играть» (дорожка v10-tutorial)

Маджонг-тян ведёт новичка за руку по первой игре, при первом открытии каждой фичи коротко объясняет «что это и за
что отвечает», а энциклопедия «Как играть» хранит всё это с иллюстрациями. Всё в этой папке и в
`game/assets/v10/tutorial/`. Горячие файлы (`main.gd`, `play.gd`, `home.gd`, …) дорожка **не трогала** — ниже
точный список хуков для интегратора.

## Файлы

| Файл | Класс | Что делает |
|---|---|---|
| `tutorial.gd` | `V10Tutorial` (Node) | Рантайм: следит за `main.screen_id`/`main.screen`, ведёт главы обучения, показывает подсказки (не больше одной за визит экрана), предикаты шагов, динамические цели (фишки стола, окно победы), подарок «первое желание» |
| `coach.gd` | `V10Coach` | Коуч-марк: затемнение с мягким вырезом (шейдер `spotlight.gdshader`), дышащий золотой ободок, указатель-стрелка с «тапом», пузырь с портретом-эмоцией МТ, печать текста, счётчик шагов «3 / 12» с точками, «Пропустить обучение» с подтверждением, «Дальше» по таймауту |
| `tut_target.gd` | `V10TutTarget` | Поиск цели: meta-id → свойство экрана → NodePath → текст → текстура → dyn → доли экрана / px от краёв; список = фолбэки; цель пересчитывается каждый кадр (ресайз, анимация) |
| `tut_steps.gd` | `V10TutSteps` | Данные глав: первая партия, победа, Чайная, первое желание, Гардероб, ульта |
| `tut_tips.gd` | `V10TutTips` | Данные 28 тем: подсказка при первом открытии + текст энциклопедии + иллюстрация |
| `tut_state.gd` | `V10TutState` | Прогресс в сейве `S.v10_tut` (идемпотентный `ensure`) |
| `help_screen.gd` | `V10Help` | Экран «Как играть»: карточки с артом, фильтр разделов, лист темы, «Показать в игре», «Обучение заново», «Крупный текст», «Подсказки на экранах», «Показать снова» |
| `tut_selftest.gd` | `V10TutSelftest` | Самотест данных/ссылок/моков/состояния |
| `test/tut_test.tscn` | — | Полный прогон первого запуска на **реальных экранах** с реальными касаниями + скриншоты |

Арт: `game/assets/v10/tutorial/*.webp` (24 иллюстрации 512²; темы `today`, `flame`, `challenge`, `constellation` пока берут арт `events`, `path`, `duels`, `gacha` — своё в проходе качества, gpt_image_2_6, без людей и текста; job id — `jobs.tsv`).
Портреты — существующие `assets/v08/emotions/mc_{happy,shy,surprised,pout,sad}.webp`.

## Сейв

`S.v10_tut = {v, step, chapters{}, skipped, tips{}, tips_off, large, gifts{}}`. Добавляется `V10TutState.ensure()`
(идемпотентно, чинит типы). Игрок 0.9 с `S.tut_done = true` автоматически получает `chapters.match1 = true`.
Конец главы `match1` ставит `S.tut_done = true` (старый код 0.9 видит обучение пройденным).
Если в M1 появится `V10Save.register`: `V10Save.register("v10_tut", V10TutState.DEFAULTS)` — или просто вызвать
`V10TutState.ensure(S)` в миграции. Подъём `SAVE_VER` не нужен.

## Хуки интегратора (точный список)

### main.gd
1. **`_ready()`**, последней строкой (после `go("home", …)`, `_splash()`, `_dev_args()`):
   ```gdscript
   V10Tutorial.attach(self)
   ```
   Больше в main ничего обязательного: смену экранов рантайм видит сам (опрос `screen_id`/`screen` каждый кадр).
2. **`settings()`** — строка «Как играть» (над версией) и событие для подсказки про эффекты:
   ```gdscript
   # popup высотой 1060 вместо 990; строка под «Тайники…» и версией
   var hb: = JButton.make("Как играть", "glass", Rect2(34, 980, 592, 60), V8Art.icon("help"), 22)
   hb.pressed.connect(func():
       Common.close_popup(p)            # UX_RULES §3.7 / П-6: окно поверх окна запрещено
       V10Help.open(self))
   p.add_child(hb)
   V10Tutorial.event("settings")      # в конце settings()
   ```
3. (по желанию) `SCREENS["v10help"] = preload("res://scripts/v10/tutorial/help_screen.gd")` — если нужен экран
   в истории «назад». По умолчанию `V10Help.open(main, topic)` — оверлей поверх чего угодно (meta `v8_back` для
   Android «назад» уже стоит).

### play.gd
1. **`_intro()`**, вместо `if tut: … _tutorial()`:
   ```gdscript
   if tut and not V10Tutorial.owns_first_match():
       await get_tree().create_timer(1.4).timeout
       _tutorial()
   ```
   (иначе старый палец 0.9 рисуется поверх коуч-марок).
2. Ничего больше: стол, лоток, кнопки, портрет, окно победы читаются через свойства `board`, `board_rect`,
   `tray_box`, `btn_hint/undo/shuffle`, `stage`, `skill_ready`, `ult`, `victory_next_btn`, `lvl`, `mode`.
   Если `V10WinStack` заменит окно победы — пометить узлы: `set_meta("tut_id", "win.stars" | "win.rewards" | "win.next")`.

### home.gd
Ничего обязательного (цели: `play_btn`, `modes_btn`, `side_btns.*`, `main.navbar`, `main.prof_root`).
Рекомендуется: `hero`/арт героини → `set_meta("tut_id", "home.hero")` (сейчас фолбэк — доля экрана).
Ритуалы (дорожка rituals): чипу серии чая `set_meta("tut_id", "rituals.streak")`, подносу `"rituals.tray"` —
подсказка «Ритуалы» включится сама, когда чип появится на главной.

### summon.gd / collection.gd
Ничего обязательного (`pull1_btn`, `pity_lbl`, `seq`, `showcase`, `flipping`; навбар). Дорожке gacha:
`"gacha.pull1"`, `"gacha.rates"` (кнопка «Шансы»), `"gacha.candle"` (Свеча желаний). Гардероб: `"coll.heroes"`
(ряд героинь), `"coll.outfits"` (лента нарядов).

## Как это работает

**Главы** (`tut_steps.gd`), порядок = приоритет: `match1` (первая партия: стол → свободная фишка (принудительно,
палец) → лоток → её пара → заблокированные → «лоток на N мест» → комбо (ещё пара) → портрет и ульта → подсказка →
отмена → перемешать → «дальше сам»), `victory1` (звёзды → награда → «Ещё уровень»), `home1` (героиня, левая колонка,
«Сесть за стол», «Режимы», вкладки, профиль, где справка), `summon1` (с 4-го уровня: «первое — за мой счёт» +
подарок, шансы, при баннере «Первый гость» (там только ×10) — шаг «открой соседнюю вкладку», «Загадать ×1»; палец никогда не ведёт на ×10; во вкладку героинь), `wardrobe1`, `ult1` (на 2-м/3-м столе, когда шкала полна: тапни
портрет — «приём»). У главы `need` (когда положена) и `when` (когда стартует на своём экране); `entry` — шаг-мостик с другого
экрана (например, после убийства приложения посреди первой партии на главной — «Наша партия не доиграна»).

**Режимы шага:** `tap` — прочитать, тап где угодно (всё остальное заблокировано); `do` — проходит только тап в
вырезе, промах — мягкий отказ (указатель вздрагивает, V9Feel.deny), шаг кончается по предикату `done`;
`wait` — ничего не видно, ждём предикат. У каждого `do` есть `timeout` → чип «Дальше»; если цель не найдена —
шаг сам становится `tap`. Пропуск всего — «Пропустить обучение» → подтверждение.

**Возобновление:** `S.v10_tut.step` пишется при каждом шаге; после убийства приложения глава продолжается с
`resume`-точки (партия не восстанавливается, поэтому шаги стола возвращаются к «Это стол»).

**Подсказки:** при входе на экран (через 0,9 с) — первая невиданная тема этого экрана, если на нём нет шага
обучения и не открыт другой коуч-марк. Одна за визит, отмечается при показе. Выключаются в «Как играть».

**Доступность:** «Крупный текст» (×1,22) в «Как играть»; если дорожка look добавит `S.text_large`/`S.text_scale` —
уважаются. Все размеры от `get_viewport_rect()`, вырез и пузырь пересчитываются каждый кадр и на `size_changed`.
Эффекты подчиняются `S.fx_level` (дыхание выреза и кольца — только при `can_fx()`); все нажатия — V9Feel.

## Самотест

```
flock /tmp/tw-godot.lock /opt/tw-tools/godot --headless --path game res://scripts/v10/tutorial/test/tut_test.tscn -- \
    --save=user://tut_test.json --save_wipe=1                       # данные + реальный прогон
    ... --tut_static=1                                              # только данные/моки/состояние
flock /tmp/tw-godot.lock xvfb-run -a /opt/tw-tools/godot --path game res://scripts/v10/tutorial/test/tut_test.tscn \
    --rendering-driver opengl3 --audio-driver Dummy --resolution 1080x2400 -- --save=user://tut_test.json \
    --save_wipe=1 --tut_shots=/tmp/tut_shots                        # + скриншоты каждого шага
```
Печатает `V10TUT ok/total`, код выхода 1 при любом провале. Проверяет: каждый шаг/глава/тема корректны, все
предикаты и dyn-цели существуют, у каждого принудительного шага есть выход, свойства, которые читают данные,
есть в реальных `play.gd/home.gd/summon.gd/collection.gd/main.gd`, каждая цель находится на мок-экране с
заявленным хуком и фолбэки работают без хуков; затем бот проходит весь первый запуск на настоящей игре
реальными касаниями (включая проверку, что тап мимо выреза не доходит до игры), подсказки (одна за визит, один раз,
выключение), «Как играть», возобновление после «убийства» приложения, «Пропустить обучение», вырез/пузырь
после ресайза.

## Названия (UX_RULES §4.2)

Реплики и справка уже на словах 0.10: «приём» (не «ульта»), вкладка «Героини» (не «Гардероб»), «Столы» (не «Режимы»),
«События» (не «Ивенты»), «героиня» (не «богиня»), «редкость» наряда. Названия вкладок в репликах берутся из настоящего
навбара (`{tabs}`, `{tab:<id>}` в `V10Tutorial.fill`), поэтому строки верны и до, и после переименования вкладок.
Цели по тексту держат оба варианта («Сесть за стол» / «Играть», «Режимы» / «Столы»). Самотест ловит запретные слова.
Пока интегратор не переименовал «Вставки ульт» в настройках, подсказка про эффекты говорит «вставки приёмов» без кавычек.
