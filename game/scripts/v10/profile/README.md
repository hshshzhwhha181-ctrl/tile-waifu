# v10/profile — Профиль 2.0: карточка игрока и реестр косметики

Ветка `v10-profile`. Спека: `docs/0.10-spec.md` §2.7, §D5, §D6. Только новые файлы, горячие файлы 0.9 не тронуты:
всё подключается хуками ниже.

## Что здесь

| Файл | Класс | Что делает |
|---|---|---|
| `cosmetics.gd` | `V10ProfileCos` | **Единственный реестр** рамок, титулов, значков и фонов карточки (§2.7). Каталог, условия открытия, подсказки «откроется …», выбор и санация `S.profile`, выдача (`grant`) и «новое» (`unseen`/`mark_seen`), `register()` для других модулей |
| `feats.gd` | `V10Feats` | 40 достижений (чистые проверки по контексту), счётчики `S.v10_feats.stats` (`bump`, `best`). Ни одного достижения за траты |
| `card_payload.gd` | `V10CardPayload` | Данные карточки для других: `mine(S)`, `validate()` (≤2 КБ, тот же код уйдёт на сервер), `sim(rng, tier)` — карточки симулированных соперников без платного и без SSR |
| `card_view.gd` | `V10CardView` | Рендер карточки деревом Control на ките 0.8: `make(payload, rect, mode)`; режимы `other` 660×880, `own` 672×560, `row` W×84, `poster`. Плюс `medal()` и `TileBack` для других экранов |
| `frame_view.gd` + `frame_fx.gdshader` | `V10FrameView` | Аватар в рамке: расписные рамки 0.8 (`frame/avatar`, `frame/avatar_top`) + перекраска шейдером (золото / сакура / аметист, светотень сохраняется) + декор кодом (лавр, листья, камни, жемчуг, звёзды, цветы, иней, солнце, луна, схема, пламя, табличка I–X / S1 / 2027) + ореол и блик. Анимация выключена при fx «минимум» и в строках лиги |
| `card_bg.gdshader` | — | Фон карточки: скруглённая маска, обрезка по фокусу, мягкий блюр, затемнение к низу, виньетка, медленный дрейф |
| `card_editor.gd` | `V10CardEditor` | «Оформить карточку»: живой превью «Так тебя видят другие», вкладки Рамка · Титул · Витрина · Фон · Значки, закрытое серое с условием, точка «новое», Сохранить / Отмена |
| `profile2_selftest.gd` (+ `_runner.gd`, `.tscn`) | `V10Profile2Selftest` | `--profile2_selftest=1`: 109 проверок |
| `card_preview.gd` / `.tscn` | — | Рендер PNG образцов под xvfb (3 карточки other, own, строки лиги, весь каталог рамок, редактор) |

### Каталог (выпущенное / с учётом скрытых)
- **Рамки 45 / 50:** по умолчанию «Чайный салон»; 6 ранговых (Бамбук…Небожитель); сезонные S1/S2 × Золото/Дракон/Небожитель;
  5 рамок основательниц (наборы A/S); 5 рамок SSR-богинь (Злата, Минамо, Кира, Веспер, Сигрид) — **скрыты, пока богини нет
  в `G.HEROES`**; лавры арок 1–2 и «Легенда арки 1»; «Восходящая» I–X (каждые 10 вершин); «Чайный мастер» I/II (серия 30/60);
  «Снова за столом · 2027», «Свой за столом», «Читающая руки», «Мой праздник · 2027», «Праздник Рин/Новы · 2027»;
  4 рамки Лавки (300/480/680/980 кр); 2 рамки пропуска (обычный, Пропуск+ анимированная).
- **Титулы 39 / 69:** «Гость салона», 6 ранговых, 16 за достижения, «Легенда арки 1», событийные, «Сезон N · Золото»,
  «Звезда: <богиня>» (★5 наряда) и «Сердце: <богиня>» (симпатия 10) на каждую из 20 (видны только выпущенные). **Не продаются никогда.**
- **Значки 20:** медальон A/S/SSR (нефрит / лаванда-серебро / золото) с иконкой из кита 0.8. **Не продаются.**
- **Фоны карточки 11:** салон, чайный сад, ледяная чайная, фестиваль, ночная улица, лунный дворец, крыша, неон, святилище,
  турнирный зал, «Первый вечер».

## Данные сохранения (добавляются лениво, SAVE_VER не трогается)
- `S.profile += {frame, title, badges[≤3], showcase{hero, outfit, pose}, card_bg}` — `sanitize()` чинит любые значения,
  старое `frame: ""` из 0.8 → `fr_default`.
- `S.v10_cos_owned {id: true}` — выданное событиями, Лавкой, пропуском, ДР (`grant`).
- `S.v10_cos_seen {id: true}` — что игрок уже видел (точка «новое», тост «новый титул»).
- `S.v10_feats {stats: {}, done: {}}` — счётчики, которых нет в сейве 0.9.
- Читаются, если есть: `v10_streak.best`, `v10_levels.{summits, legend, arcs_done}`, `v10_seasons {season: best_tier}`, `ostars`, `v10_heroes`.

## Хуки для интегратора (короткие вызовы в горячих файлах)
1. **registry_list.gd** (одна строка, когда появится `V10Registry`): самотест `--profile2_selftest=1` →
   `V10Profile2Selftest.run(host)`; дефолты сейва `v10_cos_owned {}`, `v10_cos_seen {}`, `v10_feats {stats:{}, done:{}}`.
2. **profile_screen.gd `_identity()`** → вместо блока 0.8:
   ```gdscript
   var card: = V10CardView.make(V10CardPayload.mine(G.S, {"league": V8League.my_week().league_tier, "games_week": <партий за неделю>}),
       Rect2(x, y, 672, 560), "own")
   card.edit_requested.connect(func(): V10CardEditor.open(main.overlay, G.S, func(ch): if ch: G.save(); _rebuild()))
   card.avatar_tapped.connect(_avatar_popup)
   card.showcase_tapped.connect(func(h): <реакция рига/эмоции, БЕЗ V10Bond>)
   ```
3. **V8PlayerCard.open(main, info)** → внутри `V10CardView.make(payload, rect, "other")`: для себя `V10CardPayload.mine(G.S, …)`,
   для соперника — payload из `population.gd` (п. 4). Кнопку «Открыть профиль» оставить под карточкой.
4. **population.gd**: карточка соперника = `V10CardPayload.sim(rng_по_pid, tier, nick)` (+ `pts`, `league`). Только ранговые рамки
   и рамки A/S, ранние титулы, без SSR-богинь, SSR-нарядов, Лавки и пропуска; поле `sim: true`. Метки ИИ на карточке нет (`G.SIM_LABEL=false`).
5. **league.gd** строки: `V10CardView.make(payload + {"pts": очки, "me": bool}, Rect2(x, y, w, 84), "row")` — статичные рамки.
6. **Счётчики** из `V10Hooks.game_ended(result)`: `V10Feats.best(S, "best_combo", n)`, `bump(S, "clean")` (яку «Чистая рука»),
   `bump(S, "dragons")`, `bump(S, "daily_done")`, `bump(S, "duel_wins")`; письма → `bump("letters")`, подарки → `bump("gifts")`;
   конец недели лиги → `best(S, "league_best", tier)`; сезон → `S.v10_seasons[season] = max tier`; Пагода → `best("pagoda_heat")`;
   салон → `best("salon_zones")`.
7. **Выдачи** (`V10ProfileCos.grant(S, id)`): Лавка — `fr_shop_*` после покупки; пропуск — `fr_pass_1`, `fr_pass_plus_1`;
   ДР — `fr_me_2027`, `fr_bday_<h>_2027`; возврат — `fr_back_2027`, `t_back`; «Первый гость» — `fr_own`, `t_own`;
   «Чтение руки» — `fr_palm`, `t_palm`; «Семь встреч» д7 — `cb_evening`. Новые годы ДР, Пагода и т. п. — `V10ProfileCos.register({...})`.
8. **Тост «новый титул»**: после партии `V10ProfileCos.unseen(G.S, V10ProfileCos.ctx_from_save(G.S))` → для титулов тост с печатью
   (`V10CardView._Seal`) → `mark_seen`.
9. **V10Rank** (ветка экономики): заменить `V10ProfileCos.TIER_COL/TIER_DARK` на `V10Rank.color/…`; подписи A/S/SSR уже в новом стиле.
10. **Экспорт**: самотест и превью должны оставаться в пакете (урок 0.8.1, `exclude_filter` пуст).

## Как проверить
```bash
# самотест (headless)
flock /tmp/tw-godot.lock /opt/tw-tools/godot --headless --path game \
  res://scripts/v10/profile/profile2_selftest.tscn -- --profile2_selftest=1      # PROFILE2_SELFTEST 109/109, exit 0
# превью PNG (нужен xvfb, в headless пустой рендерер)
flock /tmp/tw-godot.lock xvfb-run -a -s "-screen 0 1600x1200x24" /opt/tw-tools/godot --path game \
  --rendering-driver opengl3 --audio-driver Dummy res://scripts/v10/profile/card_preview.tscn -- --out=<dir>
```
После добавления файлов в свежий worktree один раз `godot --headless --path game --import` (кэш class_name).

## Сочность и правила приёмки
- Все нажатия через `V9Feel.press` / `deny`; закрытое — серое, с условием, отвечает «нет» и подсказкой.
- Раскрытие карточки: пружина плашки, выезд витрины, поп рамки, «печать» титула, значки по очереди (искры у SSR), плитки снизу,
  один блик-проход. Наведение мышью: подъём 1,2 %, наклон до 0,8°, блик. Тап по витрине — сердечки и пружина арта, **симпатия не меняется**.
- `S.fx_level`: при «минимум» нет блика, дрейфа фона, анимации рамок, частиц; нажатия остаются.
- Один блик на экран: анимированная рамка + проход по карточке — только при раскрытии/наведении.
- Траты на карточке не показываются; титулы и значки не продаются (самотест).
