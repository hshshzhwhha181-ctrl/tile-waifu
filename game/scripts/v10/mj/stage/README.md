# Героиня в партии — режиссёр присутствия (дорожка `stage`, ветка `v10-mj-stage`)

UX_RULES: P0 18/18, P1 11/13 (подробно в конце; два «нет» в P1 — В-1 и З-1, оба на стороне интегратора).

Цель (docs/MODES.md §3): героиня видна и живёт в **любой** партии, но не мешает играть. Один объект на экран
партии; режимы только сообщают, что случилось (`on(event, data)`), а режиссёр решает, что она делает, по одному
бюджету и одному жёсткому правилу: **пока ввод включён, ни одного пикселя её самой, её текста или эффектов нет
над святой зоной** (поле + лоток/рука + ряд помощи, +8 px). Исключение — частицы пары: ≤ 8 штук, альфа ≤ 0,6,
полёт ≤ 0,45 с, без остановок.

## Как это выглядит

| Где | Что | Когда |
|---|---|---|
| Верхняя полоса 120 px (+ вся лишняя высота 9:20+) | арочное окно портрета, вокруг — **кольцо Приёма** (одна шкала: от левой «ножки» арки через верх к правой). На 9:16 окно ≈ 96 px (влезает над лотком), на 9:20 — сцена до 412 px высотой, «стоит» на кромке стола | всегда |
| Окно | риг v10 (взгляд за пальцем, жесты, говорит при голосе) → видео → нарисованные поясные кадры (смена кадра 120 мс) | реакции: взгляд на тап, улыбка на пару, кивок ×3, хлопок ×5, кадр-поза ×8, подмигивание на «Мотив», закушенная губа в опасности, «ах!» на её фишку-подпись |
| Частицы пары | ≤ 8 искр её цвета летят от пары в окно ≤ 0,45 с, на прибытии кольцо +1 и блик на кончике шкалы | каждая пара |
| Реплика | Caveat 30 «пером» 0,4 с, 4 с у плеча (слева от окна, в свободной полосе, не на паузе и «Осталось N»), без коробки, мягкая тень; голос −14 LUFS, музыка −8 дБ (`Sfx.duck`) | ×5, опасность, подпись, волна, финиш, простой 20 с, новая механика; ≤ 1 / 20 с, одна реплика ≤ 1 / 60 с |
| Выход по пояс | из-за нижней кромки полосы (над кромкой стола) или из бокового поля > 48 px (планшеты); 0,35 с — ≤ 1,2 с — 0,3 с; клип = зона, поэтому даже в движении она не заходит на поле | только волна / финиш; ввод ≤ 0,3 с в очереди |
| Тёплый край | ember-градиент 22 px по краям экрана **минус** святая зона, «сердцебиение» ≈ 1 Гц, без вспышек | опасность (лоток/рука почти полны) |
| Финал | крупный выход в позе win/lose снизу, тап — пропуск, затем `finale_done` | победа / поражение |
| Стол риичи | портрет на месте; голос партнёрши на **твои** объявления (как персонаж за столом в MS), лента её цвета 0,7 с на риичи/рон/цумо, на действия соперниц — только взгляд | `call` (pon/chi/kan), `riichi`, `dora`, `ron`, `tsumo`, `tenpai`, `noten`, `dealin`, `kita` |

Режимы игрока (Настройки → Звук и Картинка, лист паузы):
- **Живая** — всё выше;
- **Тихая** — только окно (кадры/риг) и кольцо, без голоса, текста, выходов и тёплого края;
- **Только финиш** — окно и кольцо стоят, в партии ни голоса, ни реплики, ни выхода; на финише она появляется.

`fx_level = min` (или «Меньше движения»): нарисованный кадр вместо рига, реакции — смена кадра за 120 мс, ноль
твинов движения, нет частиц (кольцо прибавляет сразу), тёплый край без пульса, выход — проявление 120 мс.

Ассеты `game/assets/v10/mj/stage/`: `voice/*.ogg` + `voice/manifest.json` (job id, длина, LUFS, пик, текст, распознанное),

## Хуки интеграции

### 1. Экран партии `play.gd` (через `V10Rules`: 5 точек — start / pair / overflow / end + wave)

`play.gd` не меняется дорожкой; интегратор добавляет в `V10Rules` (или прямо в play при вливании):

```gdscript
# start — после _build_hud() и _make_board(): вместо V6HeroStage в шапке
presence = V10MjPresence.new().attach(self, partner, {
	"board": board,                                   # input_on берётся с доски
	"avoid": [pause_btn.get_global_rect(), goal_lbl.get_global_rect()],  # пауза и «1-2 · Осталось N»
	"charge_need": V9Ults.need(partner),              # пар до Приёма (или data.charge, см. ниже)
})
presence.sacred(board_rect)                           # поле
presence.sacred(_tray_rect())                         # лоток (объединение slot_rects)
presence.sacred(_help_rect())                         # 3 кружка помощи (+ «Ставка ×2», если видна)
presence.portrait_tapped.connect(_ult_try)            # тап по окну = Приём, если готов
board.denied.connect(func(_t): pass)                  # отказ — только звук доски, героиня молчит
# в _unhandled_input / board.tap: перед tap(t)
presence.on("pick", {"pos": t.get_global_transform_with_canvas().origin})
# pair — в _on_match(mid, combo, gold, shard)
presence.on("pair", {"pos": mid, "charge": ult_charge01})   # charge — реальная шкала Приёма (если есть)
if combo >= 3: presence.on("combo", {"n": combo})
if _motif: presence.on("motif")                       # две пары одного символа подряд (дорожка mechanics)
if shard == signature_face(partner): presence.on("signature")
if board.board_count() == 2: presence.on("last_pair")
# overflow — в _refresh() при смене «лоток почти полон»
presence.on("danger", {"on": board.tray.size() >= board.slots - 1})
# wave — при смене волны / этажа / стола (Сад, Пагода, Тройки, рейд)
presence.on("wave", {"wave": n})
# end — до показа окна победы/поражения; окно — по finale_done (или сразу, она уйдёт сама)
presence.on("win") / presence.on("lose")
# Приём — в начале каст-ина v09
presence.on("ult")
```
Сейчас `play.gd` ставит `V6HeroStage` (компакт 92×92 у паузы или карточку 240 px справа) — при вливании он
заменяется окном присутствия (одна шкала: кольцо Приёма). `Sfx.voice_started` присутствие **не** шлёт, чтобы
пузырь `V6HeroStage` не дублировал её реплику.

### 2. Стол риичи / санма (`v10-mj-riichi`, `v10-mj-sanma`)
```gdscript
presence = V10MjPresence.new().attach(self, partner, {"band": "bottom", "band_h": 200})  # её полоса 1080–1280
presence.sacred(hand_rect); presence.sacred(calls_rect); presence.sacred(discards_rect); presence.sacred(buttons_rect)
presence.input_on = waiting_for_player                   # кнопки решения на экране = ввод включён
# на каждое публичное событие движка V8Round (`said`):
presence.on("call", {"who": "me" | seat_hero, "kind": "pon" | "chi" | "kan"})
presence.on("riichi", {"who": ...}); presence.on("dora"); presence.on("ron", {"who": ...}); presence.on("tsumo", {"who": ...})
presence.on("tenpai", {"who": "me"}); presence.on("noten", {"who": "me"}); presence.on("dealin", {"who": "me"}); presence.on("kita", {"who": ...})
```
В `data` можно класть что угодно — режиссёр берёт только `PUBLIC_KEYS` (`pos n on who kind charge need first_today
wave seat`); руки соперниц (`hidden`, `hand`, `waits`…) отбрасываются до любого решения (самотест 5).
Голоса **соперниц** — забота дорожки стола: `V10MjBarks.pick(hero, "pon", rng, budget.line_free)` +
`V10MjStageLines.voice_path(hero, "pon", n + 1)` дают ту же реплику их голосом; бюджет — свой на каждую соперницу.
Настройка «Вставки за столом» (`inserts`) уже управляет лентой здесь: всегда / только мои / первая за день / выкл.

### 3. Новые экраны режимов (`args.presence`, контракт MODES §7.1)
Хаб «Столы» создаёт присутствие и передаёт его в `setup(main, args)`:
```gdscript
var p: = V10MjPresence.new().attach(screen, G.S.partner, {"avoid": screen.hud_rects()})
screen.setup(main, {"presence": p, ...})
# экран режима: args.presence.sacred(field); args.presence.sacred(tray_or_hand); args.presence.sacred(help_row)
# и только события из словаря §3.2. Если args.presence нет — заглушка (on/sacred ничего не делают).
```
Классика/Связи/Сад/Куб: «лоток» = строка цели (не святая), святая = поле + ряд помощи; Тройки — лоток на 7;
Собери руку — рука на 14; Куб — прямоугольник вьюпорта куба.

### 4. Настройки и сохранение
- `G.S["v10_mj_stage"] = {"mode": "live", "inserts": "always", "voice": true}` — `V10MjStageSettings.st()`
  создаёт словарь при первом чтении; `SAVE_VER` не трогаем, интегратору — добавить ключ в `recovery_selftest`.
- Настройки → Звук и Картинка: `V10MjStageSettings.build_rows(container, 672)` (3 строки, хит-зоны 80 px);
  лист паузы — те же строки, после изменения `presence.apply_settings()`.
- Голос уважает `G.S.voice` (общий тумблер реплик), звуки — `G.S.sound`, эффекты — `G.fx_level()`.

### 5. Звук
Голос играет на шине `Voice`, если интегратор её создаст (иначе `Master`), файлы уже −14 LUFS; дакинг через
`Sfx.duck(-8, длина + 0,3)` — шина `Music`, как у v10-audio. Стинг подписи — шина `SFX`/`Master`, −2 дБ.

## Голос (как сделано и как повторить)
- 160 реплик, модель `seed_audio` (Higgsfield), клон тембра: `audio_references` = реплика `*_riichi1` той же
  героини из `v10-audio` (тот сам клон её голоса 0.7) — тембр один во всей игре. Язык озвучки — японский, как у
  всех реплик с 0.7 (русский TTS давал акцент, HANDOFF §15); субтитр русский пером. Реплики стола — настоящие
  объявления «Пон!/Чи!/Кан!/Риичи!/Рон!/Цумо!» голосом, субтитр «Беру!/Ряд мой./Четыре!/Готова!…» (UX §4.2).
- Пайплайн: `tools/voice_pipeline.py items.json urls.txt raw out --asr` → обрезка тишины −45 дБ, усиление до
  −14 LUFS, лимитер −1,5 dBFS, Ogg q5, `manifest.json` (job id, LUFS, пик, распознанное faster-whisper и сходство).
- Тексты и ссылки клонов: `stage_lines.gd` (`LINES`, `VOICE_REF`).

## Самотест
`MJ_STAGE ok/total` — см. итог в отчёте дорожки. Проверки: (1) святая зона на 6 форматах × 3 уровнях эффектов,
частицы ≤ 0,45 с над фишками, ≤ 8 на пару, ≤ 18 живых, мышь берёт только окно; (2) блок ≤ 0,3 с только на
wave/win/lose, ранний тап в очереди и исполняется; (3) 1000 синтетических событий — частоты/кулдауны; (4) «Только
финиш» и «Тихая» — ни голоса, ни реплики, ни выхода в партии; (5) одинаковая реакция при разных `data.hidden`;
(6) `fx_level=min` — ноль твинов движения; (7) стоп-слова UX §4.3 + `V10Lint.BANNED`, длина реплик ≤ 32;
(+) у каждой реплики есть файл голоса.

## UX_RULES (чек-лист §10 для этой дорожки)

слов в кадре — одна реплика ≤ 32 симв.) · П-3 н/п (не Чайная) — да · П-4 да (новых терминов нет; «Приём» и
«Живая/Тихая/Только финиш» — описательные) · П-5 да · П-6 да (окон нет) · П-7 да · П-8 да (при прищуре — поле и
она в окне) · С-1 да (самотест 7) · С-2…С-8 да (цен, валют, точек нет) · С-9 да (реплики через стоп-слова, о
покупках ни слова) · Г-1 да (текст у плеча — вне `face_rect` окна: слева от арки) · Г-2 да (только адаптированные
поясные кадры 0.8 и риг; ничего нового не сгенерировано) · Г-3 да (без ахэгао/шока; кадр «ах!» — удивление) ·
Г-4 да (один риг — в окне; выход всегда кадр; видео не берётся в «авто») · Г-5 да (тап по окну → риг `react` в тот же кадр).
P1 (11/13): В-1 **нет** — цвета из локальной копии токенов `V10MjStageData.TOK` (класса `DS` ещё нет в дереве;
при его появлении — заменить 1:1) · В-2 да (Caveat 30, тень; минимум 18) · В-3 да · В-4 да (одна золотая линия
основания окна) · В-5 н/п · В-6 да (окно ≥ 80 px в хит-зоне на 9:16 — 96×77 + кольцо) · В-7 да (бесконечных
анимаций нет: пульс края только в опасности; без вспышек; min — информация на месте) · В-8 н/п · В-9 н/п ·
З-1 **нет** — своей дорожки у экрана нет (музыка партии — v10-audio, интегратор) · З-2 да · З-3 да (стинг подписи ≤ 1 на её пару) · З-4 да (голос −14 LUFS, дакинг −8 дБ).
