## Запуск

```
# самотест (итог «MJ_KOIKOI ok/total», выход 0 только при полном успехе; сторож 600 с)
flock /tmp/tw-godot.lock /opt/tw-tools/godot --headless --path game res://scripts/v10/mj/koikoi/koikoi_selftest.tscn -- --mj_koikoi_selftest=1 [--games=1000]
# снимки: koikoi_{table,decide,herkoi,tally,result,live_end}_<W>x<H>.png
flock /tmp/tw-godot.lock xvfb-run -a /opt/tw-tools/godot --path game --rendering-driver opengl3 --audio-driver Dummy --resolution 720x1280 res://scripts/v10/mj/koikoi/koikoi_demo.tscn -- --shots=<dir>

xvfb-run -a /opt/tw-tools/godot --path game res://scripts/v10/mj/koikoi/koikoi_demo.tscn -- --hero=yue
```

## Хуки интеграции (делает интегратор)

1. **Хаб «Столы»**, полка «За столом» (MODES §6.1): `load("res://scripts/v10/mj/koikoi/koikoi_info.gd").INFO` (проверка `ResourceLoader.exists`). Открытие — `gate.level = 45` (§6.4). Хозяйка карточки — Рин. Ключ-арт карточки: можно взять `heroines/crane_rin.webp`.
2. **Экран режима** (1 переход, §6.3): главное «Играть», сегмент «6 месяцев / 12 месяцев» (`INFO.variants`), выбор соперницы (`INFO.rivals`), «Как играть» = `V10MjKoikoiInfo.HOW`. Вторичная — «Книга» (`V10MjKoikoiBook.pages(V10MjKoikoiSave.st())`) и альбом (`V10MjKoikoiSkins.album(...)`) — экраны книги/альбома пока не сделаны (см. «Открытое»).
3. **Запуск партии**:
   ```gdscript
   var s := V10MjKoikoiScreen.new()
   s.setup(main, {"hero": "rin", "months": 6, "presence": presence})   # seed по желанию
   s.finished.connect(_on_koikoi_finished)
   ```
   `finished(result)`: `{mode:"koikoi", win, score, her, stars, time_s, pairs, hero, seed, months, yaku:[…], rewards:{coins, gems, petals, aff}, book_new:[…], skin_new:"", again?:true, quit?:true}`.
   Экран **не начисляет** награды: интегратор зачисляет `rewards` через `V10Econ`/`V10Wallet`. «Ещё партия» сама перезапускает стол внутри экрана (сигнал с `again:true` — для учёта).
4. **Сейв**: `G.S["v10_mj_koikoi"] = {wins, book, skins, best, beat, day_win, use_skins, games}` — зарегистрировать в миграции `g.gd` (DEFAULTS в `koikoi_save.gd`), проверить в `recovery_selftest`. `SAVE_VER` не трогали. `record()` вызывается экраном в конце партии (G.save() — за интегратором).
5. **Флаг самотеста**: в `main.gd` по `--mj_koikoi_selftest=1` сменить сцену на `res://scripts/v10/mj/koikoi/koikoi_selftest.tscn`.
6. **Героиня в партии** (`stage`): экран шлёт `presence.on(...)` с событиями `pick`, `pair`, `combo`, `idle`, `win`, `lose` и `presence.sacred(rect)` (стол + рука + низ). Сам рисует соперницу только в своей полосе 0…220(+ex): риг (когда будет у героини) можно подставить вместо `portrait` (TextureRect с AtlasTexture), наезд «в камеру» = твин региона атласа (`_look_at_camera`).
7. **Звук**: музыка режима играет собственным `AudioStreamPlayer` (−8 дБ, петля); если интегратор ведёт музыку через `V10Music` — передать `music:false` в args и включить трек `audio/koikoi_loop.ogg`. Реплики — `voice/*.ogg`, не чаще 1 раза в 20 с, кроме моментов «Кои-кои!/Забираю».
8. **Словарь** (`V10Glossary`): статьи «Коикои», «Кои-кои!», 12 комбинаций (имя + оригинал мелко + «как собрать» из `V10MjKoikoiBook.PAGES[].how`).

## Самотест — что проверяет
Колода 48 / по 4 на месяц / типы 5-9-10-24 / ленты 3+3+4; 200 раздач 8/8/8 без «4 на столе»; картинки колоды на месте;
все 12 комбинаций на эталонных взятках и конфликты (Пять/Четыре/Дождливые четыре/Три света, «3 света с дождём = ничего», Танэ+Ино-сика-тё, Ханами+Цукими, чаша как пустая);
кои-кои ×2/×4, перехват обнуляет её и удваивает тебя, последняя карта — автозабор, пустой месяц без очков, выбор из двух, «три на столе»;
1000 партий ИИ×ИИ по 6 месяцев без зависаний, 48 карт сохраняются; статистика стилей (Хана ≥80%, Рин ≤30%, Юэ берёт больше света, чем Хана);
скины меняют только текстуру светлых карт; стоп-слова («ставка», «пари», UX §4.3) во всех видимых строках; книга 12 страниц с разными позами; награды (+15 кр за первую победу дня).

## Идеи развития (следующие волны, без кода сейчас)
1. **«Задача Коикои»** — одна позиция в день: «Забрать или рискнуть?» с разбором вероятностей голосом Новы (мост к столу, как «Задача дня»).
2. **«Сад месяцев»** — одиночный пасьянс на картах ханафуды (раскладка 12 столбцов по месяцам), тот же арт колоды.
3. **Хати-хати на троих** — ханафуда втроём с двумя героинями, «рука на 88» (вторая волна после Лунного стола).
4. **Правила месяца** для Афиши: «Луна удваивает Цукими», «Дождь светлый», «Кои-кои бесплатно один раз».
5. **Карты месяцев новых героинь** (волна 1): у каждой — своя светлая карта сезона в альбоме (Злата — феникс весны и т. п.).
6. **Кадры Книги**: 12 поз по ключам `PAGES[].key` в стиле карт (лак и золото), с открытием при сборке.
7. **Дуэль по коду**: тот же seed колоды у двух игроков, сравнение очков (на движке `duels`).
