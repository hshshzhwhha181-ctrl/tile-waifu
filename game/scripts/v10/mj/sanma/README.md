# Лунный стол на троих (санма) + событие «Хозяйка против двоих» — дорожка `sanma`

Ветка `v10-mj-sanma` (от `gh-pages`). Только новые файлы: `game/scripts/v10/mj/sanma/`, `game/assets/v10/mj/sanma/`.
Основа: `docs/MODES.md` §4.7, §3 (героиня рядом, но не мешает), §7.1 (контракт), `docs/UX_RULES.md`.

UX_RULES: P0 19/22, P1 11/16 (разбор — в разделе «UX_RULES» ниже).
Самотест: `MJ_SANMA 72/72` (200 партий ИИ×3 за 160 с: 834 раздачи, 751 победа, 83 ничьих, 2168 кита, 99 канов, 449 побед с северами, табло до ×96).

## Что это для игрока

**Лунный стол** — риичи втроём у Юэ: дорогие руки, быстрый темп, мало ожидания чужих ходов.
- Стена 108 фишек: нет манов 2–8; красные пятёрки — 5p и 5s. Чи нет совсем.
- **«Север · кита»**: Север не сбрасывают, а откладывают как дору и сразу берут новую фишку с мёртвой стены.
  Каждый отложенный Север = +1 дора (и ещё +1 за каждый индикатор, который показывает на Север — Запад; с риичи считаются и ура).
  Индикатор 1m показывает дору 9m.
- **Отложенный Север = благословение хозяйки.** Фишка летит к портрету Юэ, портрет мигает лунным светом, расходится
  лунный ореол, она кивает и говорит одну реплику; Север ложится на **Лунную подставку** (серп-колыбель у верхнего
  края, три гнезда с точками цвета владельца). Это событие presence `kita`: решение уже принято, ввод свободен (block 0).
- На экранах 9:20 и длиннее лишняя высота — сцена хозяйки: Юэ по пояс над подставкой (её кадр из `v08/emotions`),
  северы ложатся прямо к ней.

**Событие «Хозяйка против двоих»** (крюк Доу Ди Чжу, раз в месяц, `args.event = true`):
- перед каждой раздачей хозяйка объявляет **×2 или ×3** (по стилю: у Юэ — «дорогие руки» — ×3 чаще) — реплика голосом;
- каждый **кан** и каждый **отложенный Север** удваивают табло (потолок ×96);
- табло — крупная цифра Playfair у правого края сверху, вне святой зоны; скатерть — «полнолуние» (вторая скатерть);
- множитель меняет **только счёт события**: хозяйка выиграла — +2×ценность, каждая из двоих −ценность; выиграл кто-то
  из двоих — оба +ценность, хозяйка −2×ценность (сумма всегда 0). Ценность = |выигрыш победителя| / 100 × множитель.
  Монеты, кристаллы и очки стола множитель не трогает (самотест).

**Награды** (экран их не начисляет — только `result.rewards`): «Стол на четверых» ×0,8 → 1-е 32 / 2-е 20 / 3-е 12 монет,
первая партия дня +16 кристаллов. Рекорд «дороже всего за руку» (очки, лимит, комбинации, число северов, сид).

## Правила движка (`V10MjSanmaRound extends V8Round`, исходник v08 не тронут)

| Правило | Как сделано | Флаг |
|---|---|---|
| 108 фишек, без 2–8m | `sanma_wall()`, мёртвая стена 14 | — |
| 3 места | места 0–2; место 3 в массивах V8Round — пустой «фантом» (без руки/сброса), общие циклы V8 его пропускают | — |
| ветра мест | Восток/Юг/Запад, ход по кругу 0→1→2 | — |
| нет чи | `call_options().chi = []`, ИИ-обёртка отбрасывает чи | — |
| кита | действие хода `{"a":"kita"}` → событие `{"ev":"kita", seat, tile, n}` → проверка рона на Север → добор с мёртвой стены (после 4 доборов — с хвоста живой) | `kita_ron` (true) |
| кита в риичи | только вытянутым Севером | — |
| иппацу после кита | не сбивается (≈ Tenhou, сверить) | `kita_keeps_ippatsu` (true) |
| победа добором после кита | считается «Ринсян» (≈ Tenhou, сверить) | `kita_rinshan` (true) |
| цумо | по умолчанию **без потери за отсутствующего**: доля отсутствующего делится пополам (не-дилер: дилер 2,5·base, другой 1,5·base; дилер: по 3·base). `tsumo_loss=true` — «цумо-сон», платят как на четверых. **Сверить**: по нашим данным Tenhou-санма играет *с* цумо-соном, а без потери — Mahjong Soul; спека называла Tenhou — поэтому вынесено флагом | `tsumo_loss` (false) |
| ничья | банк за темпай 2000 | — |
| старт / формат | 35 000, «Восток» (3 раздачи + повторы дилера), конец при минусе | `length` |
| повторы | рон +300 за повтор, цумо +100 с каждого | — |

`V10MjSanmaAI` — обёртка `V8AI` (стили основательниц те же): кита всегда, кроме случая, когда у руки 3+ северов
(тройка нужна руке); чи никогда. `V10MjSanmaAI.coach()` — подсказка для Учебного зала с учётом кита.

## Хуки интеграции

### 1. Хаб «Столы» (дорожка `hub`, MODES §6)
```gdscript
const SANMA_INFO := "res://scripts/v10/mj/sanma/sanma_info.gd"
if ResourceLoader.exists(SANMA_INFO):
	var info: Dictionary = load(SANMA_INFO).INFO          # полка "table", хозяйка "yue", line «Втроём, дороже и быстрее»
	var table_games: int = int(V10MjRiichiData.st().played) if ClassDB.class_exists("V10MjRiichiData") else 0  # счётчик партий «Стола на четверых»
	var open: bool = load(SANMA_INFO).unlocked(table_games)  # gate {table_games: 3}; закрыт — тизер info.teaser
```
Экран режима (1 переход): главное «Играть · Восток», второстепенное — сегмент «Стол / Хозяйка против двоих» (второе — только
в месяц события), «Как играть» — 3 строки: «Без 2–8 манов и без чи», «Север — в дору, бери новую», «Втроём: дороже и быстрее».

Запуск партии:
```gdscript
var sc: Control = load(info.screen).new()
main.add_child(sc)   # или через registry
var pres := V10MjPresence.new().attach(sc, G.S.partner, {"band": "bottom", "band_h": 180})   # дорожка stage
sc.setup(main, {"presence": pres, "partner": G.S.partner, "host": "yue", "seed": seed, "event": event_active,
	"hall": "bamboo", "names": G.S.get("mj_names", "ru")})
for r in sc.sacred_rects(): pres.sacred(r)   # экран и так шлёт их в presence.sacred() при сборке
sc.finished.connect(func(res): V10Econ.grant(res.rewards); main.back())
```
`result`: `{mode:"sanma", win, score, stars:0, time_s, pairs:0, hero, seed, rewards:{coins, gems, petals, aff}, place, scores, event_score, best_hand}`.

### 2. Если влита дорожка `riichi` (`V10MjRiichiScreen`)

кнопку «Север · кита» при `ask.opts.kita` (ответ `{"a":"kita"}`), событие движка `{"ev":"kita"}` → `presence.on("kita")`
+ полёт к хозяйке (`_on_kita` здесь — образец), `ask.kind == "kita_ron"` — как `chankan`. Пока такого класса нет,
`sanma_screen.gd` — полноценный самостоятельный экран той же раскладки.

### 3. Сейв
`G.S["v10_mj_sanma"]` = `V10MjSanmaData.DEFAULTS`: `played, firsts, places[3], best_hand{pts,han,fu,name,yaku[],kita,seed,date},

## Самотест (`MJ_SANMA ok/total`)
Флаг `--mj_sanma_selftest=1`, итог `MJ_SANMA ok/total`, код 0 только при 100 %, сторож 600 с. Последний прогон: **72/72**.
- стена: 108 фишек, без 2–8m, красные только 5p/5s, 27 видов, без повторов, раздача 13×3, живая стена 55, ветра мест;
- чи: не предлагается следующему за сбросившим, ИИ не объявляет даже подсунутый вариант, в 200 партиях — 0 чи;
- кита: опция хода, Север уходит из руки, событие `kita`, добор с мёртвой стены, мёртвая стена пополняется из живой,
  в риичи — только вытянутым Севером; подсчёт: 1 Север = +1 дора, 2 Севера при индикаторе Запад = +4, Север не создаёт
  комбинацию (рон без яку = 0), индикатор 1m → дора 9m (три 9m = 3 доры);
- платежи: цумо без потери (5000/3000 = 8000; дилер 6000×2), флаг `tsumo_loss` (6000), рон платит только набросивший;
- ИИ держит Север-тройку и откладывает одиночный Север;
- событие: только ×2/×3, у Юэ ×3 чаще, чем у Ханы, кан и Север удваивают (пон нет), потолок, счёт события с нулевой суммой;
  в 200 партиях множитель ни разу не изменил очки стола; награды ×0,8 не зависят от множителя;
- сейв: DEFAULTS, рекорд пишется и не перезаписывается дешёвой рукой, первая партия дня даёт кристаллы, вторая — нет;
- тексты: все видимые строки без стоп-слов (линтер ловит пробные), кнопки ≤ 18 символов, `INFO` по контракту, открытие после 3 партий;
- 200 партий ИИ×3 без зависаний, сумма очков (с палочками) сохраняется после каждой раздачи, «Восток» не обрывается раньше
  третьей раздачи (ловит баг «агари-ямэ», см. «Открытые вопросы»), тот же сид — та же партия;
- экран (3 места): доходит до решения игрока, кнопка «Север · кита» в ряду решений, кнопки чи нет, событие presence
  `kita` отправлено, блокировка ввода 0, святая зона передана, портрет хозяйки и табло события вне святой зоны, ≤ 6 тапаемых;
- снимки 720×1280 и 1080×2400 существуют (при `--shots=<dir>`).

## Что ещё добавить (идеи для следующих волн)
1. **Фазы луны** — каждый отложенный Север за партию меняет фазу на скатерти (серп → полумесяц → полнолуние), на
   полнолунии хозяйка надевает «лунный» наряд-вставку на 1,2 с (мёртвое время, после раздачи).
2. **Лунная задача дня** — «Задача дня» для санмы: «кита или сброс?», «что ждать без 2–8m».
3. **Красный Север** (правило-ломатель на неделю): один из четырёх северов красный — 2 доры за кита.
4. **Тень хозяйки** — асинхронная дуэль: та же стена (сид), твоя партия против записи лучшего игрока недели.
5. **Цумо-сон / без потери** — переключатель зала (Нефритовый — по Tenhou, Бамбуковый — как сейчас).
6. **Подставка героини** — косметика за симпатию: у каждой SSR своя подставка для северов (веер, чаша, кристалл).
7. **Северный ветер** — дейли-правило: первая кита в раздаче даёт +1 к счёту события без множителя (мягкий вход в событие).

## Открытые вопросы
1. **Баг движка v08 (не наш файл, чинит дорожка `riichi`):** `V8Round._next_hand()` проверяет «агари-ямэ» по дилеру
   *после* смены (`result.seat == dealer`). Если не-дилер выигрывает предпоследнюю раздачу и становится дилером последней,
   а очков у него больше всех, партия кончается на раздачу раньше. В санме переопределено (`result.renchan`), самотест
   ловит. На четверых — нужно то же исправление.
2. **Цумо в санме:** спека называла «без потери» вариантом Tenhou; по нашим данным Tenhou — с цумо-соном, а «без потери»
   ближе к Mahjong Soul. По умолчанию «без потери» (как в спеке), `tsumo_loss=true` — Tenhou. Сверить и выбрать по залам.
   Так же сверить флаги `kita_keeps_ippatsu`, `kita_rinshan`, `kita_ron`, банк ничьей 2000 и повторы 300/100.
3. Экран самостоятельный: `V10MjRiichiScreen` в ветках пока нет. После вливания `riichi` — решить, оставлять ли свой
   экран (он уже по раскладке §4.6) или перевести санму на общий экран с `seats=3` (хук 2).
4. Цвета — локальные `TOK` (копия UX §6.2): класса `DS` в ветке нет → В-1 «нет» до вливания дизайн-токенов.
5. Слов в партии при событии ≈ 14 (> 8 по §3.7): имена соперниц, ветра, «Восток 2 / Стена N», табло события.
   Предложение: имена соперниц — только при первом показе стола; подпись табло — одно слово «Хозяйка».
6. Фишки руки 48×66 (хит-зона < 80 — как во всех риичи-клиентах); дорожка `look` может дать материал фишек (`args.look`
   пока не используется, фишки — `v08/table`).
7. Голоса соперниц на пон/кан/рон и мимика за столом — через `V10MjBarks`/`V10MjPresence` дорожки `stage` при вливании;
   сейчас экран сам озвучивает только хозяйку (кита и объявление множителя).
8. На 9:20+ сцена хозяйки — статичный кадр с кивком/ореолом; при вливании `rig` поставить сюда риг Юэ (тот же прямоугольник).
