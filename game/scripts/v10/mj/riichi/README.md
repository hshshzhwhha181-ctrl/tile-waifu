# «Стол на четверых» — японский маджонг (риичи) уровня Mahjong Soul (дорожка `riichi`, ветка `v10-mj-riichi`)

Основа: MODES §4.6, UX_RULES (иерархия, простые имена, «не мешает»). Движок `v08/table` (`V8Round`, `V8Mj`, `V8AI`) **не изменён**:
экран работает через адаптер `V10MjRiichiDriver`. Только новые файлы в `game/scripts/v10/mj/riichi/` и `game/assets/v10/mj/riichi/`.

## Хуки интеграции (делает интегратор)

1. **`main.gd`** — экран и флаг самотеста:
   ```gdscript
   SCREENS["riichi"] = preload("res://scripts/v10/mj/riichi/riichi_screen.gd")   # main.go() зовёт build(main, args)
   PLAY_BACK["riichi"] = true                                                    # оверлей над столом, как у партии
   if "--mj_riichi_selftest=1" in args: get_tree().change_scene_to_file("res://scripts/v10/mj/riichi/riichi_selftest.tscn")
   ```
2. **Хаб «Столы»** (`registry_list` / полка `table`): карточка из `V10MjRiichiInfo.INFO`. Вход: `main.go("riichi", {})` — откроется выбор зала;
   или сразу `main.go("riichi", {"hall": "school", "format": "east"})`. Плашка «Стол открыт» после 3 задач дня (MODES §4.5) —
   по `INFO.gate`. Афиша: «Одна раздача дня» = `{"format": "one_hand"}` (сид дня считает экран).
3. **args**: `format`, `hall`, `seats` (3 = контракт санмы: место напротив не рисуется), `seed`, `partner`, `rivals` [3 id],
   `presence`, `look`, `fx_min`, `horizontal`, `mute`.
4. **Награды**: экран их **не начисляет**. `finished(result)`:
   `{mode:"riichi", win, score, stars:0, time_s, pairs:0, hero, seed, rewards:{coins, gems, petals:0, aff}, place, hall, format, rp, scores, first_today, one_hand_today}`
   (+ `again:true` при «Ещё партия», `abandoned:true` при выходе). `rewards` → `V10Econ`/`V10Wallet`; `rp` → `S.rp`, источник `RP_SOURCES "table"`
   (уже есть в `G`). Потолок кристаллов в сутки проверяет интегратор.
5. **Сейв** `G.S["v10_mj_riichi"] = {ver, hall_progress:{games, firsts, seen}, stats, last_seed, daily_one_hand:{day, done, seed}, first_day, prefs:{names, horizontal, stickers, riichi_hint_seen}}`.
   `V10MjRiichiData.st()` создаёт и чинит поле, `SAVE_VER` не трогается. Для профиля: `V10MjRiichiStats.card()` → 5 строк.
6. **Героиня (дорожка `stage`)**: передайте `args.presence = V10MjPresence.new().attach(screen, partner, {"band": "bottom", "band_h": <высота полосы>})`.
   Экран сам вызывает `presence.sacred()` для руки, кнопок, наборов и своего сброса, ставит `presence.input_on` при `ask`/ответе и шлёт на каждое
   `said` `presence.on(event, {who:"me"|hero, seat, kind})` (`call`, `riichi`, `dora`, `ron`, `tsumo`, `dealin`, `tenpai`, `noten`).
   Пока `presence` есть, голос партнёрши на твои заявки ведёт режиссёр, без него — `V10MjRiichiBarks`. Голоса соперниц — всегда здесь.
7. **Вид (дорожка `look`)**: `args.look = {face_tint, body_tint, back:<путь рубашки>, cloth:<путь скатерти>, music:{base, r1, r2, sting}}`.
   Без него — скатерть и рубашка зала, музыка из `assets/v10/mj/look/music/riichi*.ogg` (если влита), иначе `music/play.ogg`.
8. **Словарь**: если есть `V10Glossary` с `static func open(main, id)`, строки итога открывают его (id = ключи `V8Mj.YAKU/YAKUMAN` и `dora/aka/ura`).
9. **Санма**: `V10MjRiichiScreen` с `seats=3` скрывает место напротив; правила (без чи, кита) — в своём движке дорожки `sanma`.

## Самотест

`MJ_RIICHI 97/97`, код 0, 328 с (из них 200 партий ИИ×4 — 315 с, 1035 раздач, max 1666 шагов на партию).
Проверяет: 200 партий через адаптер без зависаний и с нулевой суммой очков; каждое `said` → ровно одна реакция и ≤1 голос (3 партии бота через экран,
включая японские названия и «Одну раздачу»); кнопки только при `ask` и исчезают после ответа; ни одна вставка не берёт ввод, пока ждётся решение,
`hold()` в это время отказывает (кат-ин не может начаться); тап по руке работает под лентой/штампом/стикером; мимика одинакова при разных скрытых
руках (и в синтетическом потоке, и на двух прогонах стола); `said` несёт только публичные ключи; сид воспроизводит стену (5 сидов + в каждой
экранной партии); `seats=3` рисует 3 места; отмена хода возвращает руку; «Одна раздача» кончается после первой раздачи; паузы ИИ 0,35–0,9 с;
раскладки 720×1280, 720×1440, 720×1600, 960×1280 в обоих видах (всё на экране, сбросы не пересекаются, рука помещается); подсказки только в
Учебном/Бамбуковом; подпись первого «Готов · риичи» один раз; награды, допуск залов, защита ранга; статистика; имена и объяснения для всех
комбинаций движка; стоп-слова во всех видимых строках (≈400) и нет «яку»/«Богиня» на экране.

## UX_RULES §10 (P0 / P1)
P0: одна шапка, нет окна поверх окна (листы сменяют друг друга) — да; святая зона: вставки `MOUSE_FILTER_IGNORE`, кат-ин только в мёртвое время — да;
простые имена, оригинал мелко — да; «Комбинация» вместо «яку» — да; минимум кегля 18 — да; rose только на главном действии («Победа», «Дальше», «Играть») — да;
пилюля только у главной кнопки — да; круг только у портретов героинь — да; нет белых вспышек и тряски интерфейса — да.
P1: тапаемых в партии ≤ 6 вне решения (пауза, стикеры, рука как поле, отмена в Учебном) — да; слов ≤ 8 вне табло — да; 3 кегля в партии — нет
(табло, имена, кнопки и подсказка дают 4: 18/22/30/44 — баннер раздачи 44 живёт 0,8 с); `fx_level=min` — проявление 120 мс вместо движения — да;
награды каскадом — частично (строки итога каскадом, награды партии строкой); тексты по левому полю — да; одна бесконечная анимация — да (нет).

## Арт (Higgsfield `gpt_image_2_6`, quality xhigh, 2k) — 13 изображений, 45,5 кр
5 скатертей залов, 3 рубашки (вставлены в форму v08-рубашки скриптом), 5 гербов доры. Людей и фигур нет — анатомия не применима;
проверено глазами: без текста и логотипов, низкий контраст в центре стола, гербы читаются на 150 px. Голоса стола уже сделала дорожка `stage`
(mc, rin; остальные подхватятся по `V10MjStageLines.voice_path`), слои музыки риичи — дорожка `look`, поэтому кредиты на них не тратились.
Исходники: см. `tools/make_art.py` (raw-файлы не коммитятся).

## Открытые вопросы
- Голоса стола в `stage` пока только у Маджонг-тян и Рин: у Ханы, Юэ и Новы работают субтитры без звука, пока stage не догенерирует.
- Санма на 3 места — только контракт отрисовки; повёрнутые на 120° боковые места и «Север · кита» — в дорожке `sanma`.
- Рейтинг R Небесного зала не считается (нужен сервер/лига 1.2); пока там те же очки ранга.
- Кегли партии: 4 вместо 3 (P1) — можно убрать подпись ветра до 18 и очки до 22, если ревью попросит.
- Отмена хода в Учебном откатывает и ходы соперниц (стена та же, они могут сыграть иначе) — это честно, но стоит сказать в обучении.

## Идеи следующей волны для стола (к `docs/IDEAS.md`)
1. **Повтор партии с её комментарием** — запись `log` движка + сид; героиня одной фразой на ключевых сбросах («тут 5п ждали двое»).
2. **«Ход как у неё»** — после раздачи показать, что сбросила бы стиль-соперница (V8AI с её стилем) — обучение через персонажей.
3. **Событийные правила стола раз в 2 недели**: «Лунная дора» (все пятёрки красные), «Открытые руки», «Ветер героини» (+1 хан, если в руке её фишка-подпись).
4. **Турнир на 8 мест (сетка ИИ-героинь)** по сиду недели с общей таблицей «сыграл тот же сид».
5. **Дуэль-зеркало**: два игрока асинхронно играют один сид против одинаковых ИИ, сравнение итогов.
6. **Коллекция комбинаций** («Книга узоров»): первая собранная комбинация открывает страницу с позой героини.
7. **Именные эффекты за симпатию** (MD-20): штамп рона, палочка риичи, лента — косметика без силы.
