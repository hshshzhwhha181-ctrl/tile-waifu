# Тройки — лоток на 7, 120 уровней (дорожка `triples`, ветка `v10-mj-triples`)

UX_RULES: P0 20/22, P1 13/16 (подробно в конце; в P0 не закрыты только ручные П-7/П-8 — ждут игроков-персон; в P1 «нет» — В-1, З-1, З-4, все на стороне интегратора: класс DS, петля музыки, LUFS).

Основа: `docs/MODES.md` §4.2, §3 (героиня рядом, но не мешает), §5.5 (Приёмы), §7.1 (контракт). TrayBoard, play.gd, main.gd, g.gd
не менялись — только новые файлы в `game/scripts/v10/mj/triples/`, `game/assets/v10/mj/triples/`, `game/data/mj/triples/`.

## Что это для игрока
Тап по свободной фишке — она по дуге летит в лоток (0,28 с, сжатие 0,9 → отскок 1,05 → 1,0). Одинаковые встают рядом, соседи
раздвигаются за 0,12 с. Три одинаковые раскрываются веером и схлопываются — искры (≤ 8, альфа ≤ 0,6, ≤ 0,45 с) летят в арочное
окно героини, кольцо Приёма растёт. Лоток 7/7 без тройки — проигрыш. На 6/7 у неё сердцебиение, последняя ячейка горит ember,
по краям экрана (вне святой зоны) тёплый край. Когда на столе всё свободно, включается «Благословение стола»: оставшиеся тройки
слетаются сами, всё быстрее, тон растёт; затем она выходит в полный рост в высокой арке-«обложке» (стол уже неактивен, тап — пропуск)
и лист «Стол чист» (≤ 3 жетона наград, «Ещё уровень · N»). Проигрыш — лист «Почти!»: если бесплатная помощь не потрачена —
«Вернуть 3 и играть» (никаких продаж в партии и после проигрыша).

Звёзды: ★ — стол чист; ★★ — без помощи (бустеры, Магнит); ★★★ — и лоток ни разу не дошёл до 6.
Бустеры (бесплатные, 1 на попытку, у боссов «Вернуть 3» и «Перемешать» по 2): «Вернуть 3» (с L5), «Магнит» (L9, на стартовом листе —
снимает 3 тройки до старта), «+1 ячейка» (L15), «Перемешать» (L22). Закрытые не показываются (без замков, UX §6.4).

## Запуск
```bash
cd game
# самотест (итог MJ_TRIPLES ok/total; код 0 только при 100 %); со снимками — проверяет 6 файлов демо
flock /tmp/tw-godot.lock /opt/tw-tools/godot --headless --audio-driver Dummy --path . \
  res://scripts/v10/mj/triples/triples_selftest.tscn -- --mj_triples_selftest=1 [--mj_triples_shots=<dir>]
# запекание полос бота → data/mj/triples/bake.json (≈ 30 с)
flock /tmp/tw-godot.lock /opt/tw-tools/godot --headless --audio-driver Dummy --path . \
  res://scripts/v10/mj/triples/triples_selftest.tscn -- --triples_bake=1
# снимки (два прогона: 720x1280 и 1080x2400)
flock /tmp/tw-godot.lock xvfb-run -a -s "-screen 0 1200x2600x24" /opt/tw-tools/godot --path . --rendering-driver opengl3 \
  --audio-driver Dummy --resolution 720x1280 res://scripts/v10/mj/triples/triples_demo.tscn -- --shots=<dir> --tag=720 \
  [--level=14] [--hero=hana] [--tray=moon] [--fx=min] [--start_sheet=1] [--only=start]
```
Итог самотеста на ветке: **MJ_TRIPLES 2742/2742** (≈ 14 с). Покрытие: 120 уровней с верным сертификатом (лоток по сертификату ≤ 6),
детерминизм и совпадение с запеканием; доля побед бота в полосе на всех 120 (средние: лёгкий 0,96 · обычный 0,85 · сложный 0,50 ·
пик 0,21); «Вернуть 3» и «+1 ячейка» на 160 решаемых состояниях (свидетель — сертификат) и на 93 случайных состояниях (точный DFS:
«решаемо до → решаемо после»); автосортировка (группы, стабильность, место вставки) на > 500 ходах; проигрыш строго на 7/7 (и 8/8
после «+1»), тройка седьмой фишкой — не проигрыш; ворота бустеров 5/9/15/22 и их открытие в сейве; Магнит сохраняет сертификат на
всех 120; «Перемешать» сохраняет набор лиц и решаемость; Приёмы пяти героинь; награды ×0,5, Салон ×0,5; аккорды и вибрация;
запретные слова; экран: святая зона пуста в старте/6-7/после игры, тапаемых 5 ≤ 6, слов ≤ 8, событие danger на 6/7, Приём Рин,
тройка → `pair`; снимки 720×1280 и 1080×2400.

## Хуки интеграции (что вписать интегратору)
1. **Хаб «Столы»** (дорожка `hub`): полка `solitaire`, карточка из `V10MjTriplesInfo.INFO` (`load()` с `ResourceLoader.exists`);
   открытие после L14 Пути (`gate.level`), одна реплика Ханы при открытии (UX §3.5). Экран режима: «Играть · N»
   (`V10MjTriplesSave.st().level`), звёзды Троек (`total_stars`), «Как играть» = `INFO`-строки `HOW` с иконками `V10MjTriplesIcon`.
2. **Переход в партию** (`main.go` / `V10Registry`):
   ```gdscript
   var s := V10MjTriplesScreen.new()
   s.setup(main, {"level": lvl, "hero": G.S.partner, "presence": presence_or_null, "look": {"tray": tray_key_or_dict, "tiles": tile_look}})
   s.finished.connect(func(r): _on_triples_done(r))   # r.action: "next" | "retry" | "exit"
   ```
   Стартовый лист (уровень, звёзды, Магнит) встроен; если хаб показывает свой — `start_sheet: false, magnet: bool`.
   Свой экран победы у интегратора — `result_sheet: false` (тогда `finished` придёт после финала героини, `r.action` пуст).
3. **Награды** (экран их не начисляет): `result.rewards` = Путь × 0,5 (оценка `V10MjTriplesSave.path_reward`; заменить базу на
   `V10Econ` Пути и умножить на `PATH_K`), `result.salon_stars` = прирост звёзд × 0,5 → Салон. Кристаллы — только по общим правилам
   (первая победа дня), здесь 0. `result` по схеме §7.1: `{mode, win, score, stars, time_s, pairs(=тройки), hero, seed, level, rewards}`.
4. **Сейв**: `G.S["v10_mj_triples"]` создаётся `V10MjTriplesSave.st()` по `DEFAULTS`; `SAVE_VER` не трогали. В `recovery_selftest`
   добавить ключ в список известных полей. Экран сам вызывает `record()` и `G.save()` (кроме `demo: true`).
5. **Героиня** (`v10-mj-stage`): передать `args.presence = V10MjPresence.new().attach(screen, hero, {...})` — экран шлёт ему
   `start/pick/pair/combo/signature/danger/last_pair/ult/win/lose` и `sacred(стол, лоток, помощь)`. Встроенная `V10MjTriplesPresence`
   тогда остаётся только источником окна-цели для искр и кольца (скрыта). Голос и Caveat — из stage; встроенные реплики — запасные.
6. **Вид** (`v10-mj-look`): `args.look.tray` — ключ одной из 5 рамок или `{tex, size: Vector2, well: Rect2}` из её скина;
   `args.look.tiles` — словарь материала фишек (по умолчанию `G.skin_look()` + `V6TileLook`). Стол — тема `V6BoardTable` героини
   (`HERO_TABLE`), Альбом может переопределить (`V7Album.table_for`). Музыка: ключ `INFO.music` = `mode_triples` (MODES §6.5).
7. **Механики** (`v10-mj-mechanics`): класса `V10MjMech` на gh-pages нет — уровни Троек сейчас только «очисти стол» + тайные фишки
   (с главы 5 на сложных/пиках/боссах). Когда библиотека вольётся: в `V10MjTriplesGen.build` добавить поле `goal` из
   `V10MjMech` (лепестки/реликвия) — сертификат не меняется, цели ставятся на фишки сертификата (≤ 3 хода на препятствие).
8. **Приём v09-кат-ин**: сейчас короткий собственный (имя Приёма Playfair Italic + её цвет, ≤ 1,2 с, ввод закрыт); полный кат-ин —
   вызвать `V9UltCast`/`V9Cutin` перед `board.cast(plan, target)` в `_try_ult()`.
9. **Тексты**: прогнать `INFO`, `HOW`, `NAMES`, `LINES` через `V10Lint`, добавить статьи «Тройки», «Магнит», «Благословение стола»
   в `V10Glossary`.

## Арт (Higgsfield)
5 рамок лотка: `gpt_image_2_6`, quality **xhigh**, 1k (1344×576, прозрачный фон), обрезаны по альфе, webp q94. Job id — в
`V10MjTriplesLook.TRAYS[*].job`. Персонажей нет (аудит анатомии не нужен), проверено: без текста, без фишек, середина однородна
(9-patch тянет только середину полки, уголки масштабируются целиком). Расход: 5 × 2 = **10 кредитов** (лимит 20).
Иконки бустеров — монолиния кодом (0 кр). Финал героини использует уже проверенные арты нарядов (`V9Ults.shown`).

## Отклонения от спеки (осознанные)
- Ячейка лотка: шаг 88 на планшетах; на 720 px ширины рамка с орнаментом не помещается — `V10MjTriplesLook.fit` ужимает рамку
  (не меньше 0,62) и потом шаг (у лаковой полки 84, фишка 78). Спека «7 × 88» выполнима только без орнамента рамки.
- Свобода фишки — жанровая (ничего не лежит сверху), без боковых блокировок Пути: в Тройках нет «не могу взять» (MODES §4.2).
- Бустеры бесплатные, 1 на попытку (боссам 2) — без экономики и продаж; запасы/цены — решение интегратора с V10Wallet (не в партии).
