# V10HudFx — премиальные HUD-эффекты 0.10 (ветка `v10-hudfx`, дорожка 5)

База: `v10-hud2` (HUD v2 «Тишина и лак») + `v10-juice` (библиотека сочности). Эта ветка добавляет **слой премиальной отделки
поверх HUD v2**: всё, что HUD_V2/UX_RULES описывают как движение, свет и живописные предметы, но чего в hud2 пока нет
(см. «Известные отступления» в `scripts/v10/hud2/README.md`). Новые файлы только в `scripts/v10/hudfx/`,
`assets/v10/hudfx/`, `shaders/v10/hudfx/`. Файлы hud2 и juice правятся только точечными хуками (≤ 10 строк на файл,
каждый хук через `V10Hud2Util.opt_class("…")` или проверку `ResourceLoader.exists`, чтобы hud2 работал и без hudfx).
Горячие файлы (g.gd, main.gd, play.gd, ui-скрипты 0.9) НЕ трогаем — их строки для интегратора в разделе «Хуки».

## Закон стиля (нарушение = блокер ревью)

Источник правды: `docs/UX_RULES.md` §6 (дизайн-система), `docs/HUD_V2.md` §1, §4, §6, §7. Коротко:
1. **Интерфейс неподвижен, героиня живёт.** HUD двигается только на вход/выход. Никакой тряски интерфейса, пульсации,
   бесконечных анимаций (единственная — «дыхание» главной кнопки, уже в `V10Button`). Один блик на экран.
2. **Без белых вспышек**, ≤ 3 вспышек/с, свет тёплый: аддитивные слои α ≤ 0.85, яркость цвета ≤ 0.8 (`V10HudFx.warm_light`).
   Ведёт акцент героини (`V10DS.HEROES[h].accent/glow/deep`, ≤ 10 % пикселей экрана).
3. **Без конфетти и фонтанов монет.** Награды — каскад карточек-фишек с шагом 80 мс, каждая — нота пентатоники вверх.
4. **Глубина тоном, а не рамкой**: одна волосяная линия `gold.700` α 0.35, лак 5 %, без обводок/теней/сакуры по углам.
5. **Цвета только из `V10DS`** (hex-литералы вне `tokens.gd` запрещены и в hudfx: селфтест грепает). Шрифты только через `V10Type`.
6. **fx_level**: `full` — всё; `mid` — частицы ×0.55, без «лишнего» света; `min` — любое движение = проявление 120 мс,
   без частиц/бликов/отклика линии, вся информация остаётся. `V10HudFx.calm()` («Без тряски и вспышек») — без вспышек света.
7. **Производительность (средний Android, GL Compatibility)**: только `CPUParticles2D` или один узел с `_draw` на вспышку;
   ≤ 18 частиц на эффект витрины; шейдеры — короткие, без циклов > 16 выборок; живого blur нет (снимок один раз);
   `_process` только пока эффект идёт (`set_process(false)` в покое); всё освобождается (`queue_free`) по окончании.
8. **Красные линии** (HANDOFF §1, HEROINES, LEGWEAR §1.1): блеск по легвиру — маска не выше колена; свет на героине не
   акцентирует пах/грудь; витрина не меняет позу/кадр.

## Модули (класс → файл → что делает)

| Модуль | Класс | Где в игре | Суть (тайминги из HUD_V2 §6 / UX §6.7) |
|---|---|---|---|
| Ядро | `V10HudFx` (`hudfx.gd`) | везде | Гейты уровня, акценты, текстуры/шейдеры/звуки, ноты пентатоники, прогрев шейдеров |
| Одометр | `V10Odometer` (`odometer.gd`) | «Осталось», счётчики помощи, награды, валюта в S-плашке | Прокрутка по разрядам 320 мс EXPO_OUT (≤ 12 шагов), ±1 — кроссфейд 120 мс, награда в конце 1,0→1,06→1,0 за 160 мс; «Осталось» без пульса; Numerals (tnum), тонкий пробел «1 980» |
| Перо голоса | `V10VoiceInk` (`voice_ink.gd`) | реплики героини (партия, Чайная, победа) | Caveat 30 «пишется пером» 0,4 с (маска-шейдер слева направо с мягкой кромкой туши), мягкая тень у плеча вне святой зоны, держит 4 с, гаснет 0,3 с; без пузыря |
| Цифра комбо | `V10ComboDigit` (`combo_digit.gd`) | над лотком слева | Display 64 italic, золото лака (градиент gold.300→gold.500, внутренняя кромка, один косой блик за «держит»); вход 120 мс BACK_OUT 1,15→1,0, держит 360, выход 120; новая сменяет старую; на T3 растёт только свет (тёплое гало акцента ≤ 0.7) |
| Кольцо Приёма | `V10PriyomRing` (`priyom_ring.gd`) | дуга за плечами героини в партии | Шейдер дуги 170°→370°: дорожка night.600 α 0.55; заряд акцентом с лаковым градиентом и мягким свечением; рост EXPO_OUT 300 мс; «готово» — один вдох света 600 мс и тихое свечение без пульса; `cast()` — свет дуги стекает к героине 300 мс |
| Витрина живая | `V10ShowcaseFx` (`showcase_fx.gd` + `showcase_live.gdshader`) | `V10ComboShowcase` T1–T3 | Один материал: маска стола T1 (как `hud2/showcase_sprite`) + `sway` волос по маске (≤ 6 px, только во время «держит») + `sheen_sweep` по легвиру 0,6 с (маска ниже колена) + контровой свет T3 акцентом по силуэту 0,6 с; частицы стихии живописными спрайтами (≤ 18 full); косой луч акцента ≤ 70 % яркости |
| Каскад наград | `V10RewardCascade` (`reward_cascade.gd`) | победа такт 2, «Забрать», Лавка | Карточки-фишки 3:4 со скосом 12 (кость + золотая кромка 1 px), живописный предмет + Numerals; шаг 80 мс, нота пентатоники вверх; на экране ≤ 3 жетона, дальше «ещё N ▸»; счёт летит в плашку-цель (`V10Odometer` + `V10Plate.ping()`) |
| Печать-ханко | `V10Hanko` (`hanko.gd`) | покупка, «Забрать», новая героиня | Падает 140 мс, 1 кадр сплющивания, глухой «тук» (`stamp_thud`), киноварь `cinnabar` проступает 300 мс по фактуре бумаги; заменяет «Успешно!» |
| Фонари-ритуалы | `V10LanternFx` (`lantern_fx.gd`) | 3 фонаря Чайной (`V10HudHome.lantern_tr`) | Новое дело: качается 2 периода (затухающий маятник от верхней точки, ≤ 6°) и загорается за 400 мс (тёплое внутреннее свечение, гало gold); сделано: свет гаснет «выдохом» 300 мс, фонарь опускается на 8 px. Горящий фонарь статичен (без мерцания) |
| Лист «Шёлк» | `V10SilkSheet` (`silk_sheet.gd`) | все листы (пауза, «Не хватает», подтверждение) | Снимок экрана один раз → уменьшение и размытие (без живого blur) → под лист с тоном night.900 α 0.5; лист снизу 220 мс QUINT_OUT, волосяная линия сверху, радиус 4; закрытие 160 мс QUINT_IN |
| Ветер | `V10Wind` (`wind.gd`) | смена партнёра/скина | Волна частиц её стихии через экран 600 мс + сборка HUD от центра (α и сдвиг, масштаб не трогается, шаг 40 мс, ≤ 5 узлов) |
| Любоваться | `V10Admire` (`admire.gd`) | Чайная | Долгое нажатие на героиню (или 12 с без касаний) — интерфейс тает «Лаком» 600 мс, остаётся она; любое касание — «Вдох» 240 мс обратно, касание не проходит дальше |
| Звёзды победы | `V10VictoryStars` (`victory_stars.gd`) | `V10HudVictory` | Живописные звёзды садятся по одной (240 мс, шаг 200 мс, без тряски), нота вверх, щепоть золотой пыли ≤ 8 частиц (full); незаработанная — силуэт paper.700 |

Каждый модуль: статический конструктор или узел-исполнитель, `fx_level`-ветки, освобождение по окончании, свой самотест
`<module>_selftest.gd` (класс `V10HudFx<Module>Test`, `static func run(host: Node) -> Dictionary {passed, failed, lines}`),
своя демо-сцена `demo/<module>_demo.tscn` (`--shots=<abs dir>` пишет PNG и выходит).

Каждый живописный предмет: свет сверху слева, одна искра, прозрачный фон, без подложки и обода (HUD_V2 §4).
Job id всех генераций — в `tools/art/jobs.tsv` (дописать строки).
