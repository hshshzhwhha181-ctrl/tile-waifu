# Лавка 2 (ветка `v10-shop`, веха M4, спека 0.10 Л1–Л8)

UI и логика Лавки поверх ядра экономики `v10-economy` (V10Econ / V10Catalog / V10Shop / V10Spend / V10Pass / V10StubPay)
в системе «Тишина и лак» из `v10-hud2` (V10DS, V10Type, V10Plate, V10Button, V10Icons, V10Header).
В ветку влиты: `v10-economy` (по заданию) и `v10-hud2` (дизайн-токены и классы кнопок; конфликт `docs/HUD_V2.md` решён в пользу gh-pages).
Свои файлы — только `game/scripts/v10/shop/` и `game/assets/v10/shop/`. Чужие файлы не правились.

Приоритеты: UX_RULES §3.2/§5/§9-7 и HUD_V2 §8.5 важнее спеки там, где они расходятся (3 сегмента вместо 4 вкладок,
«Пополнить» вместо «Камни», Лепестки — переключатель в Нарядах, один «самый низкий ₽ за желание» вместо наклеек).

## Проверки

```
cd game
# самотест (логика + раскладки в SubViewport на 7 соотношениях: 9:16, 9:18, 9:19.5, 9:20, 9:21, 3:4, 10:16)
flock /tmp/tw-godot.lock /opt/tw-tools/godot --headless --path . res://scripts/v10/shop/shop_demo.tscn -- --shop_selftest=1
# → SHOP_SELFTEST 482/482, код выхода = число провалов
# скриншоты всех экранов на нескольких размерах (SubViewport, одним запуском)
flock /tmp/tw-godot.lock xvfb-run -a -s "-screen 0 1200x1800x24" /opt/tw-tools/godot --path . res://scripts/v10/shop/shop_demo.tscn \
  --rendering-driver opengl3 --audio-driver Dummy --resolution 720x1280 -- --shots=/abs/dir --sizes=720x1280,720x1600,960x1280
# интерактивно: -- --view=vitrina|outfits|topup|topup_later|pass|retro|purchases|age [--level=35] [--store=1] [--fx=min]
```
Самотест: тексты карточек = V10Catalog; ровно один «самый низкий ₽ за желание» и это минимум; правило 3× для каждого SKU (и первой покупки);
лестница по уровню 0/5/35/61/120 и «один раз»; в карточках нет «ч/мин» и дат; store-сборка — 0 ₽ (модель и экран); заглушка: оплачено
(удвоение первой покупки), отмена, отказ, ожидание → доводится, дубль колбэка выдаёт один раз, аудит экономики чист; подросток
блокируется до провайдера; вопрос о паузе один раз; лист подтверждения (оферта, траты, ТЕСТ, спиннер, двойной тап, тост, ханко);
возраст (без предвыбора, тексты кнопки, 16–17, ребёнок, bold_ok, `needs_gate` после перезапуска, `refresh`); попап; реклама (≤ 6, chest ≤ 3,
абонемент без провайдера); подарок дня; cover; ретро-выдача пропуска; раскладки: ничего за шириной экрана, хит-зоны ≥ 80 (UX §6.1; у `Tap`
видимая плашка 56–64, зона касания дорастает до 80), ≤ 1 главной, нет розового на ₽, у каждой ₽-цены «= N желаний» и «≈ N ₽ за желание»,
текст ≥ 18 (15 — только надстрочник), запретные слова (§4.3 + «было» §4.2, SR/R/−N%/ID с границами слова, «ещё N … сегодня»), ≤ 2 валют,
≤ 10 тапаемых в первом экране Витрины, на экране возраста кнопка в нижней половине; листы confirm / «Не хватает» / наряд — ровно одна главная.
Регрессии ревью: до L8 ни одного ₽; «самый низкий» только при видимой разнице (после первых покупок — у 4 990 ₽); свайп карусели = одна
карточка при паре «касание + эмулированная мышь»; тост и ханко переживают перестройку Пропуска и «Моих покупок»; диск абонемента не тапается;
стоп-экран возраста возвращается; история показывает 1 720, а не 900; лист оплаты не закрывается, пока платёж в пути.

## Хуки интеграции (горячие файлы правит только интегратор)

1. **Экран.** `main.SCREENS["shop"] = preload("res://scripts/v10/shop/shop2_screen.gd")` (адаптер `build(main, args)`; `args.tab` 0/1/2,
   `args.v10 = "pass" | "purchases"`). Старый `screens/shop.gd` и `_buy()` удалить (Ф7). Кнопка пропуска в Желаниях/Афише → `main.go("shop", {"v10": "pass"})`.
2. **Слой листов.** В main.gd после навбара создать полноэкранный `Control` «Overlay» и присвоить `V10ShopSheet.layer = overlay`
   (иначе лист оказывается под навбаром — в демо так и сделано).
3. **Сейв.** `V10Save.register("v10_shop", V10ShopModel.defaults())` (ключи gift/age/offers/ads/cool_asked/crystal_noask; без подъёма SAVE_VER).
   Экономика — `S.econ` по README v10-economy, `G.econ` обязателен для `V10ShopHub.model()`.
4. **Экран возраста.** В `main._splash()` до входа/обучения: `if V10Age.needs_gate(S.v10_shop, now): показать V10AgeGate.make(S.v10_shop, now)`
   (НЕ `is_set`: год ниже допуска уже записан, и при перезапуске гейт снова показывает стоп-экран); `done("child")` — остаться на стоп-экране. `V10Age.bold_ok(S.v10_shop)` — единственный ключ к 18+-жестам рига и `bold`-ассетам (LEGWEAR §5).
   Подтверждение через VK ID/Яндекс ID (1.0): `econ.spend.set_age_verified(true)`.
5. **V10Catalog (v10-economy), правки по спеке Л3/Л5:** убрать `window_days` у guest_149/newbie_499 (гейты по уровню, без дат — сейчас они
   пропадают через 14 дней от установки); добавить `traveler_199` в `SKUS` (сейчас приходит через `shop.extra_skus`); перенести числа
   `V10ShopData` в каталог/economy.json; `econ.pass_xp_per_pull = 0` (Л5: за желания опыта нет); `V10Shop.offers().per_pull` пишет
   «за крутку» — запрещённое слово (UI его не использует, но поправить на «за желание»).
6. **Цены.** UI показывает то, что в V10Catalog. Каталог v10-economy (79 ₽ = 180 камня, абонемент +90/день) расходится со спекой Л4/Л6
   (79 ₽ = 60, +30/день) — открытый вопрос №1 в README v10-economy, решение владельца. Менять только каталог.
7. **«Не хватает».** Заменить тосты `summon.no_gems` и `common.need_gems` на
   `V10ShopFlow.need(screen, V10ShopHub.model(), deficit, func(): main.go("shop", {"tab": 2}), go_free)`, где
   `go_free(go: String)` открывает экран бесплатного пути («pass» → `main.go("shop", {"v10": "pass"})`, «today» → Афиша);
   можно один раз задать `model.free_paths_go`. Бесплатные пути других модулей — через `model.free_paths_fn` в виде
   `{"text": "Задания дня: ещё 50 кристаллов", "go": "today"}` (без «сегодня»: UX §4.1.7 запрещает «ещё N сегодня»).
8. **Попап после победы.** В `V10WinStack`: `ctx = {now, install, level, result, first_ssr_session, first_ssr_t, day}`
   (`first_ssr_t` — unix первой SSR, 0 если её ещё нет: UX §3.5 «и 24 часа после неё»); если
   `V10Offers.can_popup(S.v10_shop, ctx).ok` и есть `model.ladder().current` → `V10ShopFlow.confirm(screen, model, id)` и `V10Offers.mark_shown`.
9. **Реклама.** Сундук победы ×2: `model.ads.show("chest", func(ok): …)`; `model.ads_stub.host = screen` для оверлея.
10. **Абонемент.** Утренний поднос забирает `econ.shop.month_claim()`; на Чайной — `V10MonthDisc.make(model)` только как украшение
    (без тапа и точки; в 7 тапаемых Чайной он не входит). Место — зона статуса/подноса по UX §3.3, не новая кнопка.
11. **Сборки.** Пресеты `Android-test` (feature `tw_test`) и `Android-store` (`tw_store`); для 16+-варианта — `tw_16plus`. В `export_presets.cfg`
    не исключать `scripts/v10/shop/*selftest*` и `shop_demo.*`. `--shop_selftest=1` добавить в `--v10_selftest=all` через V10Registry.
12. **Звук.** Через `V10Hud2Util.sfx`: `stamp` (ханко), `sheet_open/sheet_close`, `tab_switch`, `wood_dull` (ошибка без «бззз») — ждут банк `v10-audio`.
    Музыка вкладки — `V10Music.play_tab("shop")`.
13. **Шансы.** Подвал «Шансы и правила» откроет `V10OddsScreen`, если он есть (дорожка gacha), иначе лист «В Лавке нет случайных товаров».
14. **Оферта.** Ссылка в листе подтверждения сейчас тост — подставить URL оферты (1.0, нужен ИП).
15. **Словарь и помощь «?» (П-4).** Статьи «Лунный камень», «Лунный абонемент», «Пропуск сезона», «Подарок дня», «Лепестки» готовы
    в `V10ShopData.GLOSSARY` (поля и лимиты `V10Glossary`). В `v10/clarity/glossary.gd` (ветка v10-clarity): в `CATS` добавить
    `["shop", "Лавка"]`, в `_ensure()` после `BASE` — `for e in V10ShopData.GLOSSARY: _add(e.duplicate(true))`. «?» в шапке Пропуска и «Моих покупок»
    (UX §2.4) — `V10Header.make(self, title, back, help)` со статьёй `shop.pass` / `shop.moon`.
