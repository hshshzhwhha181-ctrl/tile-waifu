# v10-clarity — понятные названия, награды и фишки

Жалоба тестера: «после партии непонятные названия и ачивки, неясно за что выданы; символы на фишках непонятно от чего зависят».
Ветка `v10-clarity` (от `gh-pages` b3dfbc7). Весь код — в `game/scripts/v10/clarity/`. В общие файлы добавлены только
однострочные хуки с пометкой `# v10-clarity hook` (список ниже) — при интеграции их легко найти `grep -n "v10-clarity hook"`.

## Что сделано

| Файл | Класс | Что делает |
|---|---|---|
| `glossary.gd` | `V10Glossary` | Единый словарь: ~150 записей. Каждая: понятное имя, мелкая «японская/поэтичная» подпись, «За что», «Как получить снова», награда, иконка, старые имена (`was`). Строится из живых таблиц игры (G.YAKU, G.CATS, FORTUNES, V6Specials, V7Combo.TIERS, FACE_NAMES, RANKS, LEAGUES, V9Ults.MODS, EGG_NAMES). |
| `clarity_state.gd` | `V10ClarityState` | Настройки и «уже видел»: `G.S["v10_clarity"]` (создаётся лениво, как `v6_special`; SAVE_VER не меняется). |
| `breakdown.gd` | `V10Breakdown` | Разбор наград на экране победы: строки «иконка · имя · за что · +N», «Стол пройден +N» с формулой, «Почему так?» (разбор именно этой партии: звёзды, очки ранга, кристаллы), «Ещё N бонусов ›». Первый раз — «НОВОЕ», золотое свечение и подсказка. Штамп по ритму 0.9. Тап по строке → карточка. Тап по кристаллам → из чего сумма. |
| `info_card.gd` | `V10InfoCard` | Карточка «За что / Как получить снова / Награда / Получено N раз», кнопка «Весь словарь». |
| `tile_marks.gd` | `V10TileMarks` | Метка масти на фишке (правый нижний угол: цвет + форма — цветок/звезда/конфета/камень/лапка; в «крупных символах» — номер картинки в масти), монетка «×5» на золотой, значки рубашек: синяя стрелка (перевёртыш, тапни) и «?» (тайная, откроется сама), сильнее затемнение зажатых в контрастном режиме. |
| `tile_info.gd` | `V10TileInfo` | Долгое нажатие на фишку (0,45 с) → пузырь: картинка, масть и номер, «пара — только такая же», сколько их на столе/в лотке, особенность (золото, рубашка, тайная, замок, ключ, цепь, джокер, хлопушка, подарок, портрет) и можно ли взять, а если нет — точная причина («сверху лежит фишка» / «зажата слева и справа» / замок / цепь). Тап по-прежнему срабатывает сразу. Долгое нажатие на зажатую фишку не засчитывается в промахи. Режим «лупы» из легенды. |
| `legend.gd` | `V10Legend` | Экран «Фишки»: живые мини-сцены из настоящих фишек (правило свободной фишки, пара в лотке), 5 мастей со всеми картинками, обычные vs крупные метки, особые фишки (перевёртыш переворачивается). «Показать на столе», «Словарь». |
| `glossary_screen.gd` | `V10GlossaryScreen` | «Словарь»: вкладки «Награды», «Фишки», «Ранги и секреты»; у бонусов — сколько раз получено. |
| `sheet.gd` | `V10Sheet` | Общая полноэкранная шторка (лента-заголовок, крестик, вкладки, список со скроллом). |
| `clarity_icon.gd` | `V10ClarityIcon` | Иконка по строке-спецификации (`art:`, `cur:`, `rank:`, `league:`, `tile:`, `suit:`, `state:`, `spec:`, `combo:`, `glyph:` + бейджи `|no`, `|x2`, `|6`). Мини-фишки — настоящие `Tile` с теми же шейдерами. PNG в `game/assets/v10/clarity/icons/<kind>_<arg>.png` подменяет любую иконку без кода. |
| `clarity.gd` | `V10Clarity` | Точки входа (хуки), «ФИШЕК НА СТОЛЕ» + плашка «? Фишки» вместо «ЦЕЛЬ» с сакурой, разовые подсказки (Маджонг-тян про долгое нажатие; вопрос «Оставить метки мастей?» после 10-го стола), окно «Фишки и словарь» в настройках, dev-флаги. |
| `clarity_selftest.gd/.tscn` | `V10ClaritySelftest` | Самотест. |
| `tour.gd` | `V10ClarityTour` | Скриншот-тур всех экранов за один запуск. |

Правило пары проверено в коде: `TrayBoard.tap` сравнивает `x.face == t.face` — пара только из одинаковых картинок;
групп «цветы/времена года» как в классическом маджонге в игре нет. Масть нужна для бонуса «Тройка», +15 кристаллов, коллекции.

## Хуки (точные строки, уже стоят в этой ветке)

`game/scripts/screens/play.gd`
```gdscript
# build(), после _v9_dev():
V10Clarity.attach_play(self)  # v10-clarity hook: tile bubble, «Фишки» pill, clear goal plate
# _victory(): правило звёзд и статистика
var star_nodes: = v8_res_stars(ctx, V10Glossary.star_rule())  # v10-clarity hook (was V8PlayRules.T.star_rule)
v8_res_line(ctx, V10Glossary.stats_line(secs, boosters_used, fails), 19, UI.INK, 4.0)  # v10-clarity hook (was T.stats)
# _victory(): сразу после var rw: = v8_res_reward(...)
V10Breakdown.tap_reward(self, rw.row, stars, reward)  # v10-clarity hook: tap the crystals → «из чего сумма»
# _victory(): вместо ctx.y = _v8_yaku_chips(...)
ctx.y = V10Clarity.victory(self, plate, V8_RES_PAD, ctx.y, pw - V8_RES_PAD * 2.0, stars, reward) + 10.0
# _on_deny(): точная причина вместо «Её прижимают сверху» (неверно, когда фишку зажали с боков)
var why_blocked: = V10Glossary.blocked_reason(board, _t)
_bubble(why_blocked if why_blocked != "" else V6Txt.s("play.blocked"))
```
```gdscript
# _track_set(): имя тройки из словаря
var nm: String = V10Glossary.label("set.%d" % c)  # v10-clarity hook
_yaku_banner(nm, "3 пары подряд · +15")
```
`_v8_yaku_chips` остаётся в play.gd (мёртвый код) — его можно удалить при интеграции.

`game/scripts/tray_board.gd`
```gdscript
# setup(), после t.build(look):
V10TileMarks.attach(t)  # v10-clarity hook: suit mark / back badge
# _unhandled_input(), первая строка ветки «e is InputEventScreenTouch and e.pressed»:
if V10TileInfo.intercept(self, e):  # v10-clarity hook: long press / lupa / close the tile bubble
	get_viewport().set_input_as_handled()
	return
```

`game/scripts/main.gd` — последняя строка `settings()`:
```gdscript
V10Clarity.settings_hook(self, p)  # v10-clarity hook: «Фишки и словарь»
```
Хук сам увеличивает окно на 84 px и сдвигает вниз строки ниже y=900 («Тайники», версия). Если лейн responsive/profile
переверстал настройки — вызвать `V10Clarity.open_settings(main)` из любой кнопки.

## Для обучения (v10-tutorial)
- `V10Glossary.tip(id)` — короткая строка «Имя — за что» для подсказки; `V10Glossary.get_entry(id)` — всё сразу.
- `V10GlossaryScreen.open(host, cat)` / `V10Legend.open(host)` — открыть словарь (раздел) или легенду из «Как играть».
- Тема `basics` в `V10TutTips` и запись `state.free` говорят одно и то же правило; ссылка «Фишки» — `V10Legend.open`.
- Если в сборке есть `V10TutState.large()`, «Крупные символы» по умолчанию берутся оттуда (мягкая связь, без зависимости).

## Самотест и скриншоты
```
flock /tmp/tw-godot.lock /opt/tw-tools/godot --headless --path game res://scripts/v10/clarity/clarity_selftest.tscn
#  → V10 CLARITY SELFTEST n/n
flock /tmp/tw-godot.lock xvfb-run -a /opt/tw-tools/godot --path game --rendering-driver opengl3 --audio-driver Dummy \
  --resolution 720x1280 -- --screen=play --level=8 --v8_devsave=1 --shots=<dir> --at=120 --v10_tour=<dir> --name=r720
```
Самотест проверяет: у каждой метки из G.YAKU, set:N, G.CATS, FORTUNES, V6Specials.NAMES/EVENTS, V7Combo.TIERS, FACE_NAMES,
RANKS, LEAGUES, V9Ults.MODS, EGG_NAMES и меток экрана победы есть запись; не пустые «за что»; длины (имя ≤26, за что ≤74,
как ≤92, награда ≤60); имена не повторяются; нет каны в главной подписи; старые имена («Чистая рука», «Полнолуние ×2»,
«Букет» …) находят свою запись; нигде не пишется «лёд» про рубашку; 5 разных форм меток; пары на столе чётные; причина
блокировки точная (сверху / бок); пузырь есть для каждой фишки.

Dev-флаги: `--v10_open=legend|glossary|settings|bubble|lupa|why|card`, `--v10_marks=on|off|auto`, `--v10_big=1`, `--v10_tab=<cat>`.

## Переименования в партии (сделаны в этой ветке, строки помечены или однозначны)
- Лента тройки (`play._track_set`): «Букет · три пары: цветы» → «Тройка: цветы · 3 пары подряд · +15».
- Плашка комбо (combo.gd): «Лихорадка» → «Полнолуние» (+ «кристаллы ×2 · N с» под ним) — одно имя с лентой «Полнолуние ×2».
- «Счастливая серия ×6» → «Чистый ритм ×6» (specials.gd); приз подарка «Звёздный миг: 8 с ×2» → «Кристаллы ×2 на 8 с».
- Гадание: кана «おみくじ» → «Гадание», подпись «бонус на эту партию» (txt.gd).
- Табличка «ЦЕЛЬ» + сакура → «ФИШЕК НА СТОЛЕ» + рубашка фишки (делает `attach_play`, play.gd не трогали).

## Экран победы на разных экранах
- 720×1280 (короткий): «Стол пройден», самый крупный бонус и «Ещё N бонусов» с иконками остальных и суммой —
  панель почти той же высоты, что чипы 0.9, бюст героини остаётся. Тап по «Ещё» → разбор всех бонусов.
- 1080×2400 и выше: до 9 строк сразу (по высоте экрана).

## Раунд 2: правки по отзывам игроков-персон (Ирина 47, Дима 24, Аня 19)
Было 6,5–7/10. Что исправлено:
- **Кристаллы сходятся.** `V10Breakdown.crystal_math(play, stars, reward)` — одна формула для «Почему так?»: итог всегда
  `reward + play.gained` (ровно то, что катится на экране победы). Ва-банк удваивает и собранное за партию — формула так и
  пишет: «(стол 180 + звёзды 3×20 + собрано в партии 40) × 2 за ва-банк = 560». Расхождение 480/560 было в туре
  (`summary(play, 3, 560)` с жёсткой цифрой) — тур теперь берёт настоящую награду (`play.get_meta("v10_win")`). Самотест сверяет 5 случаев.
- **Одно имя: «Ва-банк».** Кнопка «ВА-БАНК!», лента «Ва-банк · стол чист!», тосты, реплики героинь, `G.YAKU.riichi.name`, подпись
  фото. «Риичи» остался только у настоящего режима «Стол риичи».
- **«НОВОЕ» — одна плашка** на самом крупном новом бонусе: «НОВОЕ · ещё N впервые». Всплывающая подсказка поверх списка убрана
  (закрывала заголовок и «Почему так?»). Заголовок блока — «ОЧКИ РАНГА · ЗА ЧТО» (не путать с кристаллами).
- **Один счётчик** для «НОВОЕ», «Получено уже N раз» и «×N» в словаре: `V10Breakdown.count_for(id, yaku)`.
- **Без «лёд», «риичи», старых имён мастей, «квартал», «осколок», «ульта», «марки», «бант» у подарка, «№»** — самотест теперь
  проверяет ВСЕ видимые поля записи (имя, подпись, за что, как, награда), а не только «за что».
- **Масть — одно слово:** Цветы, Небо, Сладости, Сокровища, Звери (подпись — «7 картинок», без «масть «Букет»»).
- **Цифры с фишек убраны.** «Крупные символы» = уголок вдвое крупнее (r 16 вместо номера), обычный чуть крупнее (10,5).
  Пузырь: «масть «цветы» · уголок пару не задаёт». Маджонг-тян один раз говорит: «Цвет уголка — не пара! Пара — только
  одинаковая картинка.» (подсказка `corner`). Уголки зажатых фишек гаснут вместе с ними (альфа 0,3), в лотке — яркие.
- **Подарок = «с коробочкой»** везде (бант — картинка масти «Сокровища»). Ключ: «откроет замки того же цвета (на столе: N)».
- **Карточка:** «За что» только у наград; у фишек/мастей/рангов — «Что это».
- **Легенда:** в сцене «Какую фишку можно взять» верхняя фишка правда лежит НА средней (сдвиг на полфишки, тень), средняя
  тусклая; подписи пар меняются, когда фишка доехала до лотка (не раньше). «Полный лоток» — «партия проиграна, если не спасти».
- **Пузырь фишки** выбирает сторону (над/под фишкой), которая меньше закрывает лоток, карточку героини и кнопку ва-банка.
- **Экран победы:** карточка ранга и строка гонки с «?» и тапом → объяснение; «Лига Бамбука · #4 из 20» → «Гонка недели ·
  #4 из 20 · лига Бамбука», «Квартал» → «Сезон»; «Альбом: +13 марок» → «Коллекция фишек: +13 наград».
- **Стол:** «ульта 0/7» → «умение 0/7» (и по всей игре «Ульта» → «Умение»), «осколок» → «частичка», «Стиль: Пятый ветер» →
  «Свойство: лоток на 5 мест», гадание — эффект первым («Ещё 4 золотые», чип «Гадание: …»), вместо кандзи 吉 — значок.
- Словарь: новые записи «Желания» и «Свойство героини».
